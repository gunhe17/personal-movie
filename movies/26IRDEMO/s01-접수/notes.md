# s01-접수 — 통화 한 건이 다섯 곳으로 흩어진다

기기: web · 계정 counselor1(정상담)
배역: 검사 축 — 햇살지역아동센터 윤도현·장서아·홍시우(만 10~12세, 미등록) · 담당 정상담. 이 케이스가 s02·s03·s04로 이어진다  (정본 CAST.md)

## 조작 순서
`/agent`에서 "통화 중인데, 여러 명 검사 접수해줄 수 있어?" → 에이전트가 필수 정보만 알려준다(기관명·성함·생년월일)
→ 들은 대로 한 줄 답변 → 검사 접수 폼으로 이동 + 기관·명단 3명 prefill(담당자는 자동)
→ 사람이 검사 항목 하나 클릭 → **등록** → 검사 현황. 흐름과 근거는 features.md.

## 캡처 지점

리허설 실측(2026-09-09, SPEC v3 타이밍). 촬영 시각은 lead 3초가 앞에 붙는다.

- 시작: 빈 에이전트 화면 (lead 3s 뒤)
- 종료: 검사 현황에 새 케이스
- 전체 길이: 조작 39초 + lead/tail 6초 ≈ **45초**

| 구간 | 리허설 t | 무엇 |
|---|---|---|
| **노컷 ①** | 9.3 – 23.3 (14.0초) | 답변 전송 → 1초 정적 → 폼으로 갈아끼워짐 → 기관·명단 3명 얹힘. **커서가 멈춘 채 화면만 바뀐다** — 이 장면의 심장. 편집에서 앞뒤를 잘라 6초로 쓴다 |
| **노컷 ②** | 30.6 – 37.0 (6.4초) | 등록 클릭 → 기관·내담자 3명·케이스 3건 생성 → 검사 현황 |
| 증거 컷 | 24.6 – 30.6 | 우측 `접수 진행 2/3` → 검사 항목 둘(로르샤흐 · 스마트폰중독검사)을 고르면 3/3 |
