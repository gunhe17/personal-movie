# s04-바로링크 — 검사받으러 한 번, 결과 들으러 한 번

기기: web(보내는 쪽) + phone(들어가기 · 조회) — **테이크 셋**
배역: 검사 축 — 상담사 정상담이 윤도현의 스마트폰중독검사를 집으로 보내고, 보호자 **윤보호**가 폰에서 받는다 (정본 CAST.md)

## 구성 — 테이크 셋이 한 장면을 만든다 (2026-09-10 밤 재구성)

| 테이크 | 규격 | 무엇 |
|---|---|---|
| **`web_sendlink`** | 1600×900 | **보내는 쪽** — 검사 현황 → 바로링크 전송 → 전송 내역 |
| **`phone_enter`** (A) | **1170×2532** | **들어간다** — 문자 → 링크 탭 → 4자리 → 검사 첫 쪽 |
| **`phone_view`** (B) | **1170×2532** | **조회한다** — 상담 기록 펼침 → `결과 보기 · PDF` |

**문자에서 들어오는 대목은 A에만 있다.** B는 이미 인증된 상태로 목록에서 시작한다 —
제품이 원래 그렇게 동작한다(BFF 쿠키 2시간 · `restoreSession()`이 목록을 되살린다).
그 상태는 `node _scripts/s04-barolink-state.mjs`가 만든다(`--state _state/local-barolink.json`).

A는 문자 목업(`_mocks/s04-sms.html`)에서 시작하고 **링크가 진짜라 탭 한 번에 제품 화면으로 넘어간다** —
목업과 서비스가 한 컷으로 이어진다. 그 뒤는 전부 진짜 화면이다.

> **iOS 시뮬레이터 메시지 앱은 못 쓴다** (2026-09-10 실측). `com.apple.MobileSMS`도 `sms.db`도 있고
> 표준 iMessage 스키마라 행을 넣는 것까지 된다(트리거가 데몬 전용 확장 함수를 불러 걷어내야 한다).
> 그런데 **앱이 그 DB를 안 읽는다** — 내 행은 DB에 그대로인데 화면에는 애플의 데모 대화 둘만 뜬다.
> 주입 스크립트는 `_scripts/s04-sms.sh`에 남겨 뒀지만 **쓰지 않는다.**
>
> 문자 목업에는 **상단 상태바(시계·와이파이·배터리)를 두지 않는다** — 폰 목업의 프레임이 그 역할을 한다.

### 상태 만들기 — B는 A보다 뒤의 시점이다

A는 검사가 `pending`인 자리, B는 **제출·결과 전송까지 끝난** 자리에서 출발한다. 순서가 있다.

```bash
# B (조회)
node _scripts/s04-send-result.mjs        # 센터가 결과 전송(진짜 API) → 공개 플래그가 켜진다
node _scripts/s04-barolink-state.mjs     # 링크 인증 상태 → _state/local-barolink.json (2시간)

# A (진입) — 되돌린 자리에서
docker exec -i saas-postgres psql -U imomtae -d imomtae -f- < _scripts/s04-task-reset.sql
```

되돌리기·준비가 다섯으로 갈린다 — 헷갈리지 않게:

| 스크립트 | 무엇 |
|---|---|
| `s04-reset.sql` | 전송 내역을 비운다 — **보내는 쪽**용 |
| `s04-task-reset.sql` | 응시를 되돌린다(status·응답·보고서·공개) — **A**용 |
| `s04-setup.sql` | 상담 기록 공유문을 **만든다**(s06-setup.sql의 C00003 위에) |
| `s04-send-result.mjs` | 센터가 **결과를 전송**한다(진짜 API) — **B**의 전제 |
| `s04-barolink-state.mjs` | 링크 인증 상태를 굳힌다 — **B**가 문자·인증 없이 시작하게 |

> ⚠️ **로컬에서 결과지를 열려면 둘이 필요했다** (2026-09-10 실측).
> ① `.env`에 `S3_BUCKET_ENABLED=false` — 없으면 제출 자체가 `RuntimeError: S3 configuration incomplete`로 500이다.
> ② 그러면 presigned URL이 `file://`로 나오는데 화면이 http(s)만 허용해 `결과 주소를 확인하지 못했어요`가 뜬다.
>    제품 사본에 **개발 전용 `/local-storage` 정적 마운트**를 붙이고 `LocalStorageClient`가 그 http 주소를 주게 했다.
> 그리고 러너 버그 하나 — **PDF 응답까지 텍스트로 다시 쓰던** 번역 방지 라우트를 HTML일 때만 돌게 고쳤다.

### PDF는 열지 않는다 (t04~t08 실측)

보고서를 새 탭으로 여는 데까지 갔더니 Chromium PDF 뷰어가 폰 폭(390px)에서 **판마다 다르게 굴었다** —
폭에 맞춰 그리기도, 가로로 밀려 왼쪽에 검은 여백을 남기기도, 2.6초를 줘도 흰 화면인 판도 있었다.
보고서가 **가로로 넓은 문서**라 좁고 긴 뷰포트에서 뷰어가 어떻게 맞출지가 안 정해진다.
`mouse.wheel`로 가로를 되돌리는 것도(빈 곳으로 스크롤) `#zoom=page-width` 재진입도(흰 화면) 안 됐다.

장면이 말할 것은 "**결과가 같은 링크에 와 있다**"이고 그건 줄이 `결과 보기 · PDF`로 바뀌는 데서 이미 선다.
보고서 지면 자체는 s03의 웹 테이크와 스틸이 맡는다.

**`reveal`도 쓰지 않는다** — 폰 화면에는 목록이 통째로 들어와 스크롤할 것이 없는데, 부르면 작은 dy를 잡아
화면을 밀어내 끝이 검게 나온다(t09).

### 상태표시줄 자리를 비운다

화면을 **띠 · 영상 슬롯 · 띠** 세 층으로 나눴다(`phone.html`). 촬영본을 화면 전체에 깔면 둥근 모서리
(4.7cqh)가 페이지의 맨 윗줄(마인드스코프 로고)과 맨 아랫줄을 잘라 먹는다. 실제 폰의 상태표시줄
(`statusH` 3.8cqh)·홈 인디케이터(`homeH` 2.6cqh) 자리만큼 위아래를 비우고 그 안쪽에만 영상을 넣어
**모서리가 자르는 것이 빈 띠뿐**이 되게 했다.

매트 규약도 슬롯으로 옮겼다 — 띠는 검정판·흰판에서 똑같이 흰색이라 차이에 안 잡히고,
그래서 합성 사각형에서 자동으로 빠진다.

> 슬롯 치수는 JS에서 계산해 박는다. 플렉스 안에서는 `aspect-ratio`가 높이가 정해져도 폭을 안 잡아
> 폰이 막대가 됐다(실측). 높이가 먼저 정해지는 물건이라 `slotH = phoneH − statusH − homeH`,
> `slotW = slotH × 1170/2532` 순서로 푼다.

### 간격 — 처음 보는 화면에는 `beat`를 준다

기존 장면의 급이 그렇다: s01 `에이전트 화면` · s03 `종합보고서 편집기` · s04-web `검사 현황`이 전부 `beat`(0.7)다.
`hold(350)`은 **이미 보이던 화면 안에서** 패널이 갈아끼워질 때 쓰는 짧은 급이고(s01 `폼 도착`), 폰 쪽의
인증 화면·목록은 그 급이 아니다 — 문자에서 막 넘어온 **새 화면**이다.

처음 판이 빨랐던 이유는 값이 아니라 **방식**이었다:
