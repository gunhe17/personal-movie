# s06-필드노트 — 기억으로 쓰는 일지

기기: 전문가 앱(시뮬레이터) + web  ※ 실기기 녹음은 하지 않는다 — features.md
배역: 회기 축 — 이하준 회기, 상담사 정상담  (정본 CAST.md)

## 조작 순서
앱: 홈 → `필드노트 홈 열기` → 필드노트 홈(오늘 기록할 일정 1건 · 최근 노트 3 · `바로 녹음`)
웹: `/schedule/field-notes/[id]` — 원본 전사 · 화자별 대화 · 요약을 시간 축으로
※ 녹음 자체는 찍지 않는다(시뮬레이터에 마이크 입력이 없다). 결과는 시드의 완료된 필드노트로 보여준다.

## 캡처 지점

리허설 실측(2026-09-10, SPEC v3) — 웹 절반.

- 시작: 필드노트 헤더(30분 · 회기 연결됨)
- 종료: 요약
- 웹 길이: 조작 13.0초 + lead/tail 6초 ≈ **19초**

| 구간 | 리허설 t | 무엇 |
|---|---|---|
| **노컷** | 3.2 – 10.7 (7.5초) | 스크롤 → 화자별 대화(상담사/내담자)가 타임스탬프와 함께 → 요약. **머릿속에만 있던 것이 시간 축이 되는 자리** |

앱 절반은 idb로 라벨 확인까지 마쳤고 타임코드는 촬영 때 meta로 남는다.
