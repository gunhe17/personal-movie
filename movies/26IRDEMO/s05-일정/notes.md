# s05-일정 — 빈 시간을 맞추려면 한 명 한 명 연락한다

기기: web (내담자 앱은 찍지 않는다 — features.md)
배역: 회기 축 — 이하준(만 9세)과 어머니 이수진 · 놀이치료 C00002  (정본 CAST.md)

## 조작 순서
폰: 일정 탭 → 일정 상세 → `일정 변경 요청` → 센터가 열어둔 시간(오전·오후, 찬 시간은 잠김) 중 선택 → 요청
     → 버튼이 `변경 요청 검토 중`으로, 상단 배너 "변경 요청한 시간이에요 · 선생님 확인 후 확정돼요"
웹: `/schedule/reservations` 대기 탭 → `승인` → 확인 모달("요청한 시간으로 일정을 변경할까요?") → `확인`
     → 스낵바 "일정을 변경했어요" → 캘린더에 옮겨진 회기
폰: 일정 탭이 확정된 시간으로 바뀐다
흐름과 근거는 features.md. 웹 스크립트 `_scripts/s05-approve.mjs`.

## 시작 상태 (촬영 전 준비 필요 — 셋 다 지금 없다)
1. 이하준의 **미래 회기** 1건 (C00002 3회기가 전부 과거)
2. 앱 연결 `center_links` (내담자 상세 → 6자리 코드 → 앱 입력)
3. 보호자 앱 계정 (이수진)

## 캡처 지점
- 시작: 폰 일정 탭 · 웹 예약 대기 탭 (동시 시작)
- 종료: 웹 캘린더에 옮겨진 회기 · 폰 일정 탭 갱신
- 6초 노컷 후보: ① 폰 — 가능한 시간이 떠서 하나를 고르고 요청까지 ② 웹 — 승인 → 확인 → 캘린더 반영
- 실측 타임코드: 리허설 후 채운다 (폰 절반은 idb 설치 전까지 실측 불가)
