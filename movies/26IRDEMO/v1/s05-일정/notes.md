## 조작 순서
폰: 일정 탭 → 일정 상세 → `일정 변경 요청` → 센터가 열어둔 시간(오전·오후, 찬 시간은 잠김) 중 선택 → 요청
     → 버튼이 `변경 요청 검토 중`으로, 상단 배너 "변경 요청한 시간이에요 · 선생님 확인 후 확정돼요"
웹: `/schedule/reservations` 대기 탭 → `승인` → 확인 모달("요청한 시간으로 일정을 변경할까요?") → `확인`
     → 스낵바 "일정을 변경했어요" → 캘린더에 옮겨진 회기
폰: 일정 탭이 확정된 시간으로 바뀐다
흐름과 근거는 features.md. 웹 스크립트 `_scripts/s05-approve.mjs`.

### 되돌리기 — 승인은 회기를 진짜로 옮긴다

한 번 찍으면 `s05-setup.sql`을 다시 돌려도 전제가 깨진다. 회기가 이미 9/18 16:00에 있는데
요청도 9/18 16:00이라 화면에 **같은 시각 두 개**가 뜬다(2026-09-11 실측). 순서가 있다:

```bash
docker exec -i saas-postgres psql -U imomtae -d imomtae -f- < _scripts/s05-reset.sql   # 회기를 9/17 10:00로, 요청 삭제
docker exec -i saas-postgres psql -U imomtae -d imomtae -f- < _scripts/s05-setup.sql   # 요청 한 건 다시
```
