# s02-검사실시 — 검사는 207분

기기: web · tablet
배역: 검사 축 — **윤도현**(s01이 접수한 셋 중 하나)의 로샤. 마인드봄에서 clinician 정상담이 실시  (정본 CAST.md)

## 조작 순서

실시 화면(`/collect`)에서 시작한다. 목록은 지나가지 않는다 — 보여줄 것은 **반응 한 줄이 끝까지 채워지는 것**이다.

`추가`(줄 긋기) → 자유반응 타이핑 → 위치 칸으로 `reveal` → `W` → `영역 그리기` → 카드 위에 드래그 → 질문 타이핑 → 카드 방향 → 촉구

## 캡처 지점

리허설 실측(2026-09-10, SPEC v4). 무대는 마인드봄(4503). 실시 화면에서 시작한다.

- 시작: 카드 I · 반응 없음
- 종료: 방향까지 채워진 한 줄
- 전체 길이: 조작 28.7초 + lead/tail 2.7초 ≈ **30초**

| 구간 | 무엇 |
|---|---|
| **노컷 ①** | 내담자 화면 → 마이크 → 탭 → 임상가 화면으로 돌아오니 아이의 말이 자유반응 칸에 있다 |
| **노컷 ②** | 위치 W → 카드 위에 영역 그리기 → 질문 답변. **배지가 회색에서 초록으로** |
| 증거 컷 | 방향 — 피검자가 카드를 돌린 것도 기록이다 |
