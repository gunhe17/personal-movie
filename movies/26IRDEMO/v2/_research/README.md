## 한 장으로

### 1. 이름부터 바로잡는다

**"Kling O3"는 공식 명칭이 아니다.** 공식은 **`Image 3.0 Omni`**(`kling-v3-omni`)이고,
O3는 fal·Artlist 같은 파트너의 약칭이다. Kuaishou 보도자료에 그 문자열이 없다.

Artlist 안에서 이 이름이 **서로 다른 두 모델**을 가리킨다. 섞으면 호출이 어긋난다.

| | modelGroupId | 하는 일 |
|---|---|---|
| Kling o3 **이미지** | **354** | 첫 프레임을 만든다 |
| Kling O3 **영상** | **347** | 그 프레임을 움직인다 |
| Kling **v3** (별개 줄기) | 355 · 349 · 402 | **기본 등급 — 4K도 다중 참조도 series도 안 된다. 쓰지 않는다** |

### 2. 품질 평판이 존재하지 않는다

| | |
|---|---|
| Artificial Analysis T2I | **87위 / 159 · Elo 917.** 자기네 1년 묵은 Kolors 2.1(947)보다 낮다 |
| LMArena | **미등재** |
| 공식 벤치마크 주장 | **없다.** 논문도 테크리포트도 없다 |
| 실사용자 검증 | **없다.** r/aivideo "Kling O3" 검색 0건. 나오는 건 전부 제휴 마케팅 |
| vCoT | 공식 자료에 문자열 없음 · 논문 없음 · **API에 제어 파라미터 없음** |

**→ 이 모델을 고르는 근거는 품질이 아니라 가격과 기능이다.** 그렇게 쓰지 않으면 근거 없는 문장이 된다.

### 3. 그런데 가격과 기능은 확실히 좋다

| 사실 | 출처 |
|---|---|
| **2K는 장수와 무관하게 100 크레딧** — 9장도 100 | 01 (1·4·9로 세 번 실측) |
| 다른 모델은 장당 100 (Seedream 5장 = 500) | 01 |
| 참조 이미지 **최대 10장** · 네이티브 4K | 03 · 05 |
| 영상이 **끝 프레임을 받는다** — Artlist에서 여기만 | 01 |

> ⚠ **정정.** 처음에 "영상 1위"라고 적었는데 **그것은 Text-to-Video 순위다.**
> 우리가 쓰는 **Image-to-Video에서는 중위권이다** — AA #15 · arena.ai #18.
> 위는 MiniMax H3 · Seedance 2.x · Wan 3.0이다.
> **Kling을 영상에 쓸 근거는 순위가 아니라 `end_frame` 하나다.**

> ⚠ **그리고 "정액 배치"는 1장을 뽑을 때는 이점이 아니다.**
> 같은 100 크레딧에 **Seedream 5.0은 4K를**, 90에 **Nano Banana 2는 2K를** 준다.
> **Kling o3를 쓸 이유는 오직 여러 장을 한 번에 뽑을 때다.**

### 4. 스킬 설계를 정하는 다섯 가지

**① 손잡이가 없다.** `negative_prompt` · `cfg_scale` · `seed` 전부 없다.
v1의 `--no` 목록도 `--s`·`--c`도 옮길 곳이 없다. **모든 통제가 프레임 자체와 프롬프트 문장으로만 간다.**

**② 첫 프레임은 시작점이 아니라 클립 전체의 사전이다.**
논문(arXiv 2511.15700)이 첫 프레임을 **"개념적 기억 버퍼"**라 부른다 — 후속 프레임이 참조하는 모든 개체가 거기 저장된다.
그리고 Runway 공식: **"흐릿한 손이나 얼굴 같은 아티팩트는 증폭된다."**
**→ 프레임에 결함이 있으면 애니메이트하지 말고 프레임부터 고친다.**

**③ 글자는 반드시 깨진다. 그리고 이 저장소는 이미 그 답을 갖고 있다.**
VAE 압축(4×8×8)이면 본문 텍스트는 잠재공간에서 한 픽셀 미만이라 **복원 불가**다.
v1은 모든 프롬프트에서 `legible text, lettering, numbers, watermark, logo`를 배제해 왔다.
**→ 생성 프레임의 화면 영역은 빈 플레이트로 두고, 실제 제품 화면은 `capture-service` 촬영본을 코너 핀으로 합성한다.**
`motion-stage`가 이미 그 일을 결정론적으로 한다. **AI는 목업 주변의 세계를 만들고, 화면 안은 스킬이 채운다.**

**④ 연속성은 영상이 아니라 스틸 단계에서 잡는다.**
Artlist의 O3 영상에는 레퍼런스 입력이 없고(`image_url`·`end_frame`뿐),
이미지 쪽에도 `result_type: series`가 노출되지 않는다.
라스트 프레임 체이닝은 **오차가 곱해진다**(FramePack 논문).
**→ 아홉 스틸이 서로 일관되면 아홉 클립도 일관된다. 체이닝은 3클립 이하.**

**⑤ 2단 구성.** 탐색은 Kling o3 2K 9장으로 싸게(100), **마감은 반드시 다른 모델로.**
한 모델로 끝까지 가면 벤치마크와 가격 중 하나를 버리게 된다.

| 단계 | 모델 | 이유 |
|---|---|---|
| **탐색** | Kling o3 2K ×9 | 100 크레딧. 다른 모델은 같은 9장에 900 |
| **마감(와이드)** | **Nano Banana Pro** (Artlist 2071) | ⚠ **NB2보다 Pro가 더 필미크하다** — NB2는 *"slightly artificial"*. 그리고 **Google은 다큐멘터리 결, OpenAI는 스튜디오 광택** — v1의 룩은 다큐멘터리다 |
| 마감(비용 우선) | Nano Banana 2 2K | 2048×1152로 우리 촬영본 비율과 일치 · 배치 −50%. ⚠ **편집하면 열화하므로 한 번에 뽑고 끝낸다** |
| **마감(인물 클로즈업)** | GPT Image 2.5 · FLUX.2 [max] | **실제 피부 질감 증거가 있는 유이한 둘** |
| **룩 고정** | Recraft V4.1 | 스타일 레퍼런스 10장 → 재사용 `style_id` |
| **영상** | Kling O3 (끝 프레임 필요 시) · 아니면 Seedance 2.x | |

**⑥ 프롬프트는 길게 쓴다.** 이 모델에는 **Prompt Enhancer가 내장**돼 있어
짧게 쓰면 모델이 멋대로 채운다("한 소녀" → "햇살 아래 실크 드레스를 입은 아시아 소녀…").
400~1,200자가 스윗스팟이고 중요한 지시는 앞 60%에 둔다. 자세한 것은 10번 문서.

### 5. 지켜야 할 것

- **생성물은 30일 뒤 서버에서 삭제된다.** 스킬이 즉시 로컬로 내려받는다
- **오디오 기본값이 켜짐이다.** 끄면 클립당 300 크레딧이 절약되고 컷 사이 소리가 안 튄다
- **아동이 등장하는 프레임**은 Kling 커뮤니티 가이드라인의 미성년자 조항에 걸린다. v1이 얼굴을 피하고 손·팔만 찍은 것이 결과적으로 안전했다
- **Artlist 라이선스는 납품 전에 사람이 확인한다.** IR 영상은 대외 공개물이다

## 아직 확인 못 한 것 — 스킬을 쓰기 전에 실사할 것

| | 왜 중요한가 |
|---|---|
| **한글 렌더링 품질** | 미검증. 다만 ③ 때문에 생성 프레임에 글자를 안 넣으면 무관해진다 |
| **I2V 실제 단가** | 입력 이미지가 있어야 견적이 난다 |
| **생성 소요 시간** | 아직 한 번도 생성하지 않았다 |
| **`auto` 종횡비의 실제 동작** | 참조를 따르는지 프롬프트로 추론하는지 |
| **Kling o3 대 상위 모델의 실제 차이** | **아레나 87위가 "낮은 채도의 한국 상담센터 실내"에서도 87위라는 보장은 없다.** 같은 프롬프트로 나란히 뽑아 눈으로 보는 것이 스킬의 첫 작업이다 |
| **같은 패밀리 조합 이점** | **공개 검증이 존재하지 않는다**(08). 우리가 재면 그것은 새 데이터다 |
| **Artlist "Seedream 5.0" SKU의 정체** | 바이트댄스는 **Lite와 Pro만** 낸다. 4K를 100에 주는 그 SKU가 어느 쪽인지 확인 필요 |
| **`@Image1` 대 `reference image 1`** | 어느 쪽이 정체성을 더 강하게 잠그는지 **아무도 테스트하지 않았다.** 배치 한 번(100)이면 판정된다 |
| **인라인 부정절이 실제로 먹는지** | 네거티브 필드가 없는 모델에서 **측정된 적이 없다** |

## 지금 당장 할 값싼 실험 셋 (합쳐 300 크레딧)

1. **`@Image1` vs `reference image 1`** — 표기만 바꿔 9장씩. 미해결 중 가장 중요하다
2. **한글 렌더링 1회** — 결과가 어떻든 이 프로젝트의 의사결정이 끝난다. **공개 데이터포인트가 세계 최초가 된다**
3. **인라인 부정절 유무 A/B** — `No visible words, labels, logos…` 절만 붙였다 뗐다

## 조사의 한계

Reddit은 아카이브 API로 우회했고 **X·YouTube는 접근하지 못했다.** 실무자 A/B 보고가 가장 많을 곳이다.
**결과 없음은 접근 제약이지 부재의 증명이 아니다.**
그리고 이 주제의 2026년 웹은 제휴 SEO로 포화돼 있다 — 07번 문서 §6에 경계 도메인 목록을 남겼다.
