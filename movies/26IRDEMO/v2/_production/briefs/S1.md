## 사례 (A 기존 흐름)
- **인물 · 시각**: 실장 박접수 · 보호자 이수진 · 월요일 09:10 → 검사 전 주 → 검사 당일
- **흐름**: 전화 → 수첩에 받아 적음 → CRM에 다시 침 → 카톡 명단 사진 → 엑셀에 한 명씩 → 기록지·동의서 문자로 보내고 사진으로 회수 → 출력해 파일철 → 검사 전 주, 보호자가 설문만 쓰러 한 번 온다 → 검사 당일 다시 출력해 상담사에게

- **B로 이음새**: A의 마지막 컷에서 상담사 손에 건네진 그 종이가 B 첫 컷에서 폰 카메라 아래 놓인다. 설문(⑤)은 B 마지막 컷에서 같은 링크로 나간다.
