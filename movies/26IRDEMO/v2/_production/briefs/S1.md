# S1 접수 · 서류 · 바로링크

## 사례 (A 기존 흐름)
- **인물 · 시각**: 실장 박접수 · 보호자 이수진 · 월요일 09:10 → 검사 전 주 → 검사 당일
- **흐름**: 전화 → 카카오톡으로 명단 사진 → 컴퓨터에 한 명씩 입력 → 기록지·동의서 문자로 보내고 사진으로 회수해 출력 → 검사 전 주, 보호자가 설문만 쓰러 한 번 → 검사 당일 다시 출력해 상담사에게
- **이 A가 말하는 것**: 고객 정보는 도착한 순간 이미 디지털인데, 이 센터에서는 사람이 그것을 네 번 옮긴다. 종이 한 장은 여섯 번 손을 거치고, 설문 한 장 때문에 보호자가 한 번 더 온다.
- **B로 이음새**: A의 마지막 컷(종이를 건네는 손)에서 B 첫 컷(접수 화면)으로 — 종이 대신 한 마디. 그 종이는 B 마지막 컷에서 보호자 휴대폰에 뜬다.
