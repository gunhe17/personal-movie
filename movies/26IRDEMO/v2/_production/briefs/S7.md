# S7 정산 · 코다

## 사례 (A 기존 흐름)
- **인물 · 시각**: 상담사 정상담 → 원장 김원장 · 월말 오후 → 원장 책상
- **흐름**: 수첩의 회기 표시를 손가락으로 센다 → 종이에 적어 원장 책상에 올린다 (이 숫자로 급여) → 원장은 엑셀에서 잔여를 차감하고 월말에 대조 → 책상 한쪽, 올해 공고 네 종 프린트, 형광펜으로 단가·조건·서류를 골라 엑셀에 옮긴다
- **이 A가 말하는 것**: 한 달의 일이 접힌 종이 한 장이 되어 사장 책상에 오르고, 그 일의 단가는 사장이 수백 페이지를 형광펜으로 읽어 알아낸 것이다.
- **B로 이음새**: A의 접힌 종이(회기 수)가 B에서 화면의 잔여 숫자가 된다 — 세지 않아도 이미 맞는.
