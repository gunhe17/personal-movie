## 1. 제품 정의

### 한 줄 요약

> 상담센터 내담자/보호자를 위한 **일정 확인 + 진행현황 추적 + 치료 참여 + 성장 가이드** 앱

### 서비스 컨셉

> **"상담실 밖에서도 성장은 계속된다"**
>
> 마인드엔서는 상담사가 설계한 치료 방향을 내담자/보호자가 일상에서 실천하고,
> 그 기록이 다시 상담사에게 전달되는 **연속적인 치료 생태계**를 만든다.

### 핵심 가치

| 가치 | 설명 |
|------|------|
| 연속성 | 상담실과 일상이 단절되지 않고 하나의 흐름으로 연결 |
| 투명성 | 상담 진행 상황과 변화를 사용자가 직접 확인 |
| 참여감 | 내담자/보호자가 수동적 관찰자가 아닌 **능동적 파트너**로 참여 |
| 신뢰 | 전문가 기록과 AI 인사이트로 치료에 대한 불안 해소 |

### 앱 이름

**마인드엔서** (변경 없음)

### 타겟 사용자

| 사용자 | 설명 | 핵심 니즈 |
|--------|------|-----------|
| 성인 내담자 | 본인이 직접 상담받는 사람 | "다음 일정은 언제?" + "나 나아지고 있나?" |
| 아동 보호자 | 자녀의 상담을 관리하는 보호자 | "우리 애 어디까지 했지?" + "효과 있나?" |

- 아동이 직접 사용하는 케이스는 없음

## 3. 사용자 분석

### 3-1. 사용자 심리 특성

> 내담자와 보호자는 단순 "일정 확인"을 넘어 깊은 심리적 맥락을 가지고 앱을 사용한다.

#### 보호자 심리

| 특성 | 구체적 양상 |
|------|------------|
| 높은 불안 수준 | 아이에게 문제가 있다는 인식 자체에서 오는 죄책감과 걱정. 치료 효과를 지속적으로 의심 |
| 불확실성에 민감 | 상담 내용을 알 수 없는 상황에서 오는 불안. 상담사가 무엇을 하는지 궁금해함 |
| 과도한 책임감 | "내가 더 잘해야 한다"는 압박감. 미션 실패 = 치료 지연이라는 두려움 |
| 전문성 격차 인식 | 상담사에 비해 자신이 아이를 잘 모른다는 열등감. 전문가 의존 경향 |
| 변화에 예민 | 아이의 작은 변화도 의미 부여하고 싶어 함. **나아지고 있다는 확신**을 필요로 함 |

#### 성인 내담자 심리

| 특성 | 구체적 양상 |
|------|------------|
| 진전 감각 갈망 | "이거 효과 있는 건가?" — 변화가 눈에 보이는 증거를 원함 |
| 자기 관리 의지 | 상담 외 일상에서도 무언가 실천하고 싶지만 방법을 모름 |
| 프라이버시 민감 | 심리 관련 앱이 타인에게 보이는 것에 대한 거부감 |

### 3-2. 핵심 니즈

#### 성인 내담자

```
┌─────────────────────────────────────────────────┐
│  1순위: 안심       "다음에 뭘 하면 되지?"        │
│  → 다음 일정이 명확히 보임                       │
├─────────────────────────────────────────────────┤
│  2순위: 진전 감각  "나 나아지고 있나?"            │
│  → 회차 진행률, 변화 추이                        │
├─────────────────────────────────────────────────┤
│  3순위: 놓치지 않기 "까먹으면 안 되는데"          │
│  → 알림 + 준비사항                               │
├─────────────────────────────────────────────────┤
│  4순위: 일상 참여  "상담 외 시간에 뭘 하면 될까?" │
│  → 미션/기록 시스템                              │
└─────────────────────────────────────────────────┘
```

#### 보호자

```
┌─────────────────────────────────────────────────┐
│  1순위: 파악       "우리 애 어디까지 했지?"      │
│  → 진행현황 한눈에                               │
├─────────────────────────────────────────────────┤
│  2순위: 준비       "다음에 뭘 챙겨가야 하지?"    │
│  → 다음 일정 + 안내사항                          │
├─────────────────────────────────────────────────┤
│  3순위: 효과 확인  "돈 쓸 가치가 있나?"          │
│  → 변화 추이 (검사 비교, 회기 비교)              │
├─────────────────────────────────────────────────┤
│  4순위: 참여       "나도 뭔가 해야 하지 않나?"   │
│  → 미션 수행 + 일상 기록 → 상담사에게 전달       │
└─────────────────────────────────────────────────┘
```

### 3-3. UX 방향성 (심리 특성 기반)

| 원칙 | 적용 방향 |
|------|----------|
| 부담 최소화 | 기록은 짧고 단계적으로. 긴 입력 폼 대신 선택 → 텍스트의 점진적 구조 |
| 성취감 강화 | 기록 완료 시 주간 누적 도트, 격려 메시지 등 즉각적 피드백 |
| 전문가 권위 활용 | 상담사 이름과 노트를 전면 배치. "전문가가 보고 있다"는 신뢰감 |
| 변화의 가시화 | 타임라인, AI 인사이트, 회기 비교 등 **진행이 보이는 구조**로 불안 해소 |

## 6. 주요 기능 상세

### 6-1. 미션 시스템

> 치료 목표를 일상 행동으로 세분화하는 핵심 기제. 상담사가 SaaS에서 설정 → 앱에 자동 반영.

```
┌─────────────────────────────────────────────────┐
│  SaaS (상담사)          앱 (내담자/보호자)        │
│                                                 │
│  회기별 미션 설정  ──→  홈 · 이번 주 미션 카드    │
│                        ↓                        │
│                        기록 남기기 (3단계)        │
│                        ↓                        │
│  기록 확인 ←────────  상담사에게 전달됨           │
│  (상담 준비 자료)                                │
└─────────────────────────────────────────────────┘
```

| 구분 | 설명 | 예시 |
|------|------|------|
| 내담자/보호자 미션 | 태도/반응 변화 목표 | "아이가 화낼 때 행동보다 감정 이름을 먼저 말해주세요" |
| 활동 미션 | 일상에서 수행하는 활동 | "감정 날씨 카드 만들기", "하루 10분 산책" |
| 업데이트 주기 | 회기 기반 | 상담사가 각 회기 후 다음 미션 설정 |
| 기록 연동 | "오늘 기록 남기기" 버튼으로 통합 기록 | 미션 관련/일상 기록 구분 |

#### 홈 화면 미션 카드

```
┌─────────────────────────────────────┐
│  📌 이번 주 미션                     │
│                                     │
│  💬 감정 이름 먼저 말해주기          │
│  아이가 화를 낼 때 행동을 지적하기   │
│  전에, 감정을 먼저 인정해주세요      │
│                                     │
│  ┌─────────────────────────────┐    │
│  │    오늘 기록 남기기           │    │
│  └─────────────────────────────┘    │
│                                     │
│  ● ● ● ○ ○ ○ ○  이번 주 3회 기록   │
└─────────────────────────────────────┘
```

### 6-2. 기록 플로우

> 기록 부담을 최소화하면서 상담에 유의미한 데이터를 수집.

```
Step 1                    Step 2                   Step 3
기록 유형 선택             내용 입력                 완료
┌────────────┐            ┌────────────┐           ┌────────────┐
│ ○ 미션 관련 │            │ 상황 설명   │           │  🎉         │
│ ○ 일상 기록 │     →      │ (필수)     │    →      │ 잘 하셨어요 │
│ ○ 둘 다    │            │            │           │             │
│             │            │ 반응/느낌   │           │ ● ● ● ● ○  │
│             │            │ (선택)     │           │ 이번 주 4회 │
└────────────┘            └────────────┘           │             │
                                                   │ 상담사에게  │
                                                   │ 전달됩니다  │
                                                   └────────────┘
```

| 설계 원칙 | 적용 |
|----------|------|
| 점진적 공개 | 필수 → 선택 순서로 부담 줄임 |
| 즉각적 보상 | 완료 시 격려 메시지 + 주간 누적 도트 |
| 피드백 루프 | "상담사에게 전달됩니다" — 기록의 의미 부여 |
| 짧은 플로우 | 최대 3단계, 1분 이내 완료 |

### 6-3. 통합 타임라인 (Phase 2)

> 회기(상담사 데이터)와 내담자/보호자 기록이 날짜순으로 통합되어 치료 전체 흐름을 파악.

```
    ● ─── 5회기 (5/7)
    │     회기 요약: 감정 표현이 늘어남
    │     보호자 실천: 아이 말에 반응 속도 늦추기
    │
    ◦ ─── 내 기록 (5/9)
    │     미션 관련: 화내는 상황에서 감정 이름 말해줌
    │     아이 반응: 처음엔 무시했지만 2번째에 반응
    │
    ◦ ─── 내 기록 (5/11)
    │     일상 기록: 학교에서 친구와 다툰 후 먼저 이야기함
    │
    ○ ─── 6회기 (5/14) — 예정
          "상담 후 내용이 업데이트돼요"
```

| 노드 유형 | 시각적 구분 |
|----------|-----------|
| 완료 회기 | 파란 채운 원 ● — 회기 요약 + 보호자 실천 사항 카드 |
| 예정 회기 | 빈 원 ○ — "상담 후 업데이트" 안내 |
| 내 기록 | 작은 초록 원 ◦ — 초록 테두리 카드로 회기와 시각 구분 |

### 6-4. 전문가 노트 (Phase 1)

> 상담사가 회기 후 작성한 노트를 내담자/보호자 친화적 형식으로 제공.

```
┌─────────────────────────────────────┐
│  📝 전문가 기록                      │
│                                     │
│  ▼ 5회기 (5/7)              최신    │
│  ┌───────────────────────────────┐  │
│  │ 회기 요약                      │  │
│  │ 감정 카드 활동 진행. 이전보다   │  │
│  │ 감정 어휘가 다양해짐.          │  │
│  │                               │  │
│  │ 실천 사항                      │  │
│  │ 아이가 감정을 말할 때 즉시     │  │
│  │ 반응하지 말고 3초 기다려주세요  │  │
│  └───────────────────────────────┘  │
│                                     │
│  ▶ 4회기 (4/30)                     │
│  ▶ 3회기 (4/23)                     │
│  ▶ 2회기 (4/16)                     │
│  ▶ 1회기 (4/9)                      │
└─────────────────────────────────────┘
```

| 규칙 | 설명 |
|------|------|
| 발행 기반 공개 | 상담사가 "발행"해야만 내담자에게 노출. 작성 중 초안은 비공개 |
| 노트 도착 알림 | 새 노트 발행 시 홈에 알림 카드 + 푸시 알림 |
| 아코디언 구조 | 최신 회기 자동 펼침, 이전 회기 접힘 |
| 2개 섹션 | 회기 요약 (진행 내용 + 반응) + 실천 사항 |

### 6-5. AI 인사이트 (Phase 3)

> 상담사 노트 + 내담자/보호자 기록을 종합하여 자동 생성되는 진행 상황 요약.

```
┌─────────────────────────────────────┐
│  🤖 AI 인사이트                      │
│                                     │
│  "감정을 언어로 표현하는 빈도가      │
│   최근 3주간 늘고 있어요.            │
│   특히 '화나다' 외에 '속상하다',     │
│   '답답하다' 같은 표현이 새로        │
│   나타났어요."                       │
│                                     │
│  최근 기록 5건 · 회기 노트 2건 기반  │
└─────────────────────────────────────┘
```

| 항목 | 설명 |
|------|------|
| 위치 | 진행 현황 탭 — 타임라인 상단 |
| 데이터 소스 | 상담사 노트 + 보호자/내담자 기록 |
| 내용 | 구체적 변화 언급 + 눈에 띄는 진전 포인트 |
| 목적 | 타임라인 스크롤 전 "지금 어디쯤인지" 한눈에 파악 |
| 개인정보 | AI 처리 시 개인정보 처리 방침 명확화 필요 |

### 6-6. 회기 비교 뷰 (Phase 2)

> "정말 나아지고 있나?"에 대한 확신 제공. 1회기 vs 현재를 직관적으로 비교.

```
┌─────────────────────────────────────┐
│  📊 변화 비교 (1회기 → 현재)         │
│                                     │
│  ── 실제 반응 대조 ──               │
│  1회기: "싫어! 안 할 거야!"          │
│  현재:  "좀 쉬고 나서 할게요"        │
│                                     │
│  ── 변화 지표 ──                    │
│  감정 표현    ██░░░░░░ → ██████░░   │
│  상담 참여도  ███░░░░░ → ███████░   │
│  안정 속도    █░░░░░░░ → █████░░░   │
│                                     │
│  ── 키워드 변화 ──                  │
│  ~~싫어~~ ~~안해~~ → 쉬고 할게 괜찮아│
└─────────────────────────────────────┘
```

| 구성 요소 | 설명 |
|----------|------|
| 실제 반응 대조 | 1회기 당시 vs 현재 말/행동 나란히 표시 — 가장 감정적으로 와닿는 형식 |
| 변화 지표 바 | 감정 표현, 상담 참여도 등 항목별 진행 바 시각화 |
| 키워드 변화 | 초기 빈출 단어 vs 최근 단어 대조 (취소선 + 새 키워드 칩) |

## 7. SaaS 연계 (쌍방향 데이터 흐름)

> 마인드엔서는 SaaS(상담센터 플랫폼)와 쌍방향으로 연동된다.

```
┌──────────────────┐                ┌──────────────────┐
│   SaaS (상담사)   │                │  앱 (내담자)      │
│                  │                │                  │
│  미션 설정 ──────────────────→  홈 미션 카드          │
│  상담일지 작성 ──────────────→  전문가 기록 탭        │
│  노트 발행 ──────────────────→  홈 알림 카드 + 푸시   │
│  일정 등록 ──────────────────→  일정 탭 + 홈 요약     │
│  검사 배정 ──────────────────→  검사 진행 현황        │
│                  │                │                  │
│  기록 확인 ←──────────────────  내담자 기록 제출      │
│  (상담 준비)     │                │                  │
└──────────────────┘                └──────────────────┘
```

| SaaS 기능 | 앱 반영 위치 |
|----------|-------------|
| 미션 설정 (회기별) | 홈 — 이번 주 미션 카드 |
| 상담일지 작성 | 상담 상세 — 전문가 기록 (아코디언) |
| 노트 발행 | 홈 — "N회기 요약 노트가 도착했어요" 알림 카드 |
| 일정 등록 | 일정 탭 + 홈 진행현황 요약의 "다음 상담" |
| 검사 배정 | 검사 리스트 및 진행 현황 |

> **연계 원칙**: 상담사가 "발행"해야만 내담자에게 공개. 작성 중 초안은 비공개.
> 내담자가 남긴 기록은 상담사가 SaaS에서 확인하며, 상담 준비 자료로 활용.

### 일정 카드 패턴 (결정됨)

- 정보 위계는 **타이포그래피(크기/굵기)**로만 구분 — 색상 장식 없음

│  [△] △△발달센터 · 검사              │

│  📊 진행현황 (센터별 카드 분리)      │
│                                     │
│  [○] ○○심리센터                     │

│                                     │

|------|------|

| 알림에 센터명 포함 | 다중 센터 시 어느 센터인지 식별 |

## 10. 센터 식별 시스템 (결정됨)

### 아바타 규칙

```
센터 로고가 있는가?
  │
  ├─ YES → 로고 이미지 사용 (32x32, 둥근 사각형)
  │
  └─ NO  → 이니셜 + 자동배정 색상
           예: "해밀심리센터" → 파란 배경에 "해"
               "한결발달센터" → 초록 배경에 "한"
```

| 속성 | 값 |
|------|-----|
| 크기 | 기본 32px, 강조 시 40px |
| 모양 | 둥근 사각형 (border-radius: 8px) |
| 로고 없을 때 | 센터명 첫 글자 + 자동 배정 색상 |
| 색상 풀 | 6~8가지 구분 가능한 색상 순환 배정 |

> **왜 default 아이콘이 아닌 이니셜+색상인가?**
> 2개 이상의 센터가 모두 default 아이콘이면 구분 불가.
> 이니셜+색상은 로고 없이도 시각적 구분이 가능.

| UX 방향성 (심리 기반) | 부담 최소화, 성취감 강화, 변화 가시화 | §3-3 |
