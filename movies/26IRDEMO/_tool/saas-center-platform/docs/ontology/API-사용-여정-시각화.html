백그라운드 배선 — 도메인이 서로를 부르는 지점

여정 안에 숨어 있던 크로스도메인 연결만 모아 본 것. 앞줄이 뒷줄을 같은 트랜잭션 또는 이벤트 워커로 부른다.

상담 출석 확정─tx→바우처 차감attended·excused만 is_consumed → remaining_sessions−− (여정 3)
청구 생성─tx→바우처 차감BillableItem.client_voucher_id 연결분 소진 — 행/집계가 같은 필터를 보는 단일 tx (여정 5)
센터 승인─tx→7개 모듈 초기화역할·검사·운영시간·구독·크레딧·멤버가 한 트랜잭션 (여정 1)
앱 link claim─tx→CenterLink + 감사전역(Family·Profile) ↔ 테넌트(Client) 다리 + append-only 감사 (여정 2)
검사 응답 제출─tx→엔진 채점플러그인 registry 조회 → 점수·위험도 → report_payload (여정 4)
필드노트 파이프라인─비동기→STT·LLM → 상담일지transcribe→refine→diarize→summarize→note. AI 크레딧 소비 = 구독 플랜 한도와 연결 (여정 3)
모든 도메인 쓰기⚡→이벤트 아웃박스 → 워커emit(events+atomics) → pg_notify → 워커가 독립 tx로 반응 실행 (알림·메일·알림톡)
