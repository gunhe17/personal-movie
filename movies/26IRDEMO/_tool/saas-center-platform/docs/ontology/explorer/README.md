# ⚠ 이동됨 — tools/ontology-explorer

explorer는 Vite + Svelte 5 앱으로 개편되어 `tools/ontology-explorer/`로 이동했습니다.
이 폴더의 index.html·data/는 개편 전 버전(참고용)이며, **데이터 정본은 tools/ontology-explorer/public/data/** 입니다.

(`localhost:3502/ontology-explorer`도 같은 곳으로 리다이렉트됩니다 — 옛 서버 렌더링 콘솔은 이 앱에 흡수됐습니다.)
