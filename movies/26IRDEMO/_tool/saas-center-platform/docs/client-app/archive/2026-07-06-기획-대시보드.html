연결 3경로 (자동 매칭 폐기)

1
문자 편승 초대 주경로 · 직원 노동 제로
이미 나가는 문자(예약·검사·설문)에 토큰 링크 자동 탑재 → 탭 → 전화번호 본인인증(토큰 수신 번호 대조) → 연결. 매칭이 아니라 확인 — 오연결 없음.
2
데스크 QR 현장
센터 특정 상태에서 그 센터 스코프 안에서만 번호 대조. 실패해도 직원이 즉석 해결 — 데드엔드 없음.
3
가족 초대 + 수동 코드 fallback
이미 연결된 보호자(주보호자 `is_primary`)가 아빠·조부모를 앱에서 초대. 센터 노동 0, 대기 0.
토큰 = AssessmentSendLink 선례 재사용 (1회 claim + 본인인증 이중 게이트, 유효기간, 실패 제한, revoke). 목표: 설치 후 1분 안에 첫 할 일이 보이는 홈 도착.

이월빨간 배지·카운트 금지. 카드가 남아있는 것 자체가 상태 표현.

바우처 3층 노출 (07-07 확정)

층위치내용조건
L1 할 일 카드홈"발달재활 바우처 · 잔여 2회 · 8/31까지" — 명사·숫자만, 압박 문구·빨간색 없음잔여 ≤2회 또는 만료 30일 전에만 등장, 해제 시 조용히 소멸
L2 상시 현황마이"내 바우처" — 프로그램명 + 사람 칩 + 잔여 N회/총 M회 + 바 (임박=주황 색 온도만)상주. "몇 회 남았지?"의 상설 답 — 지금은 센터 전화·정부 포털행
L3 상세L1·L2 탭잔여 회기 큰 숫자 + 사용 내역(세션 연결) + 제도 정보(주관·정부 고시 지원금·문의처)출처 표기: "센터 등록 기준 · 정부 잔액은 사회서비스 포털"
미연동센터 찾기 안제도 정보만 노출 + [이 바우처 취급 센터 찾기] → 디렉터리 퍼널 연결앱 레벨 탭 금지(센터 유형 중립 유지) · 카탈로그 신선도 관리 필수
전부 기존 ClientVoucher · Voucher 카탈로그 · BillableItem의 파생 뷰 — 신규 엔티티 없음(상담사 신규 노동 제로). 금액(잔액)은 P1 비노출: 센터 내부 운영값이라 정부 포털 잔액과 어긋나 분쟁 소지. 확장(P1.5+): 재신청 카드 — "2027년 바우처 신청이 시작됐어요", 매년 재신청 놓침 페인 + 센터 문자 안내 노동 대체.
