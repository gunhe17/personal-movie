# 내담자 앱 기획 v5 — 케이스 ③ "서비스 사용 중 (연동)" 확정안 (2026-07-08, 패널 라운드 1~5)

> v5 케이스 드리븐 + 패널 논쟁 방식. ①·② 확정안(같은 날짜 문서)에 이어지는 마지막 케이스.
> **회사 우선순위 최상위 케이스** (SaaS 본진). v4 자산(할 일 카드 인벤토리·토큰 초대·바우처 3층)이 가장 두꺼운 영역이라, 백지 설계가 아닌 **①·②와의 충돌 검증 + 승계** 방식으로 진행.

## 0. 결정 이력 (라운드별)

| R | 쟁점 | 판정 |
|---|---|---|
| 1 | 연동 첫날 홈 | **골격 불변** — 적응형 스택 유지, 센터는 **세 번째 공급원**으로 합류(①=유저+공공, ②=+유저 리듬, ③=+센터). v4 카드 인벤토리 승계: 예약 D-1·휴강/변경·온라인 검사·사전 설문·결과지·바우처 잔여(**이제 진짜 숫자** — ②의 "세 번째 숫자" 문제 자연 해소). 상담사 신규 노동 제로 유지. **원장은 계속 유저 소유** — 연동돼도 홈이 "센터 우편함"이 되지 않음. 세션 마디는 센터 데이터로 **자동 생성**(수동 "다녀왔어요" 불필요). **말씀 담기 트리거**: 연동 직후 신규 유저만 세션 종료 시각 푸시(리추얼 형성기 한정, 중립 문구, 담기 시작하면 조기 소멸) → 이후 홈 프롬프트만. 담기율이 ②보다 낮으면 재론(하윤 단서) |
| 2 | 연결 절차 | v4 **토큰 3경로 승계**(문자 편승 / 데스크 QR / 가족 초대) + v5 신규 둘: **제4경로 역방향 연결 요청** — ①·② 기존 유저가 먼저 요청 → 센터 web에 "연결 요청 N건" → 직원이 명부 확인 후 승인(=초대 발송) → 본인인증. **전화번호 자동 연결 금지 유지**(오연결=개인정보 사고, v4 자동 매칭 폐기 원칙 계승). **기존 계정 합류** — 초대 링크가 새 계정이 아니라 쓰던 계정에 CenterLink 부착, 형제 대비 아이 프로필 확인 단계 포함. ② 유저의 센터가 연동되면 앱이 감지해 연결 제안. 부수효과: 데스크의 "연결 대기 학부모 N명" = 도입 직후 활성화 증거(영업 자산) |
| 3 | 부모→상담사 공유 + **저장 대전환** | 공유 = **"보내기"가 아니라 "보여주기 허용"** — 항목별 공유 토글 → 상담사 SaaS 화면의 그 내담자 "가정 기록" 영역에 조용히 표시. **풀 원칙**: 알림 금지·읽음 표시 금지·응답 무의무 명시(상담사의 새 노동이 되지 않게 — 하윤 조건). **🔴 대전환(대표 발제·확정): 서버 무저장 원칙 폐기** → 영상·녹음·사진 포함 동의 기반 **전체 서버 저장** + 가드레일 4: ① 암호화 ② 접근=본인+항목별 허용 담당자만 ③ **2차 활용(AI 학습 등) 금지** ④ 투명성 한 줄. 사유·상세는 ① 문서 §5 개정 이력. 이로써 폰 변경 생존·가족 공유 성립, 공유는 권한 문제로 단순화 |
| 4 | 다자녀·다중 센터·가족 | 계정→아이 프로필(N)→센터 연결(N) 모델로 **혼합 상태(한 가족 안 ①②③ 공존)가 기본 지원.** 홈은 하나 + 사람 칩(v4 승계, 아이별 앱 전환 없음), **기록 타임라인은 아이별.** 센터 간 격리: 각 센터는 자기 데이터 + 자기에게 공유 허용된 가정 기록만. **가족 공유 = 2등급(대표 확정)**: 관리자(주 보호자 — 가족 초대·내보내기, 공유 토글, 프로필 관리) / 가족 구성원(열람+작성+다녀왔어요·말씀 담기 전부). 열람 전용 3등급은 과잉으로 기각. 분리·이혼 가정 등 분쟁 케이스의 문지기 = 관리자(하윤 현장 요구) |
| 5 | 연동 유저에게 디렉터리 노출 | **절충안 확정**: "다른 영역 알아보기" 유지하되 — ① **첫 결과 = 지금 다니는 센터의 다른 프로그램**("다니시는 센터에도 감각통합이 있어요" — 센터엔 업셀 채널, 원장 반론 무력화) ② **능동 검색에만 열림**(홈 배너·추천·알림으로 타 센터 능동 노출 금지) ③ 같은 영역 검색도 차단 안 함(막으면 가짜 어포던스, 유저는 어차피 밖에서 찾음 — 밀지 않을 뿐). 기각: 전면 숨김(유저 신뢰 붕괴)·센터별 노출 토글(유저가 알면 더 나쁨). 영업 자료에 이 구조 명문화(서연) |

## 1. 케이스 ③의 정체성

**"손으로 하던 것이 자동으로 바뀌고, 내 것은 계속 내 것인 상태."**
센터 운영 데이터(예약·검사·설문·바우처)가 자동으로 흘러들지만, 홈의 주인과 기록의 소유는 유저. ①·②에서 만든 습관(기록·말씀 담기·대기실 리듬)은 연동 후에도 그대로 산다.

## 2. 승계 자산 (v4 → v5 ③)
