# 내담자 앱 기획 v5 — 케이스 ② "센터는 있지만 서비스 미사용" 확정안 (2026-07-08, 패널 라운드 1~3)

> v5 케이스 드리븐 + 패널 논쟁 방식. 케이스 ① 확정안(같은 날짜 문서)에 이어짐.
> **전제 제약(대표): 케이스 ③의 우선순위가 가장 높다** — ②는 독립 제품이 아니라 ③의 미연동 모드. 연동 시 센터 데이터로 대체될 수기 표면은 만들지 않는다.

## 0. 결정 이력 (라운드별)

| R | 쟁점 | 판정 |
|---|---|---|
| 1 | ②의 심장 | **세션 리듬** — 서연의 원탭이 리듬의 시작 동작으로 흡수. 수기 장부(잔여 계산)는 기각: "다녀왔어요" 원탭 = **원장에 마디 찍기**(카운트 아님) → 직후 **"선생님이 말한 것" 메모**(하원 5분 브리핑의 휘발 붙잡기 — 치료 효과의 절반인 가정 연계의 연결고리) + **홈워크 카드**(일주일 홈 상주). 무대 = **대기실 프라임타임**(수업 40분이 입력의 자연 시간대). 다녀온 횟수 표시는 유저 자신의 사실이라 OK, **잔여 회기 계산은 금지**(센터 장부의 영역 — "세 번째 숫자"로 신뢰 붕괴). 일정은 반복 슬롯 1개만(리듬의 시계), **휴강·보강은 정직하게 포기** — 그 불편이 연동 전환의 동력. 관찰기록·촬영 가이드는 ①에서 연속 |
| 2 | 노이즈 마케팅 (대표 발제) | 골격 = **"말하게 하지 말고 보이게 하라."** 유저를 영업사원으로 만들지 않고, 정당한 사용 행위가 노출이 되게: ① 초진 정렬 화면을 치료사에게 보여주는 순간 ② "선생님이 말한 것" 메모를 보여주는 순간 ③ 대기실 어깨너머. **[센터에 소개장 보내기]** = 치료사가 먼저 물었을 때 받아주는 장치(조르기 금지 — 트리거는 센터 불만이 아니라 치료사의 관심). **③ 프리뷰는 상시 배너 금지, 아픈 순간 원샷**(대표 판정): 대리 신호 트리거(슬롯 수동 이동·취소, 종이 결과지 사진 붙임, 횟수 화면 빈발) + 쿨다운 월 1회 + 센터 탓 금지 톤("여긴 안 돼요" ❌ "이렇게 될 수도 있어요" ⭕) |
| 3 | 워크스루 구멍 | **진입 분기 3갈래**: "다니는 센터가 있어요" → 센터 검색 → (a) 연동 센터 → ③ 온보딩으로 (b) 미연동 → ② 모드 (c) 미등재 → 수기 등록 + ② 모드. (a)에서 초대 못 받은 유저의 "연결 요청"은 ③ 접합부로 이월. **종이 문서(평가 보고서 등) 사진 붙이기** — 영상 패턴 재사용(저장은 07-08 ③R3 개정으로 서버 — ① 문서 §6 참조), 원장에 마디로. **디렉터리는 유지하되 프레임 전환(대표 판정)**: "센터 찾기" → **"다른 영역 알아보기"**(병행 니즈 — 언어+감통+놀이 병행이 발달 표준). 환승 조장 인상 제거. 연동(SaaS 고객) 센터 학부모에 대한 노출은 ③에서 재론(하윤 폭탄 경고) |

## 0-1. 보강 (07-08 오후, 대표 발제)

- **"선생님 말씀 담기"** — 하원 5분 브리핑을 붙잡는 기능. **녹음이 기본, "직접 적기"가 폴백**(같은 슬롯). 양해 프레임 내장(시작 화면에 "선생님께 '잊어버릴까 봐 담아둘게요'라고 말씀드려 보세요"), **은밀·백그라운드 녹음 모드 절대 금지**(치료사 레드라인). STT·AI 요약은 AI 프로덕션 승인 후. 당사자 간 녹음은 합법이나 치료사 방어 발화(칠링 이펙트)가 리스크 — 양해 프레임이 그 답.

## 1. 케이스 ②의 정체성

**"매주의 5분을 붙잡는 곳."** 센터가 데이터를 안 주는 상태에서, 연동돼도 센터가 절대 대체 못 하는 것(부모의 기록·선생님 말·홈워크 실행)만으로 산다. ①의 "기다림을 자산화"가 ②에선 "세션 리듬"이 된다. 앱을 잘 쓰는 것 자체가 미연동 센터에 대한 조용한 노이즈 마케팅.

## 2. 홈 (② 모드)

- 스택: 홈워크 카드(1주) / 세션 당일 "다녀왔어요" → 선생님 말 메모 / 관찰기록·촬영 가이드(① 연속) / (원샷) 연동 프리뷰
- 고정 진입점: 내 기록(원장) / 다른 영역 알아보기(디렉터리) / [센터에 소개장 보내기](마이 쪽, 저자세)
- 죄책감 금지·해석 무음·달력 뷰 금지 등 ① 원칙 전부 연속
