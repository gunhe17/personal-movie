# 마인드엔서 — 설계 원칙

> 기존 기획서의 가정을 제1원칙으로 재검토한 결과

---

## 1. 해체된 가정

| 기존 가정 | 결론 |
|---|---|
| 앱이니까 하단 4탭이 필요하다 | 핵심 정보는 하나의 흐름 → 2탭(홈+마이)으로 충분 |
| 홈/일정/기록/마이 구조가 표준이다 | "언제 가지 → 뭘 하지 → 뭐 했대 → 어디쯤이지"는 분리할 이유 없음 |
| 미소속 유저에게도 풍부한 화면이 필요하다 | 핵심 가치는 센터 연결 후. 미소속 화면은 최소한으로 |
| 대시보드가 필요하다 | 사용자가 원하는 건 "다음에 뭘 하면 되지?"에 대한 답 |

---

## 2. 핵심 결정

### 사용자 경험은 동일하다

성인 내담자와 보호자의 앱 경험은 같다. 별도 역할 선택, 분기된 화면 없음. 다중 자녀/다중 센터 모두 통합 표시 (전환 없음).

### 정보 우선순위

앱을 열었을 때 위에서 아래로:

| 순위 | 정보 | 사용자 질문 |
|---|---|---|
| 1 | 캐릭터 멘트 | — (감성적 첫인상) |
| 2 | 다음 일정 (진행 바 포함) | "언제 가지? 어디쯤이지?" |
| 3 | 미션/성장 가이드 (Phase 2) | "그때까지 뭘 하지?" |
| 4 | 콘텐츠 | — (태그 기반 맞춤 추천) |

### 다중 센터/자녀 통합

사용자는 센터 단위로 생각하지 않는다. "이번 주에 뭐가 있지?"로 생각한다.

| 영역 | 통합 방식 |
|---|---|
| 일정 | 전체 시간순 합산 (자녀 이름 + 센터명 라벨) |
| 진행현황 | 자녀별 분리 (치료 맥락이 다르므로) |
| 콘텐츠 | 통합 (태그 기반 매칭) |

---

## 3. 디자인 방향

### 키워드

풍부한 콘텐츠 + 시각적 화려함 + 재미 요소 + 높은 직관성. 단순한 관리 도구가 아닌, 열 때마다 눈이 가고 손이 가는 앱.

### 적용 요소

| 요소 | 적용 | 비고 |
|---|---|---|
| 캐릭터 (오브) | 전체 | 가이드형, Phase 2에서 AI 연결 |
| 마이크로 인터랙션 | 전체 기본 | 진행 바 애니메이션, 카드 전환, 숫자 카운트업 |
| 감성 비주얼 | 포인트만 | 시간대별 톤 변화 (홈 상단), 계절감 |
| 게이미피케이션 | 제외 | 상담 맥락에서 배지/레벨은 부자연스러움 |

### 다크 모드

MVP 포함. 오브 캐릭터가 빛 기반이라 다크 모드에서 시너지.

- 라이트: 밝은 배경 + 은은한 오브 → 차분하고 깨끗한 느낌
- 다크: 어두운 배경 + 빛나는 오브 → 몰입감, 감성적

### 접근성

| 항목 | 결정 |
|---|---|
| 폰트 크기 | 시스템 설정 따름 + 최대 상한선 (레이아웃 보호) |
| 한 손 조작 | 주요 액션 버튼 하단 배치 |
| 인지 부하 | 최소화 (우울/불안 상태 내담자 고려) |

### 브랜드 톤

| 원칙 | 설명 |
|---|---|
| 심리센터 앱처럼 보이지 않게 | 건강관리/일정 앱 느낌 |
| 정보 위계는 타이포그래피로 | 크기/굵기/여백으로 구분 (색상 장식 아닌) |

### 피해야 할 것

"상담", "심리", "내담자" 워딩 직접 노출 / 파스텔 보라/핑크 색상 / 의미 없는 그라데이션/장식

## 4. 사용자 심리 특성

### 보호자

| 특성 | 양상 |
|---|---|
| 높은 불안 | 치료 효과를 지속적으로 의심. 아이 문제 인식에서 오는 죄책감 |
| 불확실성 민감 | 상담 내용을 알 수 없는 상황에서 오는 불안 |
| 과도한 책임감 | "내가 더 잘해야 한다"는 압박감 |
| 변화에 예민 | 작은 변화도 의미 부여. 나아지고 있다는 확신 필요 |

### 성인 내담자

| 특성 | 양상 |
|---|---|
| 진전 감각 갈망 | 변화가 눈에 보이는 증거 필요 |
| 자기 관리 의지 | 상담 외 일상에서 실천하고 싶지만 방법 모름 |
| 프라이버시 민감 | 심리 관련 앱이 타인에게 보이는 것에 대한 거부감 |

### UX 방향성

| 원칙 | 적용 |
|---|---|
| 부담 최소화 | 짧고 단계적 기록, 긴 입력 폼 대신 선택 → 텍스트 |
| 성취감 강화 | 기록 완료 시 즉각적 피드백 |
| 전문가 권위 활용 | 상담사 이름과 노트 전면 배치 |
| 변화 가시화 | 타임라인, 진행 표시 등 진행이 보이는 구조 |
