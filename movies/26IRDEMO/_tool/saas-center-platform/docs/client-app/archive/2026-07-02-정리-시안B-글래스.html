북극성은 화면이 아니라 자산 — 부모가 소유하고, 센터를 초월하며, 이동 가능한 상담·발달 여정의 원장(Ledger).

북극성 · 여정 원장 킬러 · 세션 브리핑 성장 · 수직 풀 루프 비치헤드 · 아동 발달 코어는 전 센터 범용
01

북극성 — 여정 원장

현실의 치료 기록은 센터에 갇혀 있다. 센터를 옮기면 리셋되고, 부모는 결과지 종이 뭉치를 들고 새 센터에서 히스토리를 처음부터 다시 구술한다. 원장은 이 구조를 뒤집는다.

NORTH STAR

"내 상담·발달 여정의 원장"
— Profile 소유 · 센터 초월 · 이동 가능

아동 발달의 "아이 여정"은 이것의 한 인스턴스일 뿐. 코어 구조는 모든 상담센터 유형에 중립이다.

📦

Intake 지옥 해소

새 센터 첫 방문 = "여정 공유" 한 번. 종이 뭉치와 재구술의 끝.

🔓

키즈노트도 못한 것

키즈노트 기록은 원 귀속 — 졸업하면 끝. 우리는 Profile(유저) 소유라 구조적으로 가능.

🔁

파급 2차 엔진

새 센터에 우리 포맷의 여정 도착 → "이 시스템 뭐지" → SaaS 가입 압력.

⚓

센터 종속 탈피

센터 이탈 ≠ 앱 이탈. 쌓인 기록 자산이 앱에 남을 이유.

Account

폰 주인 · 로그인 · 알림 (1개)

Profile — 원장의 주인

나 / 첫째 / 둘째 (N개 · 유저 소유)

CenterLink

코드 연결 · 공유 토글 (Profile당 N개)

Client

센터의 연락처 레코드 (센터 소유)

유저 소유 층

원장·관찰기록 — 센터와 무관하게 존속. CenterLink 없는 Profile = 미연동 모드의 실존 유저.

연결 층

코드 연결 = CenterLink 생성. 센터 이동 = 링크 교체, Profile·기록은 유지.

센터 소유 층

예약·검사·결제 — 센터의 발행·설정으로만 노출 (소유자 통제 대칭).

04

퀘스트 슬롯 — F12의 재배치

F12 "AI 성장 가이드"는 Phase 3 구석에 붕 떠 있었다. 퀘스트는 브리핑 2번 칸의 진화형, 인사이트·회기 비교는 원장 위의 뷰. 슬롯은 최종형 기준으로 설계, 콘텐츠만 3단 진화.

V3 · 연구 검증 후
Phase 2

🛡️ 게임 문법 가드: 스트릭·실패 표시·미완료 리마인더 금지. 완료는 가볍게 축하, 미완료는 침묵.

06

여섯 개의 원칙

논의 전체에서 반복 적용된 불변식. 이후 모든 화면·문구·기능 판단의 기준.

🚫

원본 미러링 금지

케이스노트·가설·평가어는 내담자 비노출. 큐레이션 뷰만.

🔐

소유자 노출 통제

유저 데이터는 유저가(링크 토글), 센터 데이터는 센터가(발행·설정).

⚖️

부재의 비대칭

미가입의 빈자리는 가시화(성장 레버), 가입 센터의 비공개는 침묵(고객 존중).

🕶️

디스크리트

잠금화면 기본 중립 문구 — 아이명·센터명·치료종류 비노출. "마인드스코프" = 웰니스 중립 통과.

🎛️

가짜 어포던스 금지

없으면 안 그린다 — 빈 스위처·버튼·위젯 없음. 스트림이 편차 흡수.

🕊️

죄책감 메카닉 금지

스트릭·실패·미완료 압박 없음. 완료는 축하, 미완료는 침묵.

08

Phase 컷라인 — 3면 동시

Phase 1은 앱 하나가 아니라 세 표면 — 브리핑이 킬러인 이상 발행 경로와 노출 통제는 줄일 수 없다. P1 = 원장에 벽돌이 쌓이기 시작하는 최소 구성(AI 없이 성립), 양방향은 전부 P1.5.

PHASE 1 — 첫 출시

원장 가동

내담자 앱 (마인드스코프)
  • 통합 홈 · 적응형 히어로 · 필터 칩
  • 세션 브리핑 수신 (v1 수기)
  • 관찰기록 (입력·열람)
  • 자녀 허브 = 여정 스트림 + 퀘스트 슬롯
  • 결과지 PDF · 일정 · 마이
  • 미연동 모드 + [우리 센터에 알리기]
  • 알림 (기본 중립)
상담사 모바일
  • 필드노트 완료 → 브리핑 원탭 발행
SaaS Web
  • 노출 설정 (회기·결제 토글)
  • 초대코드 발송 · 승인 큐
  • 브리핑 보완 발행·수정
PHASE 1.5 — 양방향

루프 완성

  • 관찰기록 공유 토글 + 상담사 수신 뷰
  • 퀘스트 완료 체크 → 상담사 회신
  • AI 브리핑 초안 (승인 후 스위치 온)
  • 센터 리드 신호 ("보호자 N명 연동 요청")
PHASE 2+ — 확장

세그먼트 & AI

  • 무소속(세그먼트 1) 마켓·디렉터리

  • 예약 변경·취소 write
  • 성인 세그먼트 벽돌 (별도 설계)
  • F12 인사이트 · 회기 비교 · 성장 리포트
09

미해결 — 열려 있는 것

대표님 정렬

스토리: "화려한 앱 = SaaS 영업사원" — 내담자가 센터 도입을 끌어당기는 압력 장치이자 AI 차별화. 세련됨 + 티 안 남이 화려함 요구의 완성.
