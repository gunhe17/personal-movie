## 1. 논의의 흐름 (어떻게 여기까지 왔나)

1. **키즈노트 통찰** (사용자): SaaS(원 효율) + 앱(보호자 관찰) + **"다른 유치원은 쓰던데요" 파급**. 세그먼트 2(소속인데 센터가 SaaS 미가입) 공략 제안.
2. **스티그마 반문** (사용자): 발달센터는 "다닌다"는 말 자체가 부담 → 수평 전파 부러짐.
3. **캐리어 교체**: 파급의 주체 = ①병행 보호자(발달은 2~3센터 병행 표준, 자기 관계 안 수직 풀이라 스티그마 비용 0) ②센터 이동자 ③익명 커뮤니티.
4. **초기 타깃 = 아동 발달** (사용자 확정). 단 **모든 상담센터가 대상, 아동 발달은 비치헤드** — 코어 구조는 항상 센터 유형 중립 (사용자 반복 강조).
5. **수기 일정 격하** (사용자): 발달 일정은 고정 반복이라 등록 가치 얇음 → 일정의 진짜 가치는 **예외(변경·휴강)** = 연동만 가능.
6. **"센터가 써야만 모두 윈윈" 재정향** (사용자) → **세션 브리핑** 도출.
7. **퀘스트** (사용자): 세션 후 AI가 가정 활동을 퀘스트로 제공 = 기존 F12 AI 성장 가이드 §2. 연구 필요라 구현은 나중, **UI/UX 구조는 지금**.
8. **북극성 승격**: 기능들의 공통 구조 = **여정 원장(ledger)**.

## 2. 확정 사항

### 북극성
> **"내 상담·발달 여정의 원장"** — Profile 소유 · 센터 초월 · 이동 가능.
- Intake 지옥 해소("여정 공유" 한 번) / 키즈노트도 못한 것(기관 귀속 아님) / 파급 2차 엔진(새 센터에 우리 포맷 도착) / 센터 이탈 ≠ 앱 이탈.
- F12 재배치: 퀘스트 = 브리핑 2번 칸의 진화형, 인사이트·회기비교·리포트 = 원장 위의 뷰(P2+).

### 킬러 = 세션 브리핑
- 페인: 40분 치료 → **10분 구두 브리핑**만. 절반 증발, 아빠 픽업 날은 0. 보호자는 치료실 안을 못 봄 → 브리핑 = 창문 (키즈노트 사진의 구조적 등가).
- 파이프라인: 필드노트(기존) → [AI 초안 v2] → 상담사 검토 → **모바일 필드노트 완료 화면에서 원탭 발행**(주경로) / web 보완.
- **3칸 템플릿**: ①오늘 한 활동(사실만) ②집에서 해볼 것(=퀘스트 슬롯) ③다음 세션(자동 프리필). **평가어 제외**.
- **v1 = AI 없이 수기 30초 출시** → AI 승인 후 스위치 온. 파급 루프를 승인 일정에 인질 잡히지 않게.
- 퀘스트 3단 진화: v1 텍스트 → v2 AI 초안 → v3 구조화(연구 검증 후). 슬롯은 최종형 기준 설계.

### 홈·허브 (오전 D1·D2 개정)
- **축은 시간 하나, 사람·센터는 태그.** Profile 전환기 폐기 → **가족 통합 타임라인 + 필터 칩**(2개↑일 때만) + 드릴다운.
- **적응형 히어로 4단**: ①새 브리핑(미열람~24h) ②임박 예약(D-1↓) ③다음 예약 ④예약 없음 변형. 슬롯 1개, 아래 구조 불변.
- **자녀 허브 = 여정 스트림형** (원장이 보이는 화면): 진행 중 활동 → 시간 역순 스트림(타입 필터: 전체/브리핑/내 기록/검사) → 연결 센터. [공유] = intake·2차 엔진.

### 미연동 모드 (세그먼트 2 착지, 오전 D3·D5 개정)
- **관찰기록이 주인공** (입력·열람 = P1, 전달·공유 토글 = P1.5). 발달 보호자의 기록은 목적지(다음 세션)가 있어 "허공" 아님.
- 블러 브리핑 프리뷰("연결되면 이렇게 와요") + **[우리 센터에 알리기]** → 익명 집계 리드("보호자 N분 연동 요청").
- 수기 일정은 보조 (미연동 회색 슬롯 = 풀 압력 가시화 장치).

### 온보딩
- **게스트 없음** — 원장은 계정 귀속. 소셜로그인 → "초대코드가 있나요?" 분기.
- 있음: 코드(딥링크 자동) → OTP → 자동 매칭(실패 시 센터 승인 큐, 사유 비노출) → **연결 완료 화면에서 "이 센터가 주는 것" 긍정문 안내**.
- 없음: 프로필 만들기(아이/나) → 미연동 홈.

### 알림
- 푸시: 브리핑 / **예약 변경·휴강(최긴급)** / D-1 리마인더 / 검사 요청 / 결과지 발행. **퀘스트 리마인더 금지.**
- **기본 중립 문구** (디스크리트): 잠금화면에 아이명·센터명·치료종류 비노출, 옵트인 상세. 서비스명 **마인드스코프** = 웰니스 중립이라 통과.

### 센터별 정보 이질성
- 이벤트 스트림이 편차 흡수 (부재는 안 그림 = 가짜 어포던스 금지의 센터 단위 적용).
- **소유자 노출 통제 대칭**: 유저 데이터 = CenterLink 토글 / 센터 데이터 = 발행·설정. 일정=연동 기본, 결과지=발행제, 회기·결제=센터 토글 1개.
- **부재의 비대칭**: 미가입 빈자리 = 가시화(성장 레버) / 가입 센터 비공개 = 침묵(고객 존중).

### 6원칙
원본 미러링 금지 · 소유자 노출 통제 · 부재의 비대칭 · 디스크리트 · 가짜 어포던스 금지 · **죄책감 메카닉 금지**(스트릭·실패·미완료 압박 없음).

### Phase 컷라인 (3면 동시)
- **P1 (원장 가동)**: [앱] 통합 홈·적응형 히어로 / 브리핑 수신(v1 수기) / 관찰기록 / 자녀 허브 스트림+퀘스트 슬롯 / 결과지 PDF·일정·마이 / 미연동 모드+알리기 / 중립 알림. [상담사 모바일] **필드노트 완료 → 브리핑 원탭 발행**. [web] 노출 설정 토글 / 초대 발송·승인 큐 / 브리핑 보완 발행.
- **P1.5 (양방향)**: 관찰기록 공유+상담사 수신 뷰 / 퀘스트 완료 체크 회신 / AI 브리핑 초안 / 리드 집계 신호.
- **P2+**: 무소속 마켓 / 구조화 퀘스트 v3 / 예약 write / 성인 벽돌 / F12 뷰.
