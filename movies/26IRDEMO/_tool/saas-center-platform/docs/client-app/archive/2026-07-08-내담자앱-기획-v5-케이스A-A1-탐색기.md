> **v5 = 케이스 드리븐 재구성 + 패널 논쟁 방식.** 기능 축(v4)이 아니라 사용자 상황 축으로 진행하며, 각 쟁점은 패널(기획자·UX·치료사·개발자·실사용자)이 논쟁하고 대표가 판정한다.

> 기존 자산(3층 모델·죄책감 금지·토큰 초대·바우처 3층·따뜻하되 글 최소)은 재료로 흡수하며, 배치되는 경우 이 문서가 우선한다.

## 1. 케이스 ①의 정체성

**"다음 한 걸음을 알려주는 것."** 정보(목록·콘텐츠)가 아니라 행동 대본 — 막막함을 걸음으로 바꾼다. 여정은 센터 등록 전부터 시작되고, 그 기록은 이후 원장의 프리퀄이 된다.

페르소나 기준점(패널 실사용자 "지민맘"): 38세 워킹맘, 5세 아이가 어린이집에서 "언어가 좀 느린 듯" 언질. 밤에 맘카페를 몇 시간 읽지만 전화는 못 함("전화하면 진짜가 되는 것 같아서"). 육아 기록 앱 3회 삭제 경험(빈칸 죄책감). 기록은 카톡 '나에게 보내기'.

## 2. 흐름 (확정 골격)

```
설치 → "지금 어느 쪽에 가까우세요?" (게스트)
 ├─ 지켜보고 있어요 → [걱정 단계 홈]
 │    · 관찰기록(한 줄+영상, 촬영 가이드) — 첫 기록 시 소셜 가입
 │    · 공공 선별 안내 (3갈래 분기)
 │    · 바우처 정보 입구 (안도 톤)
 │    └─ 디렉터리 탐색·찜 시작 → 자동 승격 ↓
 ├─ 알아보고 있어요 → [알아보기 단계 홈]
 │    · 행동 대본: "이번 주 두 군데 전화 — 물어볼 것은 이것" (전화 스크립트)
 │    · 디렉터리 2층 (공공 바우처 명단 + 조용한 수집)
 │    · 전화 끝 한 줄 → 다시 확인 리마인더
 │    · 공백기 적응형 홈: 임박 리마인더 > 기록 (촬영 가이드로 기다림을 자산화)
 │    └─ 초진 확정 → D-day + 초진용 정렬 화면(기록 시간순 한 장)
 └─ 다니는 센터가 있어요 → 케이스 ②/③으로
```

## 3. 원칙 (케이스 ①에서 추가·강화된 것)

- **해석 무음**: 기록이 몇 백 개 쌓여도 앱은 판정 뉘앙스 금지. "괜찮아 보여요"(거짓 안심)가 겁주기보다 위험 — 치료사 감수 원칙
- **죄책감 금지의 기록 버전**: 빈도 무요구, 달력 뷰 금지(구멍을 보여주는 장치), 빈칸 개념 없음
- **후기 절대 금지** 유지. 차별화는 팩트(공공 명단 + 훗날 익명 집계)와 행동 대본
- **자유 텍스트 수집 금지**(크라우드소싱): 감정이 흘러들 입력창 자체를 안 만든다

## 5. 개정 이력

- **07-08 케이스 ③ 라운드 3 (대표 확정): 서버 무저장 원칙 폐기 → 동의 기반 전체 서버 저장 + 가드레일 4.**
