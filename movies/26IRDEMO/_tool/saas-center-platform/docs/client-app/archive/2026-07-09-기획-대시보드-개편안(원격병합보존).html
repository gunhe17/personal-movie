내담자 앱 기획 대시보드

막막한 부모에게 "지금 할 한 가지"와
그동안의 기록을 모아주는 앱

상담·발달 센터에 다니는 중이거나 알아보는 중인 보호자·내담자를 위한 모바일 앱. 본업은 센터용 SaaS이고, 이 앱은 그 센터의 고객에게 준다. 최종 목표는 센터와 연동된 상태(상황 ③)이지만, 연동 전에도 앱이 혼자 설 수 있게 설계했다.
기준일 2026-07-08 · 설계는 대부분 확정, 화면 시안·문구는 진행 중 · 상세 근거는 맨 아래 확정안 문서
01 — 기본 뼈대

한 앱인데, 사용자 상황에 따라 홈이 달라진다

첫 실행 때 한 번만 물어 시작점을 정하고, 이후엔 사용자의 행동(센터 찜·등록·연동)에 따라 자동으로 넘어간다. 카드를 눌러 상황별로 홈 구성과 이전 대비 무엇이 달라지는지 확인하세요.

상황 ①
센터가 처음이에요
발달이 걱정되기 시작했거나 상담을 알아보는 중. 다니는 센터 없음.
자세히 ▾
상황 ②
다니는데, 미연동
주 1~2회 다니는 중. 센터가 우리 프로그램을 안 써 데이터가 안 내려온다.
자세히 ▾
상황 ③ · 회사 최우선 ★
다니는 센터가 연동됨
센터 운영 데이터가 앱으로 자동 내려온다. ②의 전부 + 센터가 주는 것.
자세히 ▾
이런 사람
발달 걱정이 시작됐거나 상담을 알아보는 중. 아직 다니는 센터가 없다.
홈에 뜨는 것
관찰 기록무료 검사 안내바우처 정보센터 찾기(지도)전화 도우미
데이터 출처
전부 사용자가 직접 만든다. 게스트로 둘러보기 → 첫 저장(기록·찜·알림) 때 소셜 로그인.
이 단계의 역할
  • ＝ 아직 시작점. 앱은 "다음 한 걸음"만 알려준다 — 판정도 콘텐츠도 아닌 행동 안내.
이런 사람
주 1~2회 다니는 중. 센터가 미연동이라 앱에 데이터가 안 내려온다.
홈에 뜨는 것
다녀왔어요 체크선생님 말씀 담기숙제 카드종이 결과지 보관관찰 기록 (이어받음)
데이터 출처
여전히 사용자가 직접. 센터 데이터 없음.
상황 ① 대비 달라진 점
  • ＋ 수업 중심 기능 등장 — 다녀왔어요·선생님 말씀 담기·숙제 카드
  • ↻ "센터 찾기" → "다른 영역 알아보기"로 명분 전환(여러 영역 병행이 흔해서)
  • ＋ 연동 안내(소개장 보내기) 등장 — 이 센터를 SaaS 고객으로
이런 사람
다니는 센터가 우리 프로그램을 쓴다(연동). 회사 입장에서 가장 중요한 상황.
홈에 뜨는 것
②의 전부 (이어받음)예약·휴강 알림온라인 검사·설문결과지바우처 잔여 (진짜 숫자)
데이터 출처
센터 데이터가 세 번째 공급원으로 자동 합류. 전화번호 본인인증으로 센터와 연결.
상황 ② 대비 달라진 점
  • ＋ 센터가 자동으로 주는 것 등장 — 예약·검사·설문·결과지·바우처 실제 숫자
  • ↻ "다녀왔어요" 수동 체크 → 자동 생성(센터 데이터로)
  • ＋ 남은 횟수가 진짜 숫자로 표시 가능(①②에선 금지였던 것)
  • ＋ 부모→상담사 공유 · 가족 공유 · 여러 아이/센터
  • ＝ 기존 기록 습관은 그대로, 손으로 하던 것만 자동으로.
02 — 왜 이 앱인가

부모가 겪는 문제, 앱은 이렇게 푼다

기획의 출발점은 "지친 30~40대 부모가 실제로 겪는 막막함"이다. 각 문제에 대응하는 해결이 곧 이 앱의 기능이 된다.

문제
"우리 아이 괜찮나?" 밤새 검색·맘카페만 보고 아무것도 못 한다.
→
해결
지금 할 한 가지만 — 관찰 기록(글+영상), 공공 무료 발달검사 안내, 치료비 지원 정보.
문제
전화하면 진짜가 될까 봐 겁나고, 걸어도 대기가 길어 잊어버린다.
→
해결
전화 도우미 — "물어볼 것" 목록 + "언제 다시 확인?" 한 줄 → 그 날짜 알림.
문제
어느 센터가 좋은지 모르겠고, 후기는 믿을 수가 없다.
→
해결
센터 찾기(지도) — 정부 공개 바우처 기관 명단이 기본. 리뷰·후기는 넣지 않는다(운영 리스크).
문제
선생님이 수업 후 5분 설명해주는데, 집에 오면 다 까먹는다.
→
해결
선생님 말씀 담기 — 녹음 기본/메모 대안. "잊어버릴까 봐 담아둘게요" 양해 프레임 내장.
문제
미연동 센터라 앱에 데이터가 안 내려온다. 남은 횟수도 헷갈린다.
→
해결
직접 남기기 — 다녀왔어요·숙제·종이 결과지 사진. 단, 남은 횟수는 앱이 계산 안 함(센터 장부 영역).
문제
육아 기록 앱은 빈칸·연속기록으로 죄책감만 줬다. 그래서 지웠다.
→
해결
채근하지 않는 설계 — 빨간 배지·스트릭·빈 달력 없음. 안 하면 조용히 사라진다.
문제 (회사)
연동 안 된 센터를 어떻게 우리 SaaS 고객으로 만들까?
→
해결
아쉬운 순간에만 [센터에 소개장 보내기]. 조르는 구조가 아니라 관심을 받아주는 구조. 연동되면 손으로 하던 게 자동으로 바뀐다.
03 — 흐름

한 사람의 여정으로 보는 전체 흐름

38세 워킹맘, 5세 아이가 어린이집에서 "언어가 좀 느린 듯"이라는 말을 들은 상황을 기준으로 잡았다. 왼쪽에서 오른쪽으로, 상황이 바뀌어도 기록은 계속 이어진다.

상황 ①
걱정 시작
밤마다 검색·맘카페. 아직 전화도 못 함.
앱: 관찰 기록 시작 · 무료 검사 안내 · 지원 정보
→
상황 ①
알아보기
센터를 찾기 시작, 전화를 돌린다.
앱: 센터 지도 · 전화 도우미 · "5월에 다시" 알림
→
상황 ①
첫 방문
대기 몇 주간 기록이 쌓임. 초진이 잡힘.
앱: 그동안의 기록을 시간순 한 장으로 정리
→
상황 ②
등록 · 매주
주 1회 언어치료(센터는 미연동). 대기실이 앱 쓰는 시간.
앱: 다녀왔어요 · 선생님 말씀 담기 · 숙제 카드
→
상황 ③
연동 후
센터가 우리 프로그램 도입. 습관은 그대로, 손으로 하던 것만 자동.
앱: 예약·휴강 알림 · 검사·결과지 · 바우처 잔여
흐름 요약: ① → (센터 등록) → ② 또는 ③ · ②의 센터가 우리 프로그램을 도입하면 ③으로 승격 · 상황이 바뀌어도 사용자의 기록은 전부 이어진다.
04 — 만들 것

상황별로 필요한 기능

각 항목이 화면·기능 하나. 별도 표기 없으면 전부 설계 확정 상태. 한 줄 정의만 두었고, 세부 규격·근거는 맨 아래 확정안 문서에 있다.

상황 ① — 센터가 처음
  • 시작 질문첫 실행 3택으로 시작점 결정
  • 관찰 기록글 한 줄 + 사진/영상, 촬영 가이드
  • 무료 검사 안내공공 발달검사, 상황 3갈래
  • 치료비 지원 정보바우처 제도 + 신청기간 알림
  • 센터 찾기(지도)정부 공개 기관 명단 기본
  • 전화 도우미질문 목록 + 다시 확인 알림
  • 첫 방문 준비D-day + 기록 시간순 정리
상황 ② — 미연동
  • 센터 등록 분기검색 → ③절차 / ②모드 / 직접입력
  • 수업 일정"매주 화 4시" 반복 1개만
  • 다녀왔어요 체크한 탭 → 세션 생성 (횟수 계산은 안 함)
  • 선생님 말씀 담기녹음 기본 / 메모 대안
  • 숙제 카드일주일간 홈 상주
  • 종이 문서 보관보고서 사진 첨부
  • 연동 안내아쉬운 순간에만 + 소개장 버튼
상황 ③ — 연동 (진행 중)
  • 센터 자동 수신예약·휴강·검사·설문·결과지·바우처
  • 세션 기록 자동화"다녀왔어요" 자동 생성
  • 센터 연결 절차문자 링크 + 본인인증 / 요청→승인
  • 부모→상담사 공유"보여주기 허용" 스위치
  • 여러 아이·센터홈 하나, 기록은 아이별
  • 가족 공유권한 2등급(관리자/구성원)
  • 상담사가 보내주는 것⏸ 다음세션 요약·과제 발행
05 — 지켜야 할 것

어느 화면에서도 어기면 안 되는 규칙

공통 뿌리는 하나 — "이 앱은 사용자를 채근하지 않고, 아이를 평가하지 않는다." 이걸 어기면 부모가 앱을 지운다.

죄책감 장치 금지
금지: 빨간 배지·미완료 개수·연속기록(스트릭)·빈 달력. 할 일은 때 지나면 조용히 사라진다.
아이를 평가하지 않는다
금지: "괜찮아 보여요/걱정되네요" 판정 뉘앙스 일체. 거짓 안심이 최악. 해석은 사람(전문가) 몫.
남은 횟수는 계산 안 함
횟수는 센터 장부의 영역. 앱이 계산하면 숫자가 어긋나 신뢰가 깨진다. 연동(③)에서만 진짜 숫자.
몰래 녹음 금지
말씀 담기는 항상 양해 프레임. 몰래 녹음 모드는 절대 제공하지 않는다.
글은 최소, 숫자·명사로
공감 문구는 화면당 1문장. 형용사보다 명사·숫자("잔여 2회", "0.8km"). 훈계·응원 강요 금지.
해당 없으면 아예 안 보이게
바우처 없는 사용자에겐 바우처 영역 자체가 안 뜬다. 빈 상태로 보여주지 않고 표면을 없앤다.

  • 🔒민감정보 동의 — 영상·녹음 서버 저장 전환에 따른 온보딩 동의.
