# F11. 전문가 노트

> 상담사가 회기 후 작성한 요약 노트를 내담자/보호자에게 제공

**Phase**: Phase 2

---

## 유저 스토리

- 보호자로서, 오늘 상담에서 무슨 이야기가 있었는지 알고 싶다
- 보호자로서, 상담사가 알려주는 실천사항을 다시 확인하고 싶다
- 상담사로서, 공개할 준비가 된 내용만 내담자에게 보여주고 싶다

---

## 1. 핵심 규칙

- **발행 기반 공개**: 상담사가 "발행" 버튼을 눌러야만 내담자에게 노출
- 작성 중인 초안은 절대 비공개
- 상담사가 공개 범위를 통제한다

---

## 2. 노트 구조

각 회기 노트는 2개 섹션:

| 섹션 | 내용 |
|---|---|
| 회기 요약 | 이번 회기에 뭘 했는지, 아이/내담자가 어떤 반응을 보였는지 |
| 실천 사항 | 다음 회기까지 일상에서 해볼 것 |

---

## 3. 동작

### 정상 흐름

1. 상담사가 SaaS에서 노트를 작성하고 "발행"한다
2. 내담자 앱에 푸시 알림: "5회기 요약 노트가 도착했어요"
3. 홈에 알림 카드가 표시된다
4. 터치하면 노트 목록으로 이동
5. 최신 회기가 펼쳐진 상태, 이전 회기는 접힌 상태

### 노트 목록 화면

아코디언 구조:

```
┌─────────────────────────────────────┐
│  전문가 기록                         │
│                                     │
│  ▼ 5회기 (5/7)              최신    │
│  ┌───────────────────────────────┐  │
│  │ 회기 요약                      │  │
│  │ 감정 카드 활동 진행. 이전보다   │  │
│  │ 감정 어휘가 다양해짐.          │  │
│  │                               │  │
│  │ 실천 사항                      │  │
│  │ 아이가 감정을 말할 때 즉시     │  │
│  │ 반응하지 말고 3초 기다려주세요  │  │
│  └───────────────────────────────┘  │
│                                     │
│  ▶ 4회기 (4/30)                     │
│  ▶ 3회기 (4/23)                     │
└─────────────────────────────────────┘
```

### 예외

| 상황 | 동작 |
|---|---|
| 발행된 노트가 없음 | "아직 도착한 기록이 없어요" |
| 노트 로딩 실패 | 오브: "기록을 불러오지 못했어요" + [다시 시도] |
| 상담사가 발행 후 수정하면? | 수정 내용 자동 반영 (별도 알림 없음) |
| 상담사가 발행을 취소(회수)하면? | 앱에서 해당 노트 비노출 |
