# F10. 미션 & 기록

> 상담사가 설정한 미션을 앱에서 확인하고, 일상 기록을 남겨 상담사에게 전달한다

**Phase**: Phase 2

---

## 유저 스토리

- 보호자로서, 상담사가 알려준 이번 주 실천사항을 앱에서 확인하고 싶다
- 내담자로서, 상담 사이 기간에 뭘 하면 좋을지 알고 싶다
- 보호자로서, 일상에서 관찰한 아이의 변화를 간단히 기록하고 상담사에게 전달하고 싶다
- 상담사로서, 내담자/보호자의 일상 기록을 상담 전에 미리 확인하고 싶다

---

## 1. 전체 흐름

```
SaaS (상담사)              앱 (내담자/보호자)

회기별 미션 설정  ──→  홈에 이번 주 미션 카드 표시
                       ↓
                       [오늘 기록 남기기] 터치
                       ↓
                       3단계 기록 작성 (1분 이내)
                       ↓
기록 확인 ←──────────  "상담사에게 전달됩니다"
(상담 준비 자료)
```

---

## 2. 미션 표시

### 홈 미션 카드

상담사가 미션을 설정한 경우에만 표시. 미설정이면 영역 자체 미노출.

```
┌─────────────────────────────────────┐
│  이번 주 미션                        │
│                                     │
│  감정 이름 먼저 말해주기             │
│  아이가 화를 낼 때 행동을 지적하기   │
│  전에, 감정을 먼저 인정해주세요      │
│                                     │
│  [오늘 기록 남기기]                  │
│                                     │
│  ● ● ● ○ ○ ○ ○  이번 주 3회 기록   │
└─────────────────────────────────────┘
```

### 미션 유형

| 구분 | 예시 |
|---|---|
| 태도/반응 미션 | "아이가 화낼 때 감정 이름을 먼저 말해주세요" |
| 활동 미션 | "감정 날씨 카드 만들기", "하루 10분 산책" |

미션은 회기 기반으로 갱신. 상담사가 회기 후 다음 미션을 설정하면 앱에 반영.

---

## 3. 기록 플로우

### 정상 흐름

1. [오늘 기록 남기기]를 터치한다
2. 기록 유형을 선택한다 (미션 관련 / 일상 기록 / 둘 다)
3. 상황 설명을 입력한다 (필수)
4. 반응/느낌을 입력한다 (선택)
5. 완료 화면: 격려 메시지 + 주간 기록 도트 + "상담사에게 전달됩니다"

```
Step 1: 유형 선택        Step 2: 내용 입력       Step 3: 완료
○ 미션 관련              상황 설명 (필수)        잘 하셨어요
○ 일상 기록              반응/느낌 (선택)        ● ● ● ● ○  4회
○ 둘 다                                         상담사에게 전달됩니다
```

### 설계 원칙

| 원칙 | 적용 |
|---|---|
| 부담 최소화 | 최대 3단계, 1분 이내 완료 |
| 점진적 공개 | 필수 → 선택 순서로 |
| 즉각적 보상 | 격려 메시지 + 주간 누적 도트 |
| 의미 부여 | "상담사에게 전달됩니다" — 기록의 목적 명확화 |

### 예외

| 상황 | 동작 |
|---|---|
| 기록 작성 중 앱을 닫으면? | 작성 내용 소멸 (임시 저장 없음) |
| 기록 제출 실패 | 스낵바: "기록을 저장하지 못했어요" + [다시 시도] |
| 미션이 없는데 기록하고 싶으면? | "일상 기록"으로 직접 작성 가능 |
