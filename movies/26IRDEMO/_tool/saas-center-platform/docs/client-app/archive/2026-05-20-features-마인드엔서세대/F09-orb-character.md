# F09. 오브 캐릭터

> 앱 전체에 걸친 감성적 가이드 캐릭터. 에러 상태까지 브랜드 경험으로 만든다

**Phase**: MVP

---

## 유저 스토리

- 사용자로서, 앱을 열었을 때 딱딱한 UI가 아니라 따뜻한 인사를 받고 싶다
- 사용자로서, 에러가 나도 당황하지 않고 무슨 상황인지 알고 싶다
- 사용자로서, 로딩 중에도 앱이 작동하고 있다는 느낌을 받고 싶다

---

## 1. 기본 정의

| 항목 | 내용 |
|---|---|
| 형태 | 빛/오브 (따뜻한 빛 덩어리, 추상형) |
| 성격 | 차분한 안내자, 따뜻한 톤 |
| 말투 | 느낌표 없이 마침표로 끝나는 차분한 톤 |
| MVP 역할 | 상황별 한 줄 멘트 + 시각 변화 + 에러/빈 상태 표현 |
| Phase 2 확장 | AI 성장 가이드의 인격으로 확장 |

| 낮 (11~17시) | 따뜻한 주황빛 | |
| 저녁 (17~21시) | 부드러운 보랏빛 (차분) | |

### 상황별

| 상황 | 오브 표현 |
|---|---|
| 일정 임박 (D-0, D-1) | 살짝 반짝임 |
| 상담 완료 직후 | 포근하게 퍼짐 |
| 7일 이상 미접속 후 재접속 | 조용히 흔들림 |
| 로딩 중 | 숨쉬듯 맥동 (스피너 대체) |
| 에러 | 흐릿해짐 |

## 3. 상황별 멘트

### 멘트 결정 로직

멘트는 **서버 호출 없이 로컬에서 즉시 결정**한다. 우선순위가 높은 조건부터 매칭하고, 해당되는 것이 없으면 시간대별 기본 멘트를 표시한다.

**우선순위**:

| 순위 | 조건 | 멘트 |
|---|---|---|
| 1 | 네트워크 오류 | "연결이 불안정해요" |
| 2 | 서버 오류 | "잠깐 문제가 생겼어요" |
| 3 | 7일 이상 미접속 후 재접속 | "다시 만나서 반가워요" |
| 4 | 일정 D-0 (당일) | "오늘 상담이 있어요" |
| 5 | 일정 D-1 (내일) | "내일 민준이 상담이 있어요" |
| 6 | 진행현황 50% 돌파 (최초 1회) | "벌써 절반이나 왔어요" |
| 7 | 예정 일정 없음 | "아직 예정된 일정이 없어요" |
| 8 | 해당 없음 | 시간대별 기본 멘트 |

**시간대별 기본 멘트**:

| 시간대 | 멘트 |
|---|---|
| 아침 | "좋은 아침이에요" |
| 낮 | "오늘은 여유로운 하루예요" |
| 저녁 | "오늘 하루도 수고했어요" |
| 밤 | "푹 쉬어요" |

### 보호자일 때

자녀 이름을 멘트에 포함: "내일 **민준이** 상담이 있어요"

자녀가 여러 명이고 내일 여러 일정이 있으면: "내일 일정이 2건 있어요" (이름 나열 대신 건수)

---

## 4. 에러/빈 상태 표현

일반적인 에러 페이지 대신 **오브가 상태를 표현**한다.

### 네트워크 오류

```
      (흐릿해진 오브)

  "연결이 불안정해요.
   잠시 후 다시 올게요"

      [다시 시도]
```

### 서버 오류

```
      (깜빡이는 오브)

  "잠깐 문제가 생겼어요.
   곧 괜찮아질 거예요"

      [다시 시도]
```

### 로딩 중

```
      (숨쉬듯 맥동하는 오브)

  (멘트 없음, 빛 애니메이션만)
```

기존 스피너 대신 오브 맥동 사용.

### 빈 데이터

```
      (조용히 떠있는 오브)

  "아직 예정된 일정이 없어요"
```

---

## 5. 다크 모드

오브가 빛 기반이라 다크 모드에서 시각적 효과 극대화:

- **라이트**: 밝은 배경 + 은은한 오브 → 차분하고 깨끗한
- **다크**: 어두운 배경 + 빛나는 오브 → 몰입감, 감성적

오브의 색상/밝기 값은 모드별로 별도 정의 필요.
