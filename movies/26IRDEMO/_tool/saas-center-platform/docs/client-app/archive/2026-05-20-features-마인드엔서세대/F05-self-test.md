# F05. 자가진단

> 미소속 사용자에게 제공하는 간이 심리 선별검사 (일회성 체험)

**Phase**: MVP

---

## 유저 스토리

- 미소속 사용자로서, 앱을 깔았는데 뭔가 해볼 수 있는 게 있으면 좋겠다
- 사용자로서, 내 우울/불안 수준이 어느 정도인지 간단히 확인해보고 싶다

---

## 1. 성격 및 목적

| 항목 | 내용 |
|---|---|
| 성격 | 가벼운 체험 콘텐츠 |
| 결과 저장 | **하지 않음** (화면을 벗어나면 소멸) |
| 이유 | 단일 검사 결과만으로는 의미 있는 이력이 안 됨. 종합 평가는 센터에서 |
| 목적 | 즉시 가치 제공 + 센터 연결 유도 |
| 노출 위치 | 미소속 홈, 승인 대기 홈 (소속 사용자에게는 홈에서 미노출) |

---

## 2. 검사 항목

MVP 예시 (최종 항목은 별도 선정 필요):

| 검사 | 대상 | 문항 수 | 소요 시간 |
|---|---|---|---|
| PHQ-9 | 우울 선별 | 9문항 | 약 2분 |
| GAD-7 | 불안 선별 | 7문항 | 약 2분 |

---

## 3. 전체 흐름

### 정상 흐름

1. 미소속 홈에서 자가진단 [시작]을 누른다
2. 검사 안내 화면이 표시된다 (검사명, 문항 수, 소요 시간, 안내 문구)
3. [시작하기]를 누른다
4. 한 문항씩 카드 형태로 표시된다
5. 선택지를 터치하면 0.3초 후 다음 문항으로 자동 전환된다
6. 마지막 문항 응답 후 결과 화면이 표시된다
7. 결과 화면에서 [센터 코드 입력하기] 또는 [홈으로 돌아가기]를 선택한다

### 검사 안내 화면

```
── 우울 선별검사 (PHQ-9) ──────

최근 2주간의 기분 상태를
확인해볼 수 있어요.

9문항 · 약 2분

이 검사는 간이 선별 도구이며,
정확한 진단을 대체하지 않아요.

[시작하기]
```

### 문항 응답 화면

```
── 질문 3/9 ───────────────────

최근 2주간,
잠들기 어렵거나 자꾸 깨거나
너무 많이 잤다.

○ 전혀 아니다
○ 며칠 동안
○ 일주일 이상
○ 거의 매일

━━━━━━━━░░░░░░░░░░░ 3/9
```

- 선택 → 체크 표시 + 색상 변경 → 0.3초 후 다음 문항 슬라이드
- 상단 프로그레스 바로 진행률 표시
- 이전 문항 돌아가기 가능 (좌 스와이프 또는 뒤로 버튼)

### 결과 화면

```
── 우울 선별검사 (PHQ-9) 결과 ──

당신의 점수: 12점
중등도 우울이 의심돼요.

이 결과는 간이 선별 결과이며,
정확한 평가는 전문가 상담을 통해
확인하는 것이 좋아요.

[센터 코드 입력하기]
[홈으로 돌아가기]
```

**결과 수준별 멘트 톤**:

| 수준 | 톤 |
|---|---|
| 정상 범위 | "현재 큰 어려움은 없어 보여요. 꾸준히 자신을 돌보는 것도 중요해요." |
| 경미 | "가벼운 어려움이 느껴지고 있어요. 전문가와 이야기해보는 것도 좋아요." |
| 중등도 이상 | "정확한 평가와 맞춤 상담은 전문 센터에서 받아보세요." |

## 4. 예외 및 엣지케이스

| 상황 | 동작 |
|---|---|
| 문항 응답 중 앱을 닫으면? | 진행 상태 소멸. 다음에 다시 시작하면 처음부터 |
| 문항 응답 중 뒤로가기를 누르면? | 확인: "검사를 그만둘까요? 결과가 저장되지 않아요" [그만두기] [계속하기] |
| 결과 화면을 벗어나면? | 결과 소멸. 다시 보려면 재검사 |
| 같은 검사를 다시 하면? | 제한 없이 재시도 가능. 이전 결과와 비교 없음 |
| 문항 로딩 실패 | 오브: "검사를 불러오지 못했어요" + [다시 시도] |
| 결과 계산(제출) 실패 | 스낵바: "결과를 확인할 수 없었어요" + [다시 제출] |

### 규칙

- 점수 계산은 서버에서 수행 (앱에 채점 로직 미포함)
- 서버는 제출된 답변을 처리 후 **저장하지 않고 폐기**
- 소속 사용자도 자가진단에 접근 가능하지만, 소속 홈에서는 노출되지 않음 (마이페이지 등 별도 진입점 필요 시 추후 결정)
