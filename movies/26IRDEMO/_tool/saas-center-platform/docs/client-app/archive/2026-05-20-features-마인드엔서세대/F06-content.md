# F06. 콘텐츠

> 태그 기반 맞춤 추천 콘텐츠 (매거진 + 카드뉴스)

**Phase**: MVP

---

## 유저 스토리

- 보호자로서, 우리 아이 상담과 관련된 읽을거리가 있으면 좋겠다
- 미소속 사용자로서, 센터 없이도 유용한 콘텐츠를 보고 싶다
- 내담자로서, 내 상담 주제에 맞는 글을 추천받고 싶다

---

## 1. 현황

- 매거진 100건 + 카드뉴스 100건 (자체 제작, 기확보)
- 소속/미소속 **공통**으로 홈 하단에 노출

---

## 2. 태그 기반 맞춤 추천

### 태그 구조

```
카테고리 태그 (1차): 아동 / 청소년 / 성인 / 부모교육
주제 태그 (2차, 복수 가능): 우울 / 불안 / 관계 / 자존감 / 감정조절 / 놀이치료 / 언어치료 / ...
```

하나의 콘텐츠에 카테고리 1개 + 주제 1~3개.

### 추천 로직

| 사용자 상태 | 추천 방식 |
|---|---|
| 소속 | 사용자의 케이스(상담 유형, 내담자 연령대) → 관련 태그 콘텐츠 우선, 뒤에 일반 |
| 미소속 | 태그 매칭 불가 → 인기순/최신순 |

**매칭 예시**:
- 아동 놀이치료 케이스 → `아동`, `놀이치료`, `감정조절` 태그 우선
- 성인 우울 상담 → `성인`, `우울`, `자존감` 태그 우선

---

## 3. 홈 표시

### 정상 흐름

1. 홈 하단에 "읽어볼 만한 글" 영역이 표시된다
2. 가로 스크롤로 콘텐츠 카드를 넘긴다
3. 카드를 터치하면 콘텐츠 상세로 이동한다
4. 마지막 카드 뒤에 "더 보기 →" → 전체 목록 진입

### 카드 구성

```
┌──────────┐  ┌──────────┐
│ (썸네일)  │  │ (썸네일)  │
│          │  │          │
│ 놀이치료, │  │ 아이의    │
│ 어떤 변화 │  │ 감정을    │
│ 가 생기나 │  │ 읽어주는  │
│ 요?      │  │ 3가지    │
│          │  │ 방법     │
│ 3분 읽기  │  │ 2분 읽기  │
└──────────┘  └──────────┘
               → 스크롤
```

- 홈에 최대 10건
- 카드 너비: 화면의 약 40%
- 썸네일 비율: 3:4

---

## 4. 전체 목록

"더 보기"를 터치하면 진입.

```
← 콘텐츠

[전체] [매거진] [카드뉴스]    ← 탭 필터

┌────────────────────────────┐
│ (썸네일) 놀이치료, 어떤     │
│          변화가 생기나요?   │
│          3분 읽기 · 아동    │
└────────────────────────────┘
...
```

- 세로 스크롤, 무한 스크롤 (커서 기반 페이지네이션)
- 탭 필터: 전체 / 매거진 / 카드뉴스

---

## 5. 콘텐츠 상세

### 매거진

상단 커버 이미지 + 본문 (HTML 또는 마크다운 렌더링).

```
← 놀이치료, 어떤 변화가 생기나요?

(커버 이미지)
아동 · 놀이치료 · 3분 읽기

본문 내용...
```

### 카드뉴스

이미지 슬라이드. 좌우 스와이프. 하단 인디케이터.

```
← 아이의 감정을 읽어주는 3가지 방법

┌────────────────────────────┐
│      (카드 이미지 1/5)      │
└────────────────────────────┘
        ● ○ ○ ○ ○
```

## 6. 예외 및 에러

| 상황 | 동작 |
|---|---|
| 홈 콘텐츠 로딩 실패 | 콘텐츠 영역만 미표시 (조용히 실패, 다른 영역 정상) |
| 전체 목록 로딩 실패 | 오브: "콘텐츠를 불러오지 못했어요" + [다시 시도] |
| 상세 로딩 실패 | 스낵바: "콘텐츠를 열 수 없어요" + 뒤로 이동 |
| 이미지 로딩 실패 | 깨진 이미지 대신 회색 플레이스홀더 |
| 콘텐츠가 하나도 없을 때 | 영역 자체 미표시 (발생 가능성 낮음, 200건 기확보) |
