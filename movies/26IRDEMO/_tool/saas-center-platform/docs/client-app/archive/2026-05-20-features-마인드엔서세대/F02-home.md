# F02. 홈 화면

> 앱을 열었을 때 "다음에 뭘 하면 되지?"에 0.5초 안에 답하는 화면

**Phase**: MVP

---

## 유저 스토리

- 성인 내담자로서, 앱을 열면 다음 상담이 언제인지 바로 알고 싶다
- 보호자로서, 내 자녀들의 다음 일정과 진행 상황을 한눈에 보고 싶다
- 미소속 사용자로서, 센터 없이도 앱에서 할 수 있는 게 있었으면 좋겠다

---

## 1. 소속 홈

### 정상 흐름

1. 앱을 연다
2. 오브 캐릭터와 상황별 멘트가 즉시 표시된다 (서버 호출 없이 로컬)
3. 일정 카드와 콘텐츠가 병렬로 로딩된다
4. 각 영역은 도착 순서대로 독립적으로 나타난다

### 화면 구성

```
┌─────────────────────────────────────┐
│  (오브 캐릭터)                      │
│  "내일 민준이 상담이 있어요"        │
├─────────────────────────────────────┤
│  ① 다음 일정                        │
│  5/21 수 14:00 · D-2                │
│  민준 · 상담 6회차 · 놀이치료센터   │
│  ━━━━━━━━━━░░░░░░░░░░ 5/10회       │
│  [길찾기]        [전체 보기 →]       │
│                                     │
│  5/23 금 10:00 · D-4                │
│  서연 · 언어평가 · 언어치료센터     │
│  ━━━░░░░░░░░░░░░░░░░░ 1/8회        │
│  [길찾기]                            │
├─────────────────────────────────────┤
│  ② 읽어볼 만한 글                   │
│  [가로 스크롤 카드]                  │
└─────────────────────────────────────┘
     [ 홈 ]              [ 마이 ]
```

### 일정 카드 동작

**표시 내용**:
- 날짜, 시간, D-day
- 대상 이름 (보호자인 경우 자녀 이름), 회차, 센터명
- 진행 바 또는 진행 텍스트

**D-day 규칙**:
- 오늘이면 `D-0` (강조색)
- 7일 이내면 `D-N`
- 7일 초과면 D-day 미표시

**진행 표시 규칙**:
- 총 회기수가 정해져 있으면 → 진행 바: `━━━━━━━━━━░░░░░░ 5/10회`
- 총 회기수가 없으면 (일반적) → 텍스트: `6회차 진행 중 · 3개월째`

**[길찾기] 버튼**:
- 센터 좌표가 있으면 → 기기 기본 지도 앱으로 길찾기 실행
- 좌표 없이 주소만 있으면 → 주소 텍스트로 지도 앱 실행
- 둘 다 없으면 → 버튼 자체가 미표시

**[전체 보기 →]**:
- 터치하면 타임라인 화면으로 이동 (→ F03)

**최대 표시**: 3건. 초과 시 "N건 더 보기 →".

### 역할별 일정 표시

| 케이스 | 홈에서 보이는 것 |
|---|---|
| 순수 내담자 | 내 일정만 표시 (섹션 구분 없음) |
| 순수 보호자 | 자녀 일정만 표시 (자녀 이름별 섹션) |
| 둘 다 (both) | "내 일정" 섹션 + 자녀 이름별 섹션 |

```
── 내 일정 ──────────────────
5/21 수  14:00
개인상담 3회차 · ○○상담센터

── 민준 ─────────────────────
5/21 수  16:30
상담 6회차 · 놀이치료센터 · D-2

── 서연 ─────────────────────
5/23 금  10:00
언어평가 · 언어치료센터 · D-4
```

- 데이터가 없는 섹션은 미표시
- 섹션 내 정렬: 시간순 (가까운 일정이 위)
- 세 케이스 모두 같은 컴포넌트로 처리 (조건부 렌더링)

### 다중 센터 통합

센터별로 나누지 않는다. 모든 센터의 일정을 시간순으로 합산. 센터명은 일정 카드 안에 라벨로 표시. 사용자는 "이번 주에 뭐가 있지?"로 생각하기 때문.

## 2. 미소속 홈

### 정상 흐름

1. 로그인 후 센터 연결 없이 홈에 진입한다
2. 오브 캐릭터와 센터 연결 안내가 표시된다
3. 자가진단과 콘텐츠를 이용할 수 있다

### 화면 구성

```
┌─────────────────────────────────────┐
│  (오브 캐릭터)                      │
│  나를 위한                          │
│  작은 변화의 시작                   │
│                                     │
│  [센터 코드로 연결하기]              │
├─────────────────────────────────────┤
│  자가진단                           │
│  우울 선별검사 (PHQ-9)       [시작] │
│  불안 선별검사 (GAD-7)       [시작] │
├─────────────────────────────────────┤
│  읽어볼 만한 글                     │
│  [콘텐츠 가로 스크롤]               │
└─────────────────────────────────────┘
```

**[센터 코드로 연결하기]** → 센터 코드 입력 화면으로 이동 (→ F01)

---

## 3. 승인 대기 홈

### 정상 흐름

1. 센터 코드를 입력하고 승인 대기 중이다
2. 오브가 대기 상태를 안내한다
3. 승인될 때까지 미소속 콘텐츠(자가진단 + 콘텐츠)를 이용할 수 있다
4. 센터에서 승인하면 → 푸시 알림 → 소속 홈으로 자동 전환

### 화면 구성

```
┌─────────────────────────────────────┐
│  (오브 캐릭터)                      │
│  승인 대기 중                       │
│  ○○심리상담센터에서 확인 중         │
│  "승인되면 알려드릴게요"            │
├─────────────────────────────────────┤
│  (미소속과 동일: 자가진단 + 콘텐츠) │
└─────────────────────────────────────┘
```

### 예외

| 상황 | 동작 |
|---|---|
| 여러 센터에 동시 대기 | 가장 최근 요청 센터명 표시 + "N개 센터 승인 대기 중" → 마이페이지 |
| 승인됐는데 앱이 포그라운드 | 푸시 수신 → 데이터 재호출 → 소속 홈 자동 전환 |
| 승인됐는데 앱이 꺼져 있었음 | 다음 앱 진입 시 소속 홈 |
| 센터에서 거절 | 미소속 홈으로 복귀. 거절 사유는 미표시 (→ F01 참조) |

---

## 4. 조건부 표시 규칙

| 영역 | 표시 조건 | 없을 때 |
|---|---|---|
| 캐릭터 멘트 | 항상 | 시간대별 기본 멘트 (→ F09) |
| 다음 일정 | 예정 일정 1건 이상 | 오브 멘트: "아직 예정된 일정이 없어요" (일정 카드 영역 자체 미노출) |
| 미션 | Phase 2 | 영역 미노출 |
| 콘텐츠 | 항상 | 일반 콘텐츠 |

**핵심 원칙**: 데이터 없는 빈 카드로 자리를 차지하지 않는다.

---

## 5. 예외 및 에러

| 상황 | 동작 |
|---|---|
| 일정 로딩 실패 | 일정 영역에 오브 멘트: "일정을 불러오지 못했어요" + [다시 시도] |
| 콘텐츠 로딩 실패 | 콘텐츠 영역만 미표시 (조용히 실패, 다른 영역 정상) |
| 전체 네트워크 오류 | 전체 화면 오브: "연결이 불안정해요" + [다시 시도] |
| 일정은 성공, 콘텐츠 실패 | 일정만 정상 표시 (각 영역 독립) |
| 아래로 당겨서 새로고침 | 모든 영역 재호출. 오브가 살짝 반짝이는 피드백 |
