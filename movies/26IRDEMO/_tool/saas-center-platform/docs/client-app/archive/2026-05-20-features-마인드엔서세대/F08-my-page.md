# F08. 마이페이지

> 센터 정보, 프로필, 자녀 정보, 설정을 관리하는 화면

**Phase**: MVP

---

## 유저 스토리

- 보호자로서, 소속된 센터들의 정보(담당 선생님, 진행현황)를 한곳에서 보고 싶다
- 사용자로서, 프로필을 수정하고 알림 설정을 변경하고 싶다
- 보호자로서, 센터에 등록된 자녀 정보를 확인하고 싶다

---

## 1. 화면 구성

기능 나열이 아닌 **센터 카드 중심** 구조. 센터 단위로 정보를 묶는다.

```
── 프로필 ───────────────────
홍길동
hong@email.com
[프로필 수정 ›]

── 내 센터 ──────────────────
┌─────────────────────────┐
│ ○○놀이치료센터    [이용중] │
│ 담당: 김상담 선생님      │
│ 검사결과 2건 ›           │
│ 진행현황: 6/10회 ›       │
│ 내담자: 민준             │
└─────────────────────────┘
┌─────────────────────────┐
│ △△언어치료센터    [이용중] │
│ 담당: 이상담 선생님      │
│ 검사결과 1건 ›           │
│ 진행현황: 1/8회 ›        │
│ 내담자: 서연             │
└─────────────────────────┘

[+ 센터 코드로 추가 연결]

── 자녀 정보 ────────────────

이용약관 ›
```

## 2. 센터 카드

### 이용중 센터

각 센터 카드에 표시되는 정보:

| 정보 | 터치 시 |
|---|---|
| 센터명 + [이용중] 라벨 | — |
| 담당 상담사 이름 | — |
| 검사결과 N건 › | 해당 센터 검사 결과 목록 (→ F04) |
| 진행현황: N/M회 › | 해당 센터 타임라인 (→ F03) |
| 내담자: 이름 | — (보호자인 경우에만 표시) |

### 센터 식별 (아바타)

```
센터 로고가 있는가?
  ├─ YES → 로고 이미지 (32px, 둥근 사각형)
  └─ NO  → 첫 글자 + 자동 배정 색상
           예: "해밀심리센터" → 파란 배경에 "해"
```

- 색상 풀: 6~8가지 구분 가능한 색상 순환 배정
- 2개 이상 센터가 default 아이콘이면 구분 불가 → 이니셜+색상으로 해결

### 종결 센터

이용중 센터 하단으로 이동. "종결" 라벨 + 기간 표시. 기록 열람만 가능.

```
┌─────────────────────────┐
│ □□상담센터        [종결]  │
│ 2025.11 ~ 2026.04       │
│ 상담 기록 보기 ›         │
└─────────────────────────┘
```

- "상담 기록 보기" 터치 → 종결 케이스 타임라인 (읽기 전용)
- 종결 센터의 데이터는 삭제되지 않음 (MVP 정책)

### 승인 대기 센터

센터 카드 목록에 대기 상태로 표시:

```
┌─────────────────────────┐
│ ○○심리상담센터   [승인 대기] │
│ 요청일: 2026.05.20       │
└─────────────────────────┘
```

터치 불가. 승인되면 자동으로 이용중으로 전환.

## 3. 자녀 정보

- **조회 전용**. 센터에서 등록한 데이터이며 앱에서 수정 불가
- 센터가 데이터 주도권을 가짐
- 자녀 이름 터치 → 자녀 기본 정보 표시 (이름, 생년월일, 소속 센터 등)

---

## 4. 프로필/설정

### 프로필 수정

수정 가능 항목: 이름
수정 불가 항목: 이메일 (소셜 로그인 연동), 전화번호 (별도 인증 필요)

### 알림 설정

MVP: 전체 on/off 토글 1개. (→ F07)

### 개인정보 관리

| 기능 | 동작 |
|---|---|
| 전화번호 변경 | 새 번호 입력 + SMS 재인증 |
| 계정 삭제 | 확인 다이얼로그 → 삭제 요청 (처리 정책은 별도 수립) |

### 로그아웃

1. [로그아웃] 터치
2. 확인: "로그아웃 할까요?" [취소] [로그아웃]
3. 로그아웃 → 토큰 삭제 + 디바이스 토큰 해제 → 로그인 화면

## 6. 예외 및 에러

| 상황 | 동작 |
|---|---|
| 소속 센터가 없을 때 | "내 센터" 영역에 [센터 코드로 연결하기] CTA만 표시 |
| 자녀가 없을 때 | "자녀 정보" 영역 미표시 |
| 센터 데이터 로딩 실패 | 센터 카드 영역에 "정보를 불러오지 못했어요" + [다시 시도] |
| 프로필 수정 실패 | 스낵바: "수정에 실패했어요" |
| 계정 삭제 요청 | "삭제를 요청했어요. 처리까지 최대 N일 소요됩니다" (정책 확정 후) |
