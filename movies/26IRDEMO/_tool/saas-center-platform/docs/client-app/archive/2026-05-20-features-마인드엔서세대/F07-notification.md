# F07. 알림

> 일정 리마인더 및 센터 관련 푸시 알림

**Phase**: MVP

---

## 유저 스토리

- 보호자로서, 내일 자녀 상담이 있으면 미리 알림을 받고 싶다
- 내담자로서, 상담 시간을 깜빡하지 않도록 당일 알림을 받고 싶다
- 사용자로서, 센터에서 승인해주면 바로 알고 싶다

---

## 1. 알림 종류 및 타이밍

타이밍은 **시스템 고정**. MVP에서 사용자가 타이밍을 변경할 수 없다.

| 알림 | 발송 시점 | 예시 |
|---|---|---|
| 일정 전날 | D-1 오전 10시 | "내일 14:00 상담이 있어요" |
| 일정 당일 | 1시간 전 | "1시간 뒤 상담이에요, 준비됐나요?" |
| 센터 승인 | 즉시 | "○○센터에서 승인했어요!" |
| 일정 변경 | 즉시 | "5/21 상담 일정이 변경됐어요" |
| 일정 취소 | 즉시 | "5/21 상담 일정이 취소됐어요" |

---

## 2. 다중 센터/자녀 규칙

### 같은 날 여러 일정

D-1 알림은 **묶어서 한 번** 발송:
- 1건: "내일 14:00 상담이 있어요"
- 2건 이상: "내일 일정이 2건 있어요"

당일 알림(1시간 전)은 **각각** 발송 (시간이 다르므로).

### 보호자 알림

자녀 이름으로 구분:

| 케이스 | 알림 예시 |
|---|---|
| 자녀 1명 | "내일 민준이 상담이 있어요" |
| 자녀 2명, 같은 날 | "내일 민준이 14:00, 서연이 16:00 상담이 있어요" |
| 본인도 내담자 (both) | 본인: "내일 상담이 있어요" + 자녀: "민준이 상담이 있어요" (별도 발송) |

### 양쪽 부모

같은 자녀에 보호자가 2명(부/모)이면 **양쪽 다 발송**. 각자의 기기로 동일 알림.

---

## 3. 알림 톤

캐릭터(오브) 톤을 적용한다. 딱딱한 시스템 알림이 아닌 따뜻한 안내 느낌.

| 기존 톤 | 오브 톤 |
|---|---|
| "예약일 1일 전입니다" | "내일 민준이 상담이 있어요" |
| "예약 시간 1시간 전" | "1시간 뒤 상담이에요, 준비됐나요?" |
| "승인 완료" | "○○센터에서 승인했어요!" |

---

## 4. 알림 설정

MVP: **전체 on/off만**. 마이페이지 > 알림 설정.

| 설정 | 동작 |
|---|---|
| 알림 켜기 | 모든 알림 수신 |
| 알림 끄기 | 모든 알림 차단 |

종류별 설정(일정만 켜기, 승인만 켜기 등)과 방해 금지 시간은 향후 추가.

---

## 5. 알림 터치 시 동작

| 알림 종류 | 터치 시 이동 |
|---|---|
| 일정 전날/당일 | 홈 화면 (일정 카드가 보이는 위치) |
| 센터 승인 | 홈 화면 (소속 홈으로 전환됨) |
| 일정 변경/취소 | 홈 화면 |

앱이 종료 상태에서 알림 터치 → 앱 실행 → 해당 화면으로 이동.

---

## 6. 예외

| 상황 | 동작 |
|---|---|
| 기기 알림 권한 꺼져 있음 | 앱 내에서 안내: "알림을 켜면 일정을 놓치지 않아요" + [설정으로 이동] |
| 로그아웃 | 디바이스 토큰 해제, 알림 중단 |
| 다중 기기 로그인 (폰 + 태블릿) | 모든 기기에 알림 발송 |
| 알림 off 상태에서 센터 승인 | 알림 미발송. 다음 앱 진입 시 소속 홈 전환 |
