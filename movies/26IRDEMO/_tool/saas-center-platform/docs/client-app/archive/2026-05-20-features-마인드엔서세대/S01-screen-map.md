## 1. 소속 홈 (메인 화면)

### 조건부 표시 규칙

| 영역 | 조건 | 미충족 시 |
|---|---|---|
| 오브 + 멘트 | **항상** | 시간대별 기본 멘트 |
| 다음 일정 | 예정 일정 ≥ 1건 | 영역 미노출 (오브 멘트로 대체) |
| 미션 | Phase 2 + 상담사 설정 | 영역 미노출 |
| 콘텐츠 | **항상** | 일반 콘텐츠 (매칭 불가 시 인기순) |

### 에러 시 동작

| 상황 | 영향 범위 |
|---|---|
| 일정 로딩 실패 | 일정 영역만 에러 (오브 멘트 + [다시 시도]) |
| 콘텐츠 로딩 실패 | 콘텐츠 영역만 조용히 미표시 |
| 전체 네트워크 오류 | 전체 화면 오브 에러 |
| 각 영역 독립 로딩 | 성공한 영역만 표시 |

## 2. 미소속 홈

센터 연결 전 사용자. 자가진단 + 콘텐츠로 즉시 가치 제공.

```
┌─────────────────────────────────────┐
│                                     │
│         ◉  (오브 캐릭터)             │  ← F09
│                                     │
│      나를 위한                       │
│      작은 변화의 시작                │
│                                     │
│      [센터 코드로 연결하기]          │  ← F01. 센터 연결 플로우 진입
│                                     │
├─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┤
│                                     │
│  자가진단                            │  ← F05. 일회성 선별검사

## 3. 승인 대기 홈

센터 코드 입력 후 승인 대기. 미소속과 동일한 콘텐츠 + 대기 상태 표시.

```
┌─────────────────────────────────────┐
│                                     │
│         ◉  (오브 캐릭터)             │  ← F09
│                                     │
│      승인 대기 중                    │
│      ○○심리상담센터에서 확인 중      │
│      "승인되면 알려드릴게요"         │
│                                     │
├─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┤
│                                     │
│  (미소속 홈과 동일)                  │
│  자가진단 + 콘텐츠                   │
│                                     │
├─────────────────────────────────────┤
│     [ 홈 ]              [ 마이 ]    │
└─────────────────────────────────────┘

※ 승인 시 → 푸시 알림 → 소속 홈 자동 전환
※ 거절 시 → 미소속 홈 복귀
```

## 4. 타임라인 (드릴다운)

홈 [전체 보기] 또는 마이페이지 [진행현황] 터치 시 진입.

```

│   ━━━━━━━━━━░░░░░░ 5/10회          │      진행 바 (총 회기 있을 때)

│   [놀이치료 - 개별]                  │  ← 케이스별 분리

│   ○ 5/28  상담 7회차  D-9           │      먼 미래 (흐림)

회차 터치 → 바텀시트:

## 7. 화면 간 이동 맵

```
                    ┌─────────┐
                    │ 소속 홈  │
                    └────┬────┘
                         │
          ┌──────────────┼──────────────┐
          │              │              │
          ▼              ▼              ▼
   ┌────────────┐ ┌────────────┐ ┌──────────┐
   │ 타임라인    │ │ 콘텐츠     │ │ 마이페이지│
   │ (전체 보기) │ │ (더 보기)  │ │          │
   └──────┬─────┘ └─────┬──────┘ └────┬─────┘
          │             │              │
          ▼             ▼         ┌────┼────┐
   ┌────────────┐ ┌──────────┐   │    │    │
   │ 회차 상세   │ │ 콘텐츠   │   ▼    ▼    ▼

   └────────────┘ └──────────┘  결과  라인  연결

                               검사 결과
                               상세
```

### 주요 진입점 정리

| 출발 | 동작 | 도착 | 기능 |
