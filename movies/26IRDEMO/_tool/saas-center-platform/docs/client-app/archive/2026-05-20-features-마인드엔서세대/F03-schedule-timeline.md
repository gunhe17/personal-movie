# F03. 일정 & 타임라인

> 홈 일정 카드에서 "전체 보기"를 누르면 진입하는 전체 상담 이력 화면

**Phase**: MVP

---

## 유저 스토리

- 보호자로서, 자녀의 전체 상담 이력을 한 화면에서 보고 싶다
- 내담자로서, 지금까지 몇 회 했고 앞으로 몇 회 남았는지 알고 싶다
- 보호자로서, 자녀가 여러 치료(놀이/미술)를 받을 때 각각 어디까지 진행됐는지 보고 싶다

---

## 1. 전체 흐름

```
홈 일정 카드 (→ F02)
    ↓ "전체 보기" 터치
타임라인 화면
    ↓ 완료 회차 터치
회차 상세 (바텀시트)
```

---

## 2. 타임라인 화면

### 왜 캘린더가 아닌 타임라인인가

- 주 1~2회 상담에 월간 캘린더는 빈 칸만 가득함
- 타임라인은 "뭘 했고, 다음에 뭘 하는지"가 한눈에 보임
- D-day, 카드 애니메이션 등 재미 요소 적용에 적합

### 화면 구성

자녀(또는 본인) > 센터 > 케이스 3단 계층으로 구성된다.

```
← 전체 일정

── 민준 · 놀이치료센터 ───────
  ━━━━━━━━━━░░░░░░ 5/10회

  ✓ 5/14  상담 5회차  완료
  ✓ 5/7   상담 4회차  완료
  ✓ 4/30  상담 3회차  완료
  · · · 2건 더 보기
  ● 5/21  상담 6회차  D-2  [길찾기]
  ○ 5/28  상담 7회차  D-9
  ○ 6/4   상담 8회차

── 서연 · 언어치료센터 ───────
  ━━━░░░░░░░░░░░░░ 1/8회

  ✓ 5/16  언어평가    완료
  ● 5/23  치료 1회차  D-4  [길찾기]
  ○ 5/30  치료 2회차
```

---

## 3. 회차 상태 표시

| 상태 | 아이콘 | 스타일 | 설명 |
|---|---|---|---|
| 완료 (`completed`) | ✓ | 정상 톤 | "완료" |
| 미방문 (`no_show`) | ─ | 흐린 톤 | "미방문" (부정적 느낌 배제, 사유 미표시) |
| 다음 예정 | ● | 강조색 + 볼드 | D-day 표시 + [길찾기] |
| 먼 미래 예정 | ○ | 흐린 톤 | D-day 7일 이내만 표시 |
| 취소 (`cancelled`) | — | **미노출** | 타임라인에서 완전히 제외 |

**"다음 예정" 판별**: 예정된 일정 중 가장 가까운 1건만 ● 스타일. 나머지 미래 일정은 ○.

## 4. 회차 터치 시 동작

바텀시트로 상세 정보 표시.

### 완료 회차

```
5/14 수 · 상담 5회차 · 완료
놀이치료센터
담당: 김상담 선생님
14:00 ~ 14:50
```

### 미방문 회차

```
5/7 수 · 상담 4회차 · 미방문
놀이치료센터
14:00 ~ 14:50
```

### 예정 회차

```
5/21 수 · 상담 6회차 · D-2
놀이치료센터
담당: 김상담 선생님
```

## 5. 케이스별 분리

같은 센터에서 여러 프로그램(놀이치료 + 미술치료)을 받는 경우, 치료 맥락이 다르므로 **케이스별 별도 타임라인**으로 표시한다.

```
── 민준 · 놀이치료센터 ───────

  [놀이치료 - 개별]
  6회차 진행 중 · 3개월째
  ✓ 5/14  상담 5회차  완료
  ● 5/21  상담 6회차  D-2  [길찾기]
  ○ 5/28  상담 7회차  D-9

  [미술치료 - 개별]
  2회차 진행 중 · 1개월째
  ✓ 5/12  치료 1회차  완료
  ● 5/19  치료 2회차  D-0  [길찾기]
```

- 케이스 이름 = `Program.name`에서 가져옴
- 활성 케이스가 위, 종결 케이스가 아래

## 6. 종결 케이스

종결된 케이스는 **접힌 상태(collapsed)**가 기본. 터치하면 펼쳐져서 전체 이력을 볼 수 있다.

```
  [미술치료 - 개별]              ← 활성 (펼쳐짐)
  2회차 진행 중 · 1개월째
  ...

  [놀이치료 - 개별]  종결  ▸    ← 종결 (접힘)
  12회 완료 · 6개월 · 2025.11~2026.04
```

- 종결 케이스 접힌 상태: 프로그램명 + "종결" 라벨 + 총 회차 + 기간
- 터치 → 펼침: 전체 회차 목록 표시 (활성 케이스와 동일 형태)

---

## 7. 진행 표시

| 조건 | 표시 |
|---|---|
| 총 회기수 정해져 있음 | 진행 바: `━━━━━━━━━━░░░░░░░░░░ 6/12회` |
| 총 회기수 없음 (일반적) | 텍스트: `6회차 진행 중 · 3개월째` |

**경과 기간 계산** (첫 회기 날짜 ~ 오늘):

| 경과 | 표시 |
|---|---|
| 1개월 미만 | "2주째" |
| 1~11개월 | "3개월째" |
| 12개월 이상 | "1년 2개월째" |

---

## 8. 완료 회차 접기

완료 회차가 5개 이상이면 최근 3건만 표시하고 나머지는 접는다.

```
  ✓ 5/14  상담 5회차  완료
  ✓ 5/7   상담 4회차  완료
  ✓ 4/30  상담 3회차  완료
  · · · 2건 더 보기              ← 터치하면 나머지 펼침
  ● 5/21  상담 6회차  D-2
```

## 9. 길찾기

**[길찾기] 버튼이 표시되는 조건**: 예정 회차(●, ○)이면서 센터 좌표 또는 주소가 있을 때.

| 상황 | 동작 |
|---|---|
| 좌표 있음 | 기기 기본 지도 앱으로 길찾기 (iOS: Apple Maps, Android: Google Maps) |
| 주소만 있음 | 주소 텍스트로 지도 앱 실행 |
| 둘 다 없음 | 버튼 미표시 |

## 10. 예외 및 에러

| 상황 | 동작 |
|---|---|
| 타임라인 로딩 실패 | 전체 화면 오브: "일정을 불러오지 못했어요" + [다시 시도] |
| 일부 센터 데이터만 실패 | 성공한 데이터만 표시 + 하단 배너: "일부 센터 정보를 불러오지 못했어요" |
| 일정이 하나도 없음 | 오브: "아직 예정된 일정이 없어요" |
| 아래로 당겨서 새로고침 | 전체 재호출 |
