# F04. 검사 결과

> 센터에서 실시한 심리검사 결과를 열람하는 기능

**Phase**: MVP

---

## 유저 스토리

- 보호자로서, 우리 아이의 검사 결과를 앱에서 확인하고 싶다
- 내담자로서, 검사에서 어떤 결과가 나왔는지 알고 싶다
- 상담사로서, 검사 결과를 어디까지 공개할지 내가 결정하고 싶다

---

## 1. 전체 흐름

```
마이페이지 센터 카드 > "검사결과 N건" 터치 (→ F08)
    ↓
검사 결과 목록
    ↓ 개별 검사 터치
검사 결과 상세 (공개 수준에 따라 다름)
```

---

## 2. 공개 범위

검사 결과의 공개 범위는 **상담사가 결정**한다. 임상적 판단이 필요한 영역이므로 자동 공개하지 않는다.

| 수준 | 내담자에게 보이는 것 | 사용 예시 |
|---|---|---|
| **비공개** (기본값) | 검사 실시 이력만 (날짜 + 검사명) | 민감한 검사, 아직 결과 설명 전 |
| **요약 공개** | 해석 요약 + 종합 소견 | 대부분의 경우 |
| **전체 공개** | 점수 + 영역별 결과 + 종합 소견 | 자가진단형 검사, 경과 비교용 |

---

## 3. 검사 결과 목록

### 정상 흐름

1. 마이페이지 센터 카드에서 "검사결과 N건"을 터치한다
2. 해당 센터의 검사 결과 목록이 표시된다
3. 각 항목에 검사명, 날짜, 상담사 이름이 보인다

### 표시 규칙

| 공개 수준 | 목록에서 동작 |
|---|---|
| 비공개 | 검사명 + 날짜만 표시. 회색 처리. 터치 불가 |
| 요약/전체 공개 | 검사명 + 날짜 + "결과 보기 ›". 터치 가능 |

### 보호자인 경우

자녀별로 검사 결과가 구분된다. 자녀 이름이 섹션 헤더로 표시.

---

## 4. 검사 결과 상세

### 요약 공개일 때

```
← 종합심리검사

2026.05.10 실시
○○상담센터 · 김상담 선생님

[종합 소견]
전반적인 정서 상태는 또래 수준이며,
사회성 영역에서 약간의 주의가 필요합니다.

※ 자세한 내용은 담당 선생님과
  상담 시 확인해주세요.
```

### 전체 공개일 때

```
← 종합심리검사

2026.05.10 실시
○○상담센터 · 김상담 선생님

[영역별 결과]
정서 ──────── 양호
인지 ──────── 양호
사회성 ───── 주의 필요

[종합 소견]
전반적인 정서 상태는...

※ 자세한 내용은 담당 선생님과
  상담 시 확인해주세요.
```

**영역별 결과 시각화**:
- 양호: 초록 바
- 주의 필요: 주황 바
- 우려: 빨간 바

---

## 5. 종합 보고서

풀배터리 검사(여러 검사를 한번에 실시) 후 상담사가 발행하는 통합 보고서.

### 생성 플로우 (SaaS 측)

```
검사 실시 → AI 보고서 초안 생성 → 상담사 검수/수정 → 공개 범위 설정 → 발행
```

앱은 발행된 보고서만 열람. 생성/수정은 센터 웹에서만 가능.

### 보고서 화면

검사 결과 상세에서 "종합 보고서 보기 ›" 링크를 통해 진입.

```
← 종합 심리검사 결과

2026.05.10 실시 · ○○상담센터
김상담 선생님

[종합 소견]
전반적인 정서 상태는...

[영역별 결과]
정서 ──────── 주의 필요
인지 ──────── 양호
사회성 ───── 양호

※ 자세한 내용은 담당 선생님과
  상담 시 확인해주세요.
```

## 6. 예외 및 에러

| 상황 | 동작 |
|---|---|
| 비공개 검사 터치 시도 | 터치 불가 (disabled 상태, 회색) |
| 목록 로딩 실패 | 오브: "검사 결과를 불러오지 못했어요" + [다시 시도] |
| 상세 로딩 실패 | 스낵바: "결과를 불러오지 못했어요" |
| 접근 권한 없는 검사 접근 시도 | 목록에 아예 미노출 (서버에서 필터링) |
| 보고서가 아직 발행되지 않은 검사 | 목록에서 "결과 준비 중" 표시. 터치 불가 |

### 접근 권한 규칙

- 본인의 검사 결과만 볼 수 있다
- 보호자는 자녀의 검사 결과를 볼 수 있다
- 다른 내담자의 결과는 절대 노출되지 않는다
