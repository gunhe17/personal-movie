# 내담자 앱 기획 — 민감정보 동의 설계 확정안 (2026-07-09, 패널 라운드 1~6)

> v5 케이스 드리븐 완주(07-08) 후 첫 공통 과제. **서버 저장 대전환(07-08 ③R3)의 후속** — "동의 기반 전체 저장"의 그 동의를 설계한다.
> 패널에 **개인정보 법무(태오)** 추가. 기존 패널(기획 서연·UX 준호·치료사 하윤·실사용자 지민맘) 유지, 각 쟁점은 패널 논쟁 후 대표가 판정.

---

## 0. 결정 이력 (라운드별)

| R | 쟁점 | 판정 |
|---|---|---|
| 1 | 동의 시점 | **가입 시점 일괄** (대표 판정 — 패널 다수안인 하이브리드 기각). 게스트 둘러보기 → 첫 저장 행위에서 소셜 가입, 그 플로우 안에 동의 스택 일괄 배치. 기능 사용 순간에는 동의가 끼어들지 않고 **안내(투명성 표시)만**. 단서(태오): **일괄 ≠ 포괄** — 한 화면이되 항목은 법적으로 분리(각각 체크), 민감정보는 그 안에서도 별도 동의 |
| 2 | 동의 단위 | **민감정보도 필수.** 스택 = 필수 3(이용약관 · 개인정보 수집·이용 · 민감정보 수집·이용) + 선택(마케팅 등). 가입 = 전체 동의, **전체 동의 원탭** 제공(항목별 체크 병존 — 합법). 앱의 본질이 아이 기록이므로 구조를 정직하게 — 최소수집 원칙 관련 "동의 강제" 지적 리스크는 감수(대표 판정). 법정 명칭은 고지 본문에 정확히, 리드 문구는 "아이의 발달 기록을 안전하게 보관하기 위해" 톤으로 순화. 각 동의 항목은 4요소(목적·항목·보유기간·거부권과 불이익) 구비 |
| 3 | 정보주체 (아이) | **보호자 확인 2단.** ①② 아이 프로필 생성 시 자기신고 한 줄("저는 이 아이의 보호자입니다") + ③ 센터 연동 시 기존 절차(명부 확인·본인인증)를 **법정대리인 확인으로 공식화**(절차 추가 없이 법적 의미만 부여, 문서화만 추가). "본인" 프로필은 법정대리인 문제 자체가 없음 — 센터 유형 중립 원칙 성립. 분리·이혼 가정 방어선 = 가족 문지기(관리자) + 센터 명부 확인(기존 구조로 충분, 하윤). **14세 이상 자녀의 본인 동의는 이월** |
| 4 | 제3자 (녹음·공유) | 공유 토글 = **제3자 제공 동의** — 토글 자리에 제공받는 자(센터명·담당자)·목적·항목 "한 줄 + 펼침", OFF = 즉시 제공 중단. **녹음(선생님 목소리)은 발화 소속 센터에만 공유 가능, 타 센터에는 토글 자체가 없음** — 본인 발화가 본인 소속으로 돌아가는 구조라 리스크 낮음. 전체 공유 허용은 치료사 칠링 이펙트·본진 영업 리스크·목소리 주인 미동의로 기각, 가족 전용은 병행 니즈(A센터 말을 B센터에 정확히 전달)를 과하게 막아 기각. 내용의 타 센터 전달은 메모 경로(추후 STT·AI 요약으로 개선). 상담사 화면엔 "보호자 동의 하에 공유된 자료" 대칭 표시 |
| 5 | 출구 (철회·삭제) | **나가는 문 4개.** ① 동의 철회 · ② 탈퇴 = **기록 내보내기 먼저 제안**(초진 정렬 화면과 같은 엔진, "떠나도 기록은 당신 것") → **30일 복구 유예**(재로그인 시 복구, "복구 목적 한시 보관" 고지로 적법) → 완전 파기. 민감정보 철회 시 보관 근거가 사라지므로 "철회하되 기록 유지"는 성립 안 함. ③ 센터 연결 해제 = 파기 아닌 **제공 중단** — 복사본 없는 "보여주기 허용" 모델이라 상담사 화면에서 즉시 소멸, 파생 카드(예약 등)는 사라지되 **원장 마디(사실 기록)는 유저 소유로 보존**("내 것은 계속 내 것"). ④ 가족 내보내기 = 접근권 회수, 작성 기록은 아이 타임라인에 보존(작성자 표시) — **"구성원 작성 기록은 아이 기록의 일부" 약관 명시**(작성자 삭제 요구 회색지대 방어) |
| 6 | 투명성 표면 (가드레일 ④) | **상태 배지 계단형.** 목록 = 아이콘만(🔒 나와 가족만 / 공유 중) → 상세 = 구체적 한 줄("해맑음센터 김○○ 선생님이 볼 수 있어요" — 사람이 떠올려지는 수준, 하윤) → 탭 = 펼침(누가·어떤 항목·언제부터). 입력 화면(작성·촬영·녹음 시작)엔 한 줄 전문 상시(읽을 동기가 있는 자리). 공유 OFF 시 "이제 나와 가족만 볼 수 있어요" 확인 피드백. 모든 카드 텍스트 상시는 "글 최소" 충돌 + 배너 블라인드로 기각. 허브 = **마이 > "내 기록과 동의"** — 동의 현황(항목별)·역방향 공유 목록(어떤 기록이 어느 센터에 열려 있나)·내보내기·철회·탈퇴 집결 |

## 1. 가입 동의 스택 (화면 골격)

```
게스트 둘러보기 (동의 없음 — 시작 질문·디렉터리·제도 정보)
 └─ 첫 저장 행위 (기록 작성 · 찜 · 리마인더)
     └─ 소셜 로그인 → 동의 스택 한 장
         [전체 동의]  ← 원탭
         ├─ (필수) 서비스 이용약관
         ├─ (필수) 개인정보 수집·이용 — 계정·글 기록·일정·전화 이력
         ├─ (필수) 민감정보 수집·이용 — 아이 발달·건강 관련 기록(글·사진·영상·녹음), 암호화 저장
         └─ (선택) 마케팅 정보 수신
         리드 문구: "아이의 기록을 안전하게 보관하기 위해 동의가 필요해요" (감수 대상)
     └─ 아이 프로필 생성 시: "저는 이 아이의 보호자입니다" 확인 한 줄 (별도 화면 아님)
```

- 온보딩(설치 직후)에는 동의도 약속 선언도 없음 — R1에서 일괄형 채택으로 "약속 선언 화면" 아이디어는 미채택(시안 단계에서 브랜드 화면으로 재검토 가능은 열어둠).
- 녹음의 **양해 프레임**("잊어버릴까 봐 담아둘게요")은 법적 동의와 별개 층 — 가입 때 동의를 받았어도 녹음 시작 화면에 유지(②R 보강 확정 그대로).

## 2. 원칙과의 접합

| 기존 확정 | 이 설계에서의 위치 |
|---|---|
| 가드레일 ① 암호화 | 민감정보 동의 고지 본문에 명시 |
| 가드레일 ② 접근 = 본인 + 항목별 허용 담당자 | 공유 토글(R4) + 계단형 배지(R6)가 구현체 |
| 가드레일 ③ 2차 활용 금지 | 동의 고지에 "AI 학습 등 다른 목적 사용 안 함" 명시 — 별도 동의 없인 불가 |
| 가드레일 ④ 투명성 한 줄 | R6 계단형으로 구현 수준 확정 |
| 첫 저장 시 가입 | R1 일괄 동의의 시점과 동일 — 구조 충돌 없음 |
| 가족 2등급 (③R4) | 구성원도 자기 가입 시 동일 스택. 아이에 대한 법정대리인 동의는 관리자 1개로 성립, 구성원 접근권은 관리자의 초대가 부여 |
| 연결 4경로 (③R2) | 어느 경로든 본인인증 시점에 법정대리인 확인 공식화(R3) 부착 |
