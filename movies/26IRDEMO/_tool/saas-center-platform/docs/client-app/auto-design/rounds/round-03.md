# Round 03 — 홈 정보 위계 — 비연동/단일센터/멀티센터 상태별

## 주제/긴장
홈은 앱이 두 질문("다음에 뭐 하지?" / "우리 애 어디까지 했지?")에 0.5초 안에 답해야 하는 단일 화면(F02)이다. R2에서 확정된 2탭·상태무관 고정 프레임 위에서, 세 상태(비연동 / 단일센터 / 멀티센터)와 역할(본인 / 보호자)에 따라 **정보 위계와 스크롤 순서**만 결정한다. 센터 필터칩·집계 데이터 소스는 R6, 셀프체크 결과 화면 위계는 R8, relation 인가는 R9로 경계를 지킨다.

- **T1 (미소속 정체성 vs activation)**: 비연동홈을 콘텐츠 소비 화면이 아닌 '연결 깔때기'로 위계화. CTA를 첫 뷰포트 1순위로 고정.
- **T2 (단일 vs 멀티센터 복잡도)**: 센터 수로 레이아웃을 분기하지 않고, 동일 통합 타임라인 컴포넌트 + 카드 내 센터 라벨로 흡수. 위계는 '상태×역할'로만 결정.

## A · 옹호 주장 (근거 포함)
- **비연동홈 위계 = 센터 연결 CTA(첫 뷰포트, 1순위) > 셀프체크(2) > 고정 매거진(3)** (px): R1 activation 깔때기 재정의의 직접 귀결. CTA가 셀프체크 아래로 밀리면 깔때기 입구가 막힘. F02 명세도 오브 멘트 직하에 [센터 코드로 연결하기] 배치.
- **셀프체크 결과 화면 하단에 연결 유도 CTA를 깔때기 종착점으로 배치** (px): 결과 비저장(R1) 정책상 점수를 본 직후 전환 의지가 정점인 순간에 연결 유도. 정적 CTA만이라 백엔드 0.
- **소속홈 행동 우선 위계 = 오브멘트 > 다음 일정 > (P2 미션) > 매거진** (px): '다음에 뭐 하지' 1차 질문에 행동 정보(언제·어디·길찾기)를 맥락 정보(진행률·읽을거리)보다 위에 둬야 0.5초 응답 성립. 매거진 상단 승격은 소비앱처럼 보여 '동반자' 정체성과 충돌.
- **보호자 소속홈에서 자녀 이름별 섹션이 1차 그룹핑, 센터 라벨은 카드 내 2차** (px/code): 보호자 멘탈모델은 '민준이 일정'이지 '놀이치료센터'가 아님. R2 '자녀 섹션 1차 그룹핑' 확정의 홈 스크롤 구체화.
- **단일/멀티 홈 동일 통합 타임라인 컴포넌트 + 카드 내 센터 라벨, 센터 수로 위계 분기 안 함** (code): R2 통합 무전환·라벨 식별 MVP 확정. 단일은 라벨이 반복될 뿐 같은 컴포넌트로 자연 처리.
- **세 상태 공통 오브+멘트 최상단 고정** (code/px): 서버 무의존 로컬 렌더라 각 영역 독립 로딩 실패 시에도 화면이 비지 않음. R2 상태무관 프레임 일치.
- **승인 대기홈 = 대기 배너(멘트 교체) + 비연동 본문 재사용** (roi): 대기 중에도 셀프체크/매거진으로 이탈 방지. 별도 본문 신설은 명세 재작업 낭비.
- **빈 영역 미노출(빈 카드 금지)** (px): F02 핵심원칙. 일정 0건이면 영역 자체를 숨기고 오브 멘트로 대체, 상태 전환 시 위계가 자연 충전.

## B · 검증 반박 (근거 포함)
- 비연동홈 위계, 소속홈 행동 우선 위계, 자녀 섹션 1차 그룹핑, 단일/멀티 무분기, 오브멘트 최상단 고정, 빈 영역 미노출, 매거진 상단 승격 제외, 센터 수 분기 제외, 전역 스위처 제외 — **전부 인정**. R1/R2 결정과 F02·S01 명세의 직접 귀결.
- **셀프체크 결과 화면 하단 연결 CTA는 홈 위계 결정 대상 아님 → R8 연기** (roi/px): 이 라운드 주제는 홈 위계. 셀프체크 결과는 별도 화면(F05)이고 R8 소관. 라운드 경계를 넘어 미정 화면 위계를 선결하면 R8 자유도 침식. 또한 나쁜 점수 직후 연결 CTA는 미검증 px 가설이며 '불안 자극 후 영업'으로 읽힐 임상 신뢰 리스크 **T10** 동반. 원칙만 메모, 결정은 R8.
- **승인 대기홈은 본문 재사용 인정하되 최상단은 연결 CTA가 아닌 대기 안내로 교체** (px): 이미 코드 입력하고 승인 대기 중인 사용자에게 '연결하기' CTA를 재노출하면 가짜 미완료감. F02 대기홈 명세도 최상단을 '승인 대기 중' 멘트로 교체. 본문(셀프체크+매거진) 재사용은 OK, 1순위 위계만 교체 필수. 다중 센터 동시 대기는 멘트 영역, 상세는 마이로.

## 결정 요약
홈 위계는 **상태(비연동/대기/소속) × 역할(본인/보호자)로만 결정하고, 센터 수로는 분기하지 않는다**. 세 상태 공통으로 오브+멘트가 최상단(로컬 렌더, 폴백)에 고정되며 빈 영역은 미노출한다.

- **비연동홈** = 연결 CTA(첫 뷰포트 1순위) > 셀프체크 > 고정 매거진. activation 깔때기의 시각화.
- **승인 대기홈** = 본문(셀프체크+매거진)은 비연동과 재사용하되 **최상단은 연결 CTA가 아니라 '승인 대기 중' 안내로 교체** (B안 채택 — 이미 신청한 사용자의 가짜 미완료감 방지). 다중 센터 동시 대기는 멘트 영역에서 'N개 센터 대기', 상세는 마이로.
- **소속홈** = 오브멘트 > 다음 일정 > (P2 미션) > 매거진. 행동 정보가 맥락 정보보다 위. 보호자는 **자녀 이름별 섹션이 1차 그룹핑, 센터 라벨은 카드 내 2차**.
- **단일/멀티** = 동일 통합 타임라인 컴포넌트 + 카드 내 센터 라벨. 멀티 전용 장치(필터칩·집계 헤더)는 홈 위계에 넣지 않고 R6로 연기 — UI가 미정 백엔드를 강제하지 않도록 R2 연기 결정을 우회 번복하지 않는다.
- **셀프체크 결과 CTA**는 홈 위계가 아닌 F05 결과 화면 위계라 R8로 연기 (라운드 경계 + T10 신뢰 리스크 미검증). 원칙('결과를 상담사와 잇는 동선')만 메모.

**A의 두 주장(결과 CTA 홈 확정 / 대기홈 비연동 본문 완전 재사용)은 B의 라운드 경계·임상 신뢰·가짜 미완료감 근거가 더 강해 B안으로 판정한다.** 나머지 10개 항목은 양측 일치.

이전 라운드 번복 없음. R1·R2 결정을 위계 차원으로 구체화했을 뿐이며, 멀티센터 연기 결정(R2)을 그대로 보존했다.

## 남은 질문
- (R8) 셀프체크 결과 화면(F05) 위계와 톤: '결과 → 센터 연결' 동선을 어디에·어떤 톤으로 둘지. 고득점(고위험) 사용자에게 영업으로 읽히지 않을 임상 안전 카피(T10) 검증 방법.
- (R6) 멀티센터 '전체 합산' 데이터 소스 확정(백엔드 집계 엔드포인트 vs client-side N-call 머지)과 그 위에서 센터 필터칩 Phase2 재론.
- (R4/R5) 소속홈 '다음 일정' 카드의 정보 밀도: 길찾기·준비물·온라인 링크 등 어디까지 첫 뷰포트에 노출할지(행동 우선 위계의 구체 필드).
- (R9) 보호자 자녀 섹션의 relation 기반 인가 구현 범위·프라이버시, 본인+자녀 동시 보유 시(role=both) 본인 섹션과 자녀 섹션의 상하 위계.
- 승인 대기 멘트의 카피와, 여러 센터 동시 대기 시 멘트 영역 표현('N개 센터 대기')의 구체 문구(R8 톤과 연동).

## 다음 라운드로 이어받기
홈 위계는 '상태×역할'로만 결정(센터 수 무분기), 오브멘트 최상단 고정·빈 영역 미노출이 세 상태 공통 골격으로 확정됐다. 비연동=연결CTA>셀프체크>매거진, 대기=본문 재사용+최상단 대기안내 교체, 소속=오브멘트>일정>(미션)>매거진·보호자 자녀섹션 1차 그룹핑으로 못박혔다. 멀티 전용 장치는 R6, 셀프체크 결과 CTA 배치·톤은 R8로 넘겼다. 후속 라운드는 이 위계 골격을 건드리지 말고, 각 카드의 정보 밀도(R4/R5)·결과 화면 동선(R8)·relation 인가(R9)를 채운다.
