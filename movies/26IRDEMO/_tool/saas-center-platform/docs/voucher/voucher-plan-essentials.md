# 바우처 기능 기획 — 요약판

> 상세 버전: [`voucher-plan.md`](./voucher-plan.md) (전체 섹션·시나리오·Cross-cutting Concerns 포함)
> 이 문서는 **읽는 데 5분 이내**로 핵심만 전달하는 압축본이다.

---

## 1. 한 줄 요약

> **중앙화(P1 수동 관리) → 자동화(P2 AI·판별) → 정산(P3 사용 측정·청구)** 단계로, 상담센터가 정부·기관 바우처를 "관리할 수 있는 대상"으로 다루게 한다.

---

## 2. 왜 필요한가

- 한국 심리상담 시장에서 바우처(전국민 마음투자·청년마음건강 등)는 단순 할인이 아니라 **정부 지원금 + 본인부담금 이중 결제 + 회기·증빙 의무**가 걸린 복합 결제 수단
- 현재 센터는 이를 **수기·엑셀**로 관리 → 중복 사용·회기 초과·청구 누락·감사 리스크
- 상담사는 **바우처 제출용 일지를 센터 내부 일지와 별도로 재작성**하는 반복 노동

---

## 3. Phase 로드맵

| Phase | 테마 | 한 줄 약속 | 핵심 기능 |
|---|---|---|---|
| **P1** | 중앙화·수동 관리 | "바우처가 시스템 안에서 관리된다" | 카탈로그 등록 · 센터 취급 바우처 설정 · 내담자 바우처 **수동 등록/조회** · 잔여 회기 수동 갱신 |
| **P2** | AI·자동화 | "담당자가 직접 판별·재작성하지 않아도 된다" | **2A** AI 상담일지 양식 변환 · **2B** 자격 판별·추천 |
| **P3** | 정산·감사 | "모든 사용이 정확히 기록·청구·감사 대응된다" | 자동 회기 차감 · 중복 방지 · 월별 청구 집계 · 감사 증빙 관리 |

**P1의 현실적 성격**
- 잔여 회기·만료일은 **플랫폼 내부 기록값**. 공공 시스템과 실시간 동기화되지 않으며, 담당자가 외부(국민행복카드 앱·복지로 등)에서 확인한 값을 직접 입력
- 자동 판별·자동 차감은 모두 P2/P3 영역

**초기 타겟**: **전국민 마음투자 지원사업 1종** (확장은 그 이후)
**데이터 소스**: **super_admin 수동 큐레이션** (공공 API 없음, 크롤링도 ROI 낮음)

## 5. 핵심 정책 (반드시 짚고 갈 것)

1. **자격 판별은 안내이지 확정이 아니다** — 최종 승인은 복지로·지자체 소관. UI에 명시
2. **지원금과 본인부담금은 분리 결제·분리 환불** — 소득분위별 본인부담률 차등
3. **회기 차감 타이밍**: 상담 **종료 후 완료 처리** 시점 (초안 권장)
4. **복수 바우처 동시 보유** 가능 → 차감 우선순위 규칙 필요 (만료 임박 우선 + 수동 오버라이드)
5. **상담과 검사의 차감 방식이 다르다** — 상담 = 세션 1건 = 1회기, 검사 = 케이스 단위 + 바우처별 환산율
6. **증빙 5년 보존 의무** — 상담일지·청구서·동의서·변동 로그
7. **민감정보(소득·검사 점수)는 별도 동의 기반 수집**, 접근 권한 최소화

## 6. 놓치기 쉬운 핵심 고려사항

원본 문서의 13개 Cross-cutting Concerns 중 **우선순위 상위**만.

- **법률 근거**: 사회서비스이용권법 — 부정수급 시 제공기관 행정 처분 리스크
- **상담사 자격증 만료 추적** — 만료자의 세션은 청구 불가
- **제공기관 등록번호** — 바우처별로 다름 (한 센터도 사업마다 별도)
- **바우처 단가·본인부담률 변경 시 버전 관리** — 시행일 전후 청구 분리
- **바우처 미사용 센터와의 공존 (Opt-in)** — 기본 꺼짐, 센터가 켜야 노출
- **모바일·웹 동기화** — 같은 세션 중복 처리 방지 (idempotency 키)
- **감사 로그 영구 보존** — 발급·차감·취소·수정 전체 이력

## 7. 지금 결정해야 할 사항 (Open Questions 핵심)

전체 11개 Open Questions 중 **착수 전 가장 먼저 확정**해야 할 것.

1. **회기 차감 타이밍** — 상담 종료 시 vs 관리자 승인 시
2. **복수 바우처 보유 시 우선순위 규칙** — 만료 임박? 부담률 낮은 것? 수동?
3. **Phase 2 AI 모델 사용 시 개인정보 전송 범위** — 법무 검토 필요
4. **상담·검사 차감 환산 규칙 표현 방식** — JSON 조건식? 계산 표?
5. **바우처 기능 유료 플랜 gating 여부** — subscription 모듈 연동 범위
6. **3개 플랫폼 출시 순서** — 웹 우선? 웹·모바일 동시?

## 8. 성공 지표 (요약)

- **P1**: 엑셀 관리 병행 비율 감소, 담당자 교체 인수인계 시간
- **P2**: AI 초안 그대로 승인 비율 60%+ / 자격 판별 정확도 95%+
- **P3**: 월별 청구 누락률 1% 미만 / 중복 차감 사고 0건
