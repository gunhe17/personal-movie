## 🎯 한 줄 요약

> **중앙화 → 자동화 → 정산** 3단계로, 상담센터가 정부·기관 바우처를 "관리할 수 있는 대상"으로 다루게 한다.

---

## ❓ 왜 필요한가

📌 **한국 심리상담 시장에서 바우처는 단순 할인이 아니다**
- 정부 지원금 + 본인부담금의 **이중 결제 구조**
- 회기 수·유효기간·증빙 의무가 따라붙는 **복합 결제 수단**

📌 **현재 센터의 고통**
- 수기·엑셀 관리 → 중복 사용·회기 초과·청구 누락
- 상담사가 **바우처 제출용 일지를 센터 내부 일지와 따로 재작성**하는 반복 노동
- 감사 대응 시 5년치 증빙을 분산된 곳에서 취합

📌 **도입 효과**
- 센터 수익 보호 (누락·중복 방지)
- 상담사 업무 경감 (AI 일지 변환)
- 접수 품질 향상 (자동 자격 추천)
- 감사·보고 대응력 향상

---

## 🗺️ Phase 로드맵

| Phase | 🎨 테마 | 한 줄 약속 |
| --- | --- | --- |
| **P1** | 🗂️ 중앙화·수동 관리 | 바우처가 시스템 안에서 관리된다 |
| **P2** | 🤖 AI·자동화 | 담당자가 직접 판별·재작성하지 않아도 된다 |
| **P3** | 💰 정산·감사 | 모든 사용이 정확히 기록·청구·감사된다 |

### 📦 Phase별 핵심 기능

**P1 — 중앙화**
- 바우처 카탈로그 등록 (super_admin)
- 센터 취급 바우처 설정 (센터 관리자)
- 내담자 바우처 **수동 등록·조회** (접수·상담사)
- 잔여 회기 **수동 갱신**

**P2 — AI·자동화**
- **2A**: AI 상담일지 양식 자동 변환
- **2B**: 내담자 자격 판별·추천

**P3 — 정산·감사**
- 자동 회기 차감 + 중복 방지
- 월별 청구 집계
- 감사 증빙 관리

### ⚠️ P1의 현실적 성격

> 🔍 **P1의 "잔여 회기"는 공공 시스템 실시간 값이 아니다**
>
> - 플랫폼 내부의 **수동 기록값**
> - 담당자가 외부(국민행복카드 앱·복지로 등)에서 확인한 값을 직접 입력·갱신
> - 자동 판별·자동 차감은 모두 P2/P3 영역
>
> 즉, P1은 "엑셀에 적던 걸 플랫폼 DB로 옮긴" 수준이 본질. 이 정직함이 기획의 출발점.

### 🎯 초기 타겟

- **전국민 마음투자 지원사업 1종** (확장은 그 이후)
- **데이터 소스**: super_admin 수동 큐레이션 (공공 API 없음)

## 📱 플랫폼별 역할

| 기능 | 🌐 SaaS 웹 | 📱 전문가 앱 | 👤 내담자 앱 *(미래)* |
| --- | --- | --- | --- |
| 카탈로그·취급 바우처 설정 | ✅ | ❌ | ❌ |
| 내담자 바우처 등록 (P1) | ✅ | △ 간이 | ❌ |
| 잔여 회기 조회 | ✅ | ✅ *(내 담당)* | ✅ *(본인)* |
| 수동·자동 회기 차감 | ✅ | ✅ | ❌ |
| AI 일지 변환 (P2A) | ✅ | ✅ 트리거 | ❌ |
| 자격 판별 (P2B) | ✅ | ✅ 간이 | ✅ 본인용 |
| 전자 서명·증빙·자가진단 | △ 대리 | △ 태블릿 | ✅ 직접 |

> 💡 **설계 배려**
> P1 데이터 모델에 **"입력 주체"(staff / client) 구분 필드**를 미리 둔다.
> 내담자 앱이 도입될 때 데이터 재구축 없이 매끄럽게 전환되게 한다.

## 📐 핵심 정책

> ⚖️ **반드시 짚고 갈 7가지 원칙**

1. 🚨 **자격 판별은 "안내"이지 "확정"이 아니다** — 최종 승인은 복지로·지자체 소관
2. 💳 **지원금·본인부담금은 분리 결제·분리 환불** — 소득분위별 본인부담률 차등
3. ⏱️ **회기 차감 타이밍**: 상담 **종료 후 완료 처리** 시점
4. 🎫 **복수 바우처 동시 보유 가능** → 만료 임박 우선 + 수동 오버라이드
5. 🧪 **상담·검사는 차감 방식 다름** — 상담 1세션 = 1회기, 검사는 케이스별 환산
6. 📚 **증빙 5년 보존 의무** — 상담일지·청구서·동의서·변동 로그
7. 🔐 **민감정보 별도 동의 기반 수집** — 소득·검사 점수·진단 정보

## ⚠️ 놓치기 쉬운 핵심 고려사항

> ⭐ 원본 13개 Cross-cutting Concerns 중 **우선순위 상위만**

- ⚖️ **법률 리스크**: 사회서비스이용권법 부정수급 시 행정 처분
- 🎓 **상담사 자격증 만료 추적** — 만료자의 세션은 청구 불가
- 🏢 **제공기관 등록번호**는 바우처별로 다름 (한 센터도 사업마다 별도)
- 📆 **단가·본인부담률 변경 시 버전 관리** — 시행일 전후 청구 분리
- 🎛️ **바우처 미사용 센터와의 공존** — Opt-in, 기본 꺼짐
- 🔄 **모바일·웹 동기화** — 중복 처리 방지 (idempotency 키)
- 📖 **감사 로그 영구 보존** — 발급·차감·취소·수정 전체 이력

## 📊 성공 지표

### P1 — 중앙화
- 엑셀 관리 병행 비율 감소율

- 월별 청구 누락률 **1% 미만**

- 감사 증빙 출력 가능률 **100%**
