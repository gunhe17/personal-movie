## 서비스별 상세 분석

### 1. Mingl (밍글) - 예약 중심 관리

#### 핵심 기능
**예약 관리**:
- 상담 일정 등록 → 자동 예약 알림 발송
- 내담자 앱에서 예약 확인 및 예정된 상담 조회

**고객 관리**:
- 모든 내담자 상담 정보 한눈에 조회
- 상담 기록 작성 (내담자도 작성 가능)

**검사 관리**:
- 심리검사 발송 및 결과 확인 간소화
- 내담자가 받은 검사 결과 조회

**서류 관리**:
- 상담 신청서, 동의서, 인테이크 폼 발송
- 전자서명 지원 (추정)

**커뮤니케이션**:
- 상담사-내담자 채팅 (연락처 노출 없이 안전하게 소통)

#### 회계/결제 관리 기능
**확인된 정보**: 없음

**분석**:
- 공식 웹사이트 및 앱스토어 설명에 매출 관리, 수납, 정산 기능 언급 없음
- **예약 및 상담 기록 관리에 특화**된 것으로 보임
- 결제는 별도 시스템(포스, 현금영수증 단말기 등) 사용 추정

#### 시사점
- 회계 기능을 포함하지 않아도 서비스 출시 가능 (MVP 전략)
- 예약 관리만으로도 상담센터에 가치 제공 가능

### 2. 마음주의 (Mindism) - 급여 정산 중심

#### 핵심 기능
**통합 관리**:
- "서비스 예약부터 급여 정산까지 한 번에"
- PC + 모바일 지원

**고객 정보 관리**:
- 고객 정보 및 캘린더 간편 관리
- CRM 기능 (무료)

**커뮤니케이션**:
- WEB 발신 문자 발송
- 온라인 화상 서비스 체계 활용

**자동화**:
- "상담과 수업 예약부터 자동 알림까지"

#### 회계/결제 관리 기능
**명시된 기능**:
- ✅ **급여 정산**: "예약부터 급여 정산까지 한 번에"
- ✅ **수납 관리**: 공식 설명에 포함

**추정 기능**:
- 상담사별 급여 계산 (프리랜서 상담사 타겟)
- 매출 조회 (기본적인 수준)

**미확인**:
- 포스기 연동 여부
- 상세 보고서 기능
- 세금계산서 발행

#### 특징
- **Freemium 모델**: 무료 CRM 제공 → 유료 기능 추가 판매 추정
- **프리랜서 타겟**: 센터보다는 개인 상담사에 최적화된 것으로 보임

#### 시사점
- 급여 정산 기능을 핵심 가치로 제시
- B2C (센터 → 내담자) 수납보다 B2B (센터 → 상담사) 정산에 초점

### 3. 에피 (EpiPro) - 매출 관리 올인원

#### 핵심 기능
**매출 관리 (가장 상세)**:
- 개인상담, 집단상담, 이용권, 바우처 매출 관리
- 미수금, 위약금 관리
- 수익 + 환불 + 정산 통합 관리

**이용권 매출**:
- 회기 수, 사용 내역, 잔여 횟수 **자동 계산**
- 이용권 매출 별도 관리

**바우처 매출**:
- 바우처 지원금 + 자기부담금 분리 기록
- 회기별 · 완납 형태 관리

**팀원 정산**:
- 상담사별 상담종류별 매출 확인
- 상담사별 정산 비율/고정금액 설정
- 참석 상태에 따라 **자동 계산**

**위약금 관리**:
- 노쇼 · 당일취소 위약금 설정
- 실제 받은 위약금 매출 확인

**미수금 관리**:
- 결제 완료 여부 확인
- 미수금 추적

**자동 분류**:
- 상담종류별, 바우처별, 상담선생님별, 결제수단별 자동 분류

#### 회계/결제 관리 기능
**명시된 기능**:
- ✅ **매출 관리**: 매우 상세 (7가지 유형)
- ✅ **정산 관리**: 상담사별 자동 계산
- ✅ **미수금 관리**: 별도 추적
- ✅ **위약금 관리**: 노쇼/취소 별도 처리

**자동화 수준**:
- 🟢 **높음**: 회기 수, 잔여 횟수 자동 계산
- 🟢 **높음**: 상담사 정산 자동 계산
- 🟢 **높음**: 매출 자동 분류

**미확인**:
- 포스기 연동 여부
- 현금영수증/세금계산서 발행
- 회계 보고서 (손익계산서 등)

#### 특징
- **경쟁사 중 가장 강력한 매출 관리 기능**
- 바우처(정부 지원금) 관리 지원 → 한국 상담센터 특화
- 이용권(회기제) 관리 → 상담센터 비즈니스 모델 이해도 높음

#### 시사점
- 매출 관리를 핵심 차별화 포인트로 선택
- 수기 입력 방식이지만 자동 계산으로 편의성 제공
- 포스기 없이도 충분한 가치 제공 가능

## 핵심 인사이트

### 1. 포스기 연동은 필수가 아니다

**발견**:
- **모든 경쟁사에서 포스기 연동 명시 없음**
- 에피, 케어플센터 등은 300+ 기관 사용 중 → 포스기 없이도 시장 검증됨

**이유**:
1. **포스기 비통합 현실**: 각 센터마다 다른 포스 시스템 (또는 없음)
2. **수기 입력 수용**: 자동 계산 기능으로 보완 시 센터가 수용
3. **우선순위**: 예약, 고객 관리, 상담 기록이 더 중요

**전략 제안**:
- Phase 1: 포스기 연동 없이 출시 (수기 입력 + 자동 계산)
- Phase 2: Open API 제공 (센터가 자체 연동)
- Phase 3: 주요 포스 시스템 개별 연동 (점유율 높은 순서)

---

### 2. 매출 관리의 핵심은 "자동 계산"

**에피의 성공 요인**:
- 회기 수, 잔여 횟수 **자동 계산**
- 상담사 정산 **자동 계산**
- 매출 유형별 **자동 분류**

**사용자 Pain Point 해결**:
- ❌ Before: 엑셀로 수동 계산 → 실수, 시간 낭비
- ✅ After: 시스템이 자동 계산 → 정확성, 효율성

**필수 자동화 기능**:
1. **이용권 회기 관리**: 10회 이용권 구매 → 상담 1회 → 잔여 9회 자동 계산
2. **바우처 지원금 계산**: 정부 지원 80% + 자기부담 20% 자동 분리
3. **상담사 정산**: 매출의 60% 정산 설정 → 자동 계산
4. **미수금 추적**: 결제 완료/미완료 자동 표시

---

### 3. 바우처(정부 지원금) 관리는 한국 특화 기능

**발견**:
- 에피에서 바우처 관리 강조
- 정부 바우처 사업 (아동·청소년 심리지원, 발달재활 서비스 등)

**바우처 특징**:
- 정부 지원금 + 자기부담금 분리
- 회기별 또는 완납 형태
- 정산 시 지원금/자기부담금 구분 필요

**우리 시스템 필수 고려**:
- 바우처 매출 별도 관리
- 지원금 vs 자기부담금 분리 입력
- 바우처 정산 보고서 (정부 제출용)

---

### 4. 이용권(회기제) 관리는 상담센터 핵심 비즈니스

**상담센터 수익 모델**:
- 단일 상담 (1회 결제)
- **이용권** (10회, 20회 등 패키지 판매) ← 주요 수익원

**이용권 관리 요구사항**:
1. 이용권 생성: "10회 이용권, 100만원"
2. 사용 추적: 상담 1회 → 잔여 9회
3. 만료 관리: 3개월 유효기간
4. 환불 처리: 사용 3회, 잔여 7회 환불

**에피의 접근**:
- 회기 수, 사용 내역, 잔여 횟수 **자동 계산**
- 별도 매출 카테고리로 관리

---

### 5. 팀원 정산은 B2B 비즈니스 (센터 → 상담사)

**발견**:
- 마음주의: "급여 정산까지 한 번에"
- 에피: "상담사별 정산 자동 계산"

**상담센터 운영 특징**:
- 정규직 상담사 (월급제)
- 프리랜서 상담사 (건당 정산)
- 혼합 모델 (기본급 + 인센티브)

**정산 시나리오**:
1. **건당 정산**: 상담 1회 = 5만원 지급
2. **비율 정산**: 매출의 60% 지급
3. **고정급 + 인센티브**: 월 200만원 + 초과 상담 1회당 3만원

**필수 기능**:
- 상담사별 정산 규칙 설정
- 참석 상태 추적 (출석, 노쇼, 취소)
- 월별 자동 정산 계산

---

### 6. 미수금 관리는 센터의 큰 Pain Point

**발견**:
- 에피에서 미수금 관리 별도 강조

**상담센터 현실**:
- 내담자가 당일 결제 못함 → 미수금 발생
- 관리 소홀 → 미수금 누적 → 현금 흐름 악화

**필수 기능**:
1. 미수금 자동 기록 (결제 완료 여부 체크)
2. 미수금 알림 (센터 관리자, 상담사)
3. 미수금 추적 리포트 (내담자별, 기간별)
4. 미수금 회수 시 자동 업데이트

---

### 7. 위약금 관리는 노쇼 문제 해결

**발견**:
- 에피에서 노쇼 · 당일취소 위약금 관리 지원

**상담센터 문제**:
- 노쇼(no-show): 예약했지만 나타나지 않음
- 당일 취소: 상담사 시간 낭비

**위약금 정책 예시**:
- 노쇼: 상담료의 100%
- 당일 취소: 상담료의 50%
- 전날 취소: 위약금 없음

**필수 기능**:
1. 위약금 정책 설정 (노쇼, 당일취소 등)
2. 예약 상태 추적 (출석, 노쇼, 취소)
3. 위약금 자동 계산
4. 위약금 매출 별도 집계

## 우리 시스템 설계 방향

### Phase 1: MVP (포스기 없는 회계 시스템)

**목표**: 에피 수준의 매출 관리 기능 제공 (수기 입력 + 자동 계산)

#### 필수 기능

**1. 수납 관리 (Payment)**
- 수납 유형: 개인상담, 집단상담, 이용권, 바우처, 기타
- 결제 수단: 현금, 카드, 계좌이체, 바우처
- 결제 상태: 완료, 미수금, 환불
- 수기 입력: 날짜, 금액, 수단, 내담자, 상담사

**2. 이용권 관리 (Package)**
- 이용권 생성: 회기 수, 금액, 유효기간
- 사용 추적: 상담 시 자동 차감
- 잔여 회기: 실시간 계산
- 만료 알림: 유효기간 임박 시

**3. 바우처 관리 (Voucher)**
- 바우처 유형: 아동청소년심리지원, 발달재활서비스 등
- 지원금/자기부담금 분리 입력
- 회기별 정산 (정부 제출용)

**4. 팀원 정산 (Staff Settlement)**
- 상담사별 정산 규칙 설정 (건당, 비율, 고정급)
- 참석 상태 기반 자동 계산
- 월별 정산 보고서

**5. 미수금 관리 (Unpaid)**
- 미수금 자동 기록 및 추적
- 내담자별 미수금 현황
- 미수금 알림 (SMS, 앱 푸시)

**6. 위약금 관리 (Penalty)**
- 위약금 정책 설정 (노쇼, 취소 등)
- 예약 상태 추적
- 위약금 자동 계산

**7. 매출 보고서 (Revenue Report)**
- 일별/월별 매출 집계
- 상담사별 매출 (정산용)
- 결제 수단별 매출
- 바우처별 매출
- 미수금 현황

#### 자동화 전략

| 기능 | 수기 입력 | 자동 계산 |
|------|----------|----------|
| 수납 기록 | ✅ 날짜, 금액, 수단 입력 | ❌ |
| 이용권 차감 | ✅ 상담 기록 시 선택 | ✅ 잔여 회기 자동 계산 |
| 바우처 분리 | ✅ 지원금/자기부담 입력 | ✅ 합계 자동 계산 |
| 상담사 정산 | ❌ | ✅ 규칙 기반 자동 계산 |
| 미수금 추적 | ❌ | ✅ 결제 상태 기반 자동 |
| 위약금 계산 | ❌ | ✅ 정책 기반 자동 계산 |

#### 포스기 연동 없이 해결하는 방법

**문제**: 포스기 없이 어떻게 수납을 관리하나?

**해결책 1: 간소화된 입력 UX**
- 상담 종료 후 즉시 수납 기록 (원클릭)
- 자주 쓰는 금액 템플릿 (5만원, 10만원 등)
- 바코드/QR 스캔 (이용권 코드)

**해결책 2: 자동 계산으로 보완**
- 이용권 잔여 회기 자동 계산
- 바우처 지원금 자동 분리
- 상담사 정산 자동 계산
- 미수금 자동 추적

**해결책 3: 현금영수증/세금계산서 별도 처리**
- Phase 1: 센터가 기존 방식 유지 (별도 단말기)
- Phase 2: API 연동 (국세청 홈택스, 현금영수증 API)

---

### Phase 2: 확장 기능

#### 1. Open API 제공
- 센터가 자체 포스 시스템과 연동 가능
- Webhook으로 수납 데이터 자동 동기화

#### 2. 주요 포스 시스템 연동
- 시장 조사 후 점유율 높은 순서로 연동

#### 3. 회계 보고서 고도화
- 손익계산서 자동 생성
- 세금 신고용 리포트 (부가세, 종합소득세)
- 비용 관리 (임대료, 인건비 등)

#### 4. 예측 분석
- 다음 달 예상 매출 (머신러닝)
- 이용권 환불 예측
- 미수금 회수 가능성 예측

## 결론 및 다음 단계

### 핵심 결론

1. **포스기 연동은 Phase 1에서 불필요**
   - 경쟁사들도 포스기 연동 없이 시장 검증됨
   - 수기 입력 + 자동 계산으로 충분한 가치 제공

2. **자동 계산이 핵심 차별화**
   - 이용권 회기, 바우처 분리, 상담사 정산 자동화
   - 에피가 이 전략으로 성공

3. **바우처 관리는 한국 시장 필수**
   - 정부 지원 사업 다수
   - 지원금/자기부담금 분리 관리 필요

4. **이용권 관리는 상담센터 수익 모델 핵심**
   - 회기제 패키지 판매가 주요 수익원
   - 잔여 회기 자동 계산 필수

5. **미수금/위약금 관리는 센터 Pain Point**
   - 현금 흐름 관리의 핵심
   - 자동 추적 및 알림 필요
