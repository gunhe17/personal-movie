# 마인드엔서 내담자 앱 — 미해결 이슈

> 기획 논의 중 발생한 애매한 사항, 추가 논의 필요 항목을 추적하는 문서
> 최종 수정: 2026-05-19

---

## 미해결 이슈

### ISSUE-001: 최근 노트 기능 방향
- **상태**: 보류
- **내용**: 상담사가 내담자에게 노트를 발행하는 기능. 의도된 기능이 아니라 기획 중 나온 아이디어.
- **쟁점**:
  - 상담사가 매 회기마다 별도 노트를 쓰는 건 부담
  - 상담 내용 중 공개 범위에 대한 전문적 판단 필요
  - 실제 수요 검증 안 됨
- **결정**: Phase 2로 보류, 추가 논의 필요

### ISSUE-002: 데이터 삭제 정책
- **상태**: 보류
- **내용**: 센터 종결/탈퇴 시 내담자 데이터 삭제 범위
- **쟁점**:
  - 심리상담 기록 보관 의무 기간 (법적 검토 필요)
  - 내담자의 삭제 요청권 (개인정보보호법)
  - 센터 재방문 시 이력 연속성
- **결정**: MVP는 종결 = 읽기 전용, 삭제 정책은 법률 검토 후 별도 수립

### ISSUE-003: 오브 캐릭터 이름
- **상태**: 미정
- **내용**: 캐릭터에 이름을 부여할 것인지, 서비스명(마인드엔서)과 연결할 것인지
- **쟁점**: 이름이 있으면 애착이 생기지만, 이름 짓기에 브랜딩 리소스 필요

### ISSUE-004: 내담자 앱 용어 매핑
- **상태**: 진행 중
- **내용**: 센터 관리 용어를 내담자 앱에 맞게 변환하는 매핑 체계 필요
- **확정된 매핑**:
  - `completed` → "완료" (✓, 정상 톤)
  - `no_show` → "미방문" (─, 흐린 톤)
  - `scheduled` → 다음 회차는 강조(●), 먼 미래는 흐림(○)
  - `cancelled` → 타임라인에서 미노출
- **쟁점**: 참여자 attendance_status(absent, late, excused)도 내담자 앱에서 표시할지 검토 필요

### ISSUE-005: 종결된 케이스 타임라인 표시
- **상태**: 미정
- **내용**: 같은 센터에서 이전 케이스 종결 후 새 케이스 시작 시, 종결된 케이스를 타임라인에 어떻게 보여줄지
- **쟁점**:
  - 종결 케이스도 이력으로 보여줘야 하는지
  - 보여준다면 접힌 상태(collapsed)로 보여주는 게 적절한지
  - 마이페이지의 종결 센터와 구분 필요 (같은 센터 내 케이스 종결 vs 센터 자체 종결)

### ISSUE-006: 애플 로그인 지원 추가
- **상태**: 개발 필요
- **내용**: Account.provider에 현재 "email", "kakao", "naver", "google"이 있지만 "apple"이 없음
- **쟁점**:
  - iOS 앱에서 소셜 로그인 제공 시 애플 로그인은 App Store 심사 필수 요건
  - 애플은 이메일 숨기기(Private Relay) 기능이 있어서 이메일 기반 매칭에 주의 필요
- **결정**: provider에 "apple" 추가 필요, 애플 특유의 인증 흐름 구현 필요

### ISSUE-007: 소셜 로그인 시 전화번호 입력 시점
- **상태**: 확정
- **내용**: 소셜 로그인으로 가입 시 전화번호를 언제 입력받을 것인지
- **결정**: 센터 코드 입력 시점에 전화번호 입력 + SMS 인증번호 확인
- **이유**: 
  - 가입 직후 입력은 이탈률 증가
  - NICE 본인인증은 MVP에 과도
  - 센터가 최종 승인 권한을 가지므로 번호 소유 확인만으로 충분
  - 미소속 유저는 전화번호 없이도 앱 사용 가능

### ISSUE-008: 디바이스 토큰 관리 (다중 기기)
- **상태**: 개발 필요
- **내용**: 내담자 앱 FCM 디바이스 토큰 저장/관리
- **쟁점**:
  - 한 사용자가 여러 기기에서 로그인 가능 (폰 + 태블릿)
  - 부모 양쪽 각각 별도 기기 → 각각 알림 수신
  - 로그아웃 시 토큰 해제 처리
  - 기존 전문가 앱 FCM 구조를 재사용할 수 있는지 확인 필요

### ISSUE-009: 앱 이름 확정
- **상태**: 임시 확정
- **내용**: 내담자 앱 이름을 "마인드엔서"로 임시 결정
- **쟁점**:
  - 전문가 앱과 이름 구분 필요 여부 (같은 이름이면 스토어에서 혼동)
  - "마인드엔서 for 내담자" / "마인드엔서 케어" 같은 서브 네이밍 검토
  - 브랜딩 관점에서 최종 결정 필요

### ISSUE-010: 자가진단 상세 설계
- **상태**: 보류
- **내용**: 미소속 홈에서 제공하는 자가진단 기능의 상세 UX
- **쟁점**:
  - 어떤 검사 항목을 사용할지 미정 (PHQ-9, GAD-7은 예시일 뿐)
  - 검사 진행 화면 형태 (스크롤/카드/대화형)
  - 오브 캐릭터 연동 여부
- **결정**: 검사 항목 선정 후 별도 논의

### ISSUE-011: 센터 주소 좌표 저장
- **상태**: 개발 필요
- **내용**: 센터 등록 시 카카오맵 주소 검색 API 연동, latitude/longitude 좌표 저장 필요
- **쟁점**:
  - 현재 센터 모델에 좌표 필드 없음 (텍스트 주소만 JSONB로 저장)
  - 기존 등록된 센터 데이터 마이그레이션 필요
  - 센터 웹에서 주소 입력 UI를 카카오맵 검색으로 변경 필요
- **결정**: 내담자 앱 길찾기 기능의 전제 조건. 센터 웹 + API 수정 필요
