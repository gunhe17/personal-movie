# 상담 상태 정책 (축약본)

> 케이스·세션·참여자 3단계 상태의 핵심 규칙만 정리. 상세 배경은 `status-policy.md` 참고.

---

## 1. 계층별 상태값

| 계층 | DB 값 | UI 라벨 | 비고 |
|------|-------|----------|------|
| **케이스** | active | 진행중 | |
| | completed | 종결 | 회기 "완료"와 구분 |
| | cancelled | 취소 | |
| **세션** | scheduled | 예약 | |
| | completed | 완료 | |
| | no_show | 노쇼 | |
| | cancelled | 취소 | |
| **참여자** | scheduled | 대기 | 출석 확인 대기 |
| | attended | 참석 | |
| | absent | 불참 | |

---

## 2. 계층 간 연동

| 상황 | 처리 |
|------|------|
| 세션 → completed | 대기만 attended 일괄 처리 (참석/불참 유지) |
| 세션 → no_show | 참석·대기 → absent 일괄 처리 |
| 세션 → cancelled | 참여자 상태 변경 없음 |
| 케이스 → completed/cancelled | 예약된 세션 있으면 오류 |

---

## 3. 참여자 혼재 시 세션 변경

| 참여자 혼재 | 세션 변경 | 참여자 처리 |
|-------------|-----------|-------------|
| A=참석, B=불참, C=대기 | → 완료 | C만 attended, A·B 유지 |
| A=참석, B=대기 | → 노쇼 | A·B 모두 absent |
| (어떤 혼재든) | → 취소 | 변경 없음 |

---

## 4. UI 표시

| 화면 | 표시할 상태 |
|------|-------------|
| 상담 상세 | 미표시 (세션·참여자 중심) |
| 회기 목록 | 세션 상태 |
| 회기 상세 내담자 카드 | 참여자 상태 |

**색상**: 진행/예약/대기=파랑, 완료/참석=초록, 취소/불참/노쇼=빨강·회색

---

## 5. 조작 흐름

**변경 가능 조건**
- 케이스: 예약 세션 없어야 함
- 세션: 날짜 지났거나 수동 변경
- 참여자: 세션이 예약일 때만

**확인 모달**
- 세션 → 완료: 대기 있으면 "대기 내담자(이름)를 참석으로 일괄 처리"
- 세션 → 노쇼: "내담자 전원을 불참으로 일괄 처리"
- 세션 → 취소: "회기 취소 (재예약 가능)"
- 모달 "취소" 버튼 = 작업 취소 (상태 변경 안 함)

---

## 6. 청구(Billing) 연동

| 세션 상태 | 청구 대상 |
|-----------|-----------|
| completed | attended 참여자만 |
| no_show | 없음 |
| cancelled | **없음** (참여자 상태와 무관) |
| scheduled | 없음 |

**세션 취소 시**: 기존 청구(PaymentRecord) 있으면 → 취소 또는 환불 처리.

---

## 7. 구현 체크리스트

| 항목 | 현재 |
|------|------|
| 케이스 종결/진행중 | ✅ |
| 세션 완료/노쇼 | ✅ 적용 |
| 참여자 대기/참석/불참 | ✅ 적용 |
| 참여자 혼재 + 세션 변경 | ✅ detail-service |
| 모달 취소 시 abort | ✅ |
| 청구 대상 판단 | ⚠️ Billing 구현 시 적용 |
