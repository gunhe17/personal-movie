## 사이클 (모듈당 1커밋 기준 — B·C급 동반 시 슬라이스 분리 가능)

1. **예약 작업 확인** — 진행표 그 모듈 행의 예약 작업(H0 조사 결과) + 이전 loop 이월분.
2. **체크리스트 대조 정독** — models → repository → services → facade → handlers → router → events 순. grep만으로 판정 금지, 파일 정독.
3. **수정** — A급 즉시, B·C급은 프론트 3앱 동반 같은 슬라이스(U11: 계약 불일치 즉시 수정). 리네임은 3형태 grep(식별자·kwarg·리터럴) × 3앱.
4. **게이트** — baseline 4종 green + 구 이름 잔재 0.
5. **커밋 → 진행표 갱신** — 위반 0이면 `[깨끗]` 부기만.
