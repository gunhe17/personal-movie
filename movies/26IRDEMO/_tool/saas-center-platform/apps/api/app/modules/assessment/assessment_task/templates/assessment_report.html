스마트폰, '건강하게' 사용해요

  • 머리와 허리를 세우고 눈높이에서 사용해요.
  • 사용 후에는 눈 건강 체조와 스트레칭을 해요.

스마트폰, '바르게' 사용해요

  • 사용 시간을 미리 정하고 지켜요.
  • 자기 전에는 스마트폰 사용을 줄여요.

스마트폰, '지혜롭게' 사용해요

  • 보고 들은 정보가 맞는지 한 번 더 생각해요.
  • 불편한 내용은 혼자 고민하지 말아요.

온라인에서도 서로를 존중해요

  • 예의 있는 말과 행동을 지켜요.
  • 서로를 존중하는 말로 소통해요.

01 어깨 긴장완화 [10회 2세트]

어깨를 가볍게 돌려주기

1. 손을 합장한 후 턱에 손을 대고 서서히 밀어 올려주세요.
2. 천천히 턱을 가슴 쪽으로 내려주세요.
{% include 'assets/Stretch_02.svg' %}
02 목 가동성 향상 [10회 2세트]

목을 좌우로 천천히 늘려주기

1. 고개를 천천히 좌우로 돌려주세요.
2. 허리에 손을 두고 고개로 천천히 원을 그려주세요.
{% include 'assets/Stretch_03.svg' %}
03 상체 이완 스트레칭 [10회 2세트]

팔과 어깨를 부드럽게 늘려주기

1. 손을 위로 올린 후 팔꿈치를 내려 등에 놓아주세요.
2. 양손으로 나머지 팔 팔꿈치를 잡아 당겨주세요.
