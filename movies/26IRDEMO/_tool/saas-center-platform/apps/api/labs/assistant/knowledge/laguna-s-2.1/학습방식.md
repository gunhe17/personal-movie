# 학습방식 — 아키텍처·훈련이 행동에 남긴 결

## 구조

- 오픈웨이트 **MoE 118B / 활성 8B**, 1M 컨텍스트 — 저비용($0.10/$0.20 per M)·저지연(~3.4s)의 원천.
- **from-scratch, 태그-네이티브** — 자체 chat_template(`<system>`·`<tool_call>`·`<think>`).
  "XML=Claude 전용" / "Anthropic식 작성이 정답" 둘 다 오판으로 판정 — 형식 A/B는 wash(목록 위반 25% 동일).

## persistence RL — 핵심 훈련 성질과 그 양면

"조기 승리 선언을 하지 않도록" 훈련(벤더 공개). 실측된 양면:

| 면 | 실측 |
|---|---|
| 이로움 — 멀티홉을 끝까지 밂 | 2~5홉·fan-out 완주 29/30, 하드엣지 14/15 |
| 해로움 — 거절·중단을 못 함 | 거절 도구 recall ~10%(precision 100%이나 무용) · 권한 환각 · 스코프 밖에서 할 수 있는 척 |

→ 설계 귀결: **거절은 도구가 아니라 프로즈**, 안전은 프롬프트가 아니라 **스코프 물리 차단**(D3·D4).

## thinking

- 자체 `<think>` 태그 보유하나 **reasoning on은 정확도 +0, 비용 ≥+64%, 빈답 글리치(~27%) 원인** —
  off 동결(D2). 벤더 권장(on, TB 60→70)과 반대 — 우리 워크로드(짧은 tool-use 턴) 기준 트레이드 수용.

## 제어 채널

- API 레벨 강제(tool_choice=any)는 무시 — **유일한 행동 레버는 대화 내 텍스트**(가드의 지적+재요청)와
  **히스토리가 보여주는 시범**(도구 흔적 복원 — h01). 훈련 성질상 "말로 시키는 것"보다 "본보기"가 잘 듣는다.
