# 계약 — 하드 제약 (전 항목 벤더 문서, 실측 0 — 실측 시 항목별 승격)

[xAI STT 문서](https://docs.x.ai/developers/model-capabilities/audio/speech-to-text) ·

## 경로 1: OpenRouter 경유 (`POST /api/v1/audio/transcriptions`)

- 요청 2형: base64 JSON `input_audio: {data, format}` (data URI 아닌 raw bytes b64) 또는
  OpenAI 호환 multipart. 포맷: wav·mp3·flac·m4a·ogg·webm·aac.
- **multipart 25 MB 상한 + 업스트림 타임아웃 60s** — 긴 녹음(상담 세션급)은 이 경로 부적합 추정,
  분할 또는 직결로.
- 파라미터: `model`·`language`(ISO-639-1, 미지정 시 자동감지)·`temperature`·`provider`(passthrough).
- 응답 `{text, usage: {seconds, total_tokens, cost, …}}` + `X-Generation-Id` 헤더 — 과금 추적은 usage가 정본.
- **없는 것**: 스트리밍·URL 입력·SRT/VTT.
- **[실측 2026-07-28, h06 E1] 파라미터 통과 여부** — `response_format=verbose_json` +
  `timestamp_granularities[]=word`는 **통과**(language·duration·segments·words 85개 반환).
  `diarize=true`는 **조용히 무시**(에러 없이 text만, verbose_json의 words에도 speaker 전부 null)
  → 화자 분리는 이 경로에서 불가, 직결 전용.
- **[실측 2026-07-28, h06 E1] 조용한 절삭 — 경로 무관 모델 자체** — 90초 이상 오디오는 첫
  ~62.6초(직결 words timestamp 실측)만 전사되고 HTTP 200(에러 무표시). 직결도 동일 지점·동일
  텍스트로 재현 — OpenRouter 층 무혐의. 30·60초 클립은 완전 전사. 기전 불명(무음 프로브가 고정
  오디오 캡·출력 캡 둘 다 기각 — 콘텐츠 의존 조기 종료 추정). **과금은 절삭과 무관하게 입력 전체
  길이**(+120.0초 파일에 180초 청구 1건). → 우회는 60초 청킹뿐(직결 500MB도 소용없음).
- **[실측 2026-07-28, h06 E1 bench60] `language=ko` 이탈 — 경로 무관 모델 자체** — 60초 세그먼트
  6개 중 2곳에서 출력 언어 이탈(일본어 환각·영어 번역). 직결 `language=ko`에서도 동일 재현
  (seg600은 한국어로 시작해 출력 도중 영어 번역 전환) — 자동 언어 전환이 힌트를 누른다.
  직결 diarize는 필드 실존이나 다화자 구간 화자 1 뭉갬(단발), `language` 응답 필드는 `en` 오표기.

## 경로 2: xAI 직결 (`POST https://api.x.ai/v1/stt` · 스트리밍 `wss://` 동일 경로)

- multipart — **`file`은 반드시 마지막 필드**(순서 하드 제약), 최대 **500 MB**. 대안 `url`(서버측 다운로드).
- 언어 25종 — **한국어 `ko` 포함**. `format=true`(ITN: "백" → "100")는 `language` 필수, 없으면 400.
- 고유 파라미터: `diarize`(화자분리) · `multichannel`(≤8ch) · `keyterm`(편향, ≤100개·각 50자) ·
  `filler_words` · `vad_threshold`.
- 응답: `text`·`language`·`duration`·`words[{text, start, end, speaker}]` — word timestamps 기본 포함,
  `speaker`는 diarize 시만.
- 스트리밍(실시간): `interim_results`(~500ms 부분자막)·`endpointing`·`smart_turn` — **실시간 전사는 직결만 가능**.
- 에러: 413=500MB 초과 · 400=file/url 부재·raw 오디오에 sample_rate 누락 등.
- 레이트리밋(블로그가 xAI 문서 전사 — [laozhang](https://blog.laozhang.ai/en/posts/grok-speech-to-text-api), 콘솔이 정본):
  REST 600 RPM · wss 10 RPS · 동시 스트리밍 세션 100/팀.
