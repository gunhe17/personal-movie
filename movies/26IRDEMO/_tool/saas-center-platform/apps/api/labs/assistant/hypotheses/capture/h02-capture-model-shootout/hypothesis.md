# 바우처 캡처 충실성 특성(날조·quote·기권·축 배치)은 후보 모델 간에 갈리며, 동일 하네스 페어드 실측으로 채택 후보를 판별할 수 있다

측정형·비교형. h07이 만든 하네스(fixtures·결정적 채점기)를 동결하고 모델만 변형하는
페어드 — "같은 문항·같은 세계·변형만 차이" 규약(README §4)의 모델판. 채택 문턱 =
h07과 동일(날조 0 · quote 원문 일치 · 명시 부재 시 기권 · 골든 정확).

## 조사

- h07 E1: flash-lite 단독 실측 — 날조 0·quote 96%·기권은 유사물 존재 시 실패(s7).
  본 가설은 그 실패 축이 모델 등급에 따라 갈리는지를 묻는다.
- 외부: HHEM에서 gpt-5.4-nano(3.1%/100%)가 flash-lite(3.3%/99.5%)보다 상위 —
  캡처 과제에서도 유지되는지가 검증점. ExtractBench는 PDF→JSON이 프론티어에게도
  난제임을 보임(모델 간 차이가 클 것으로 예상되는 근거).
- 후보 선정: 토의 문서 모델 조사 절(비중국계 제약·역할별 1순위) + haiku·sonnet(Anthropic
  지시준수 계열) + gemini-2.5-flash(동일 계열 한 단계 위 — 등급 효과 분리용).

| 모델 | 값정확 | quote | 환각 | 기권 | 지시준수 | K불안정 | 평균s | 실비$ |

| gemini-2.5-flash | 73% | 85% | 0 | **0/4** | 0/4 | 0 | 3.3 | .034 |

**기전 문장 지지 — 특성은 모델 간에 실제로 갈리고, 갈리는 축이 예상과 달랐다:**

1. **환각 0은 후보군 공통**(80시행 전건) — 값 날조는 이 과제·프롬프트에서 분별 축이
   아니다. 채택 문턱 ①은 전원 통과.
2. **기권이 최대 분별 축이며 계열 특성**: Claude 둘·nano = 4/4, Gemini 둘 = 2/4·0/4.
   특히 flash가 lite보다 나쁨(0/4) — **등급 상승이 기권을 개선하지 않음**, 훈련 계열
   특성이라는 증거. h07 s7 발견(유사물 존재 시 강제 배치)은 Gemini 계열 성향으로 좁혀짐.
3. **quote 충실성은 기권과 상충**: quote 서열 lite 95% > sonnet 92% > flash 85% >
   haiku 79% > nano 48%. **기권 잘하는 모델이 quote를 재구성하는 경향** — nano는
   기권 4/4인데 quote 절반이 재구성(캡처 부적합 수준), haiku도 s3에서 0/7 재구성.
   단일 모델이 양축 최고인 경우 없음 = **트레이드오프 실측** (A2 규약: 자동 채택 금지).
4. sonnet-5 = 값정확 최고(93%)·기권 4/4·quote 92%로 유일하게 양축 상위 — 단
   지연 13.5s(lite의 4.7×)·비용 40×·K불안정 3문항(temp 0에서도).
5. 지시준수(연령 -1 환산·○ 선별)는 Claude만 부분 수행(2/4 — 환산 수행) — 그러나
   2단 구조에선 환산이 코드 소관이라 채택 가중치 낮음.

**사전 판정 규칙 적용**: ①환각 탈락 없음 ②기권 서열 = {haiku, sonnet, nano} > lite > flash
③동률 해소(값정확·비용) → **haiku-4.5 1위, sonnet-5 2위**(정확도 최고나 비용·지연),
nano 탈락(quote 48% = 스내핑 전제 붕괴), Gemini 계열은 기권 축에서 밀림 — 단 lite는
quote 최고·최저가라 "캡처+코드 검산이 오배치를 잡는 구성"에선 여전히 유효 후보.

**파이프라인 함의**: 실패 모드의 검출 가능성이 갈린다 — quote 실패는 S2c 스내핑이
기계 검출(소견化), 오배치는 검산(시군 멤버십 등)이 일부만 잡음(s5형 구간 오배치는
구조 유효라 통과 위험). **검출 안 되는 실패(오배치)를 적게 내는 모델이 안전** →
기권 축 우선의 사전 규칙이 사후에도 정당화됨.
