# hypotheses/ — 가설 대장

**가설 1파일 = 증명 루프 1개.** 루프의 불변량은 파일 제목의 **기전 문장**("X가 Y를 유발한다, Z 때문에")
이고, 내부에 실험(E번호)이 축적되며, 종료 조건은 "지표 도달"이 아니라 **판정 도달**이다 — 어느 경로로
끝나든 사실 하나를 남긴다("증명 실패"도 산출물). 채택된 처방은
[.claude/loop/assistant.md](../../../../../.claude/loop/assistant.md) 결정 대장(D번호)에 등재하고 여기엔 근거를 남긴다.

## 가설 루프 — 절차 정본 (2026-07-28)

문턱(통계·조건)은 아래 판정 기준 v2가 소유하고, 이 절은 **순서·분기·종료**를 소유한다.

### 1. 관측·개설 (→ open)

단발 관측(WUI 1회·실측 잔여물)은 개설 사유일 뿐 증명이 아니다(§2). 기전 문장 **초안**과 재현
조건을 기록해 파일을 연다. 다른 가설의 종료에서 파생됐으면 frontmatter `derived_from`에 명시.

### 2. 조사 — 위임 가능 (agent)

산출물 계약 3가지, 결과는 "조사" 절에 근거 링크로:
1. [knowledge/](../knowledge/README.md) 해당 모델 주제 파일 대조 — 기존 실측과 모순되는가.
2. 이 대장의 계보 검색 — 같은 형태의 처방이 이미 기각됐는가(기각 범위 한정 조항 §4 확인).
3. 외부 유사 사례·일반 해법 조사 — LLM 일반에서 이 부류 문제의 통상 처방.

### 3. 수립·평가 — 위임 가능 (agent)

**기전 문장을 확정·고정한다 — 이후 이 문장이 루프의 불변량.** 처방 후보를 나열하고 관문 3개로 평가:
- **h04 게이트**: 행동 성향에 대한 프롬프트-문구 처방은 페어드 1회 상한(빠른 기각용).
  1차 처방은 코드·구조·데이터에서 찾는다([h04](h04-prompt-resistance/hypothesis.md) proven — 우회하려면 반증부터).
- **해상도**: 기대 효과 δ로 `stats.n_star(δ)` 산출 — 감당 불가한 N*이면 개설만 하고 보류(③으로).
- **비용**: 일일 캡(select-lab §23 규율) 안에서 설계.

### 4. 실험 환경 — 세계는 fixtures, 피험체는 프로덕션 import

- 피험체(Loop·가드·스펙·프롬프트·히스토리 재구성)는 프로덕션 import — 재조립 금지.
  [../env/mockenv.py](../env/mockenv.py)가 Executor의 DB 소비 지점(`_dispatch`)만 교체한다(구 harness.py 고아화가 반례).
- 세계(도구 결과)는 e폴더 `fixtures.json`으로 동결 — **녹화→동결**(RecordingExecutor 실DB 1회, 손제작
  금지: 봉투·절삭 형태가 모델 행동에 영향). 세계가 고정되면 남는 분산은 모델 확률성뿐 — 검출력 상승.
- 페어드 구조(같은 문항·같은 fixtures·변형만 차이) 필수 — 런 간 비교는 무엇도 증명하지 않는다(§1-7).

### 5. 실험 — 2레인, E번호 축적

| 레인 | 규율 | 증명력 |
|---|---|---|
| **탐색** | 조건 자유 변경·소규모 N — "조금씩 바꿔보기"는 여기서 마음껏 | **0** — 결과는 다음 확증 실험의 설계 재료로만 |
| **확증** | 사전 등록(§1) 커밋 → 실행 1회 → 판정 1회. 실행 후 설계 불변(사후 변경=탐색 강등) | status 승격은 확증만 가능 |

모든 실험은 E1, E2, …로 파일에 축적하고 레인을 명기한다. 실패한 실험도 지우지 않는다.
같은 처방을 문턱 넘을 때까지 재실행하는 것은 레인 위반(p-hacking) — 노이즈(런간 25~40%p)는
언젠가 문턱을 넘는다.

### 6. 종료 — 판정 도달 5종 (어느 하나로 반드시 닫힌다)

| # | 종료 경로 | status |
|---|---|---|
| ① | 처방 채택 — A1~A4 전건 충족 | adopted (+ D번호) |
| ② | "MDE(δ) 이상의 효과 부재"로 기각 (§4 문구 규율) | refuted / mitigated |
| ③ | 해상도 한계 — q<1이 예산 내 해소 불가 | open 유지 + "해상도 부족" 명시, 백로그 등재 |
| ④ | **파생 사실 발견** — 현 가설을 그 사실로 마감, 새 가설 분기 | superseded / 부분 판정 |
| ⑤ | 비용 캡 — 확증 레인 처방 변형 2회 wash | 종료 (기각 범위는 그 처방 형태 한정) |

### 7. 분기 — 기전 문장 테스트

> **이 결과를 반영하려면 기전 문장을 고쳐 써야 하는가?**
> 아니오 → 같은 가설의 다음 실험(E+1). 예 → 현 가설 종료(⑥-④) + 새 가설 개설(`derived_from` 링크).

선례: h01 1차→2차(문장 유지 = 실험 추가) / h02→h03(가드 사각 = 새 기전, 분기) /
누적 부정 증거→h04(메타 승격, 분기).

## 가설 폴더 스키마

가설 = 폴더 — 실행 기록과 전용 환경이 실험 구성 안에 함께 산다:

```
h{NN}-{slug}/
  hypothesis.md      ← 아래 스키마 (기전 문장·E블록·판정) — 사실의 정본
  e{N}/              ← 실험 1개 = 폴더 1개, E블록과 1:1 (실험 없는 가설은 생략)
    lab.py           ← 조건 상수(사전 등록 집행본) + 조작 변인 + judge
    fixtures.json    ← 세계 — 도구 결과 동결 (녹화→동결, 손제작 금지)
    results.jsonl    ← 원시 실행 기록
```

- 레인 = 폴더 가변성: **[확증] 폴더는 사전 등록 커밋 후 불변**(실행 후 수정 = 탐색 강등, 새 조건 =
  새 e폴더 — p-hacking 가드가 폴더 규약에 내장) / [탐색] 폴더는 실행 중 자유 수정.
- 실험 간 lab 복사는 드리프트가 아니라 기록 — 종결 e폴더는 동결된 실험 기구다. 공유 모듈로 뽑지 않는다.

hypothesis.md:

```markdown
---
name: h{NN}-{slug}
status: open | proven | adopted | mitigated | refuted | superseded
model: <대상 모델>
opened: <일자>
closed: <일자 | ->
lab: <e{N}/lab.py | ../../env/prod_lab.py | ->
results: <e{N}/results.jsonl | 경로 @ 커밋 (git 무덤) | ->
decision: <D번호 | ->        ← 채택 시 assistant.md 결정 번호
derived_from: <h번호 | ->    ← 분기 계보 (⑥-④ 파생이면 필수)
---
# <기전 문장 — 루프의 불변량. 고쳐 쓰게 되면 그것이 분기 신호>
## 현상 (존재 주장)      ← 무엇이 관측됐나 — 재현 조건·실사례
## 조사                  ← knowledge 대조·계보·외부 사례 (단계 2 산출물)
## 존재 증명             ← 수치·통제 조건 (없으면 status: open 유지)
## 처방 가설             ← "이렇게 하면 …" — 기전 가설 명시 + 관문 3개 통과 기록
## 실험 E1 [확증|탐색]
### 사전 등록            ← 확증만. e{N}/lab.py 조건 상수가 집행본 — 실행 전 커밋: 변형·N·K·MDE·q·판정 지표
### 결과·판정            ← 보고 표준형(§5) + 수치 표
## 실험 E2 …             ← 실패 실험도 축적
## 종료 판정             ← 5종 중 무엇으로 닫혔나 + 분기 링크
## 교훈·반전             ← 1차 처방의 부작용 등 (있으면)
```

- **status 어휘**: open(관측만) → proven(존재 증명) → adopted(처방 채택) / mitigated(완화만, 근본 미해결) /
  refuted(현상 또는 처방 반증) / superseded(다른 가설·결정으로 대체).
- v2 이전 실험은 **[소급·탐색]** 레인으로 편입(사전 등록 부재) — 판정은 소급 조항(§7)으로 유지하고,
  확증은 새 E번호 [확증]으로만.
- "실패 실험도 지우지 않는다"는 **E블록 기록(사실)**에 대한 규율이다 — 종결 가설의 원시 jsonl·도구는
  `경로 @ 커밋` 포인터를 남기고 git 무덤으로 보내도 된다(복원: `git show <커밋>:<경로>`).

# 판정 기준 (정본 v2 — 2026-07-28)

> 근거: Anthropic "Adding Error Bars to Evals"(arXiv 2411.00640)·"Resolution Diagnostics for Paired
> LLM Evaluation"(arXiv 2605.30315)·자체 실측(런간 드리프트 25~40%p·발현 변동 0~40%).
> 계산은 [../env/stats.py](../env/stats.py)가 집행 — 손계산·눈대중 판정 금지.
> **절대 기준의 의미**: "넘으면 참"이 아니라 **"못 넘으면 status 승격 금지"** — 확률 시스템에서
> 절대는 하한의 절대다.

## 0. 현상 분류 — 판정 경로가 갈린다

| 부류 | 정의 | 예 |
|---|---|---|
| **결정적** | 코드·구조가 원인 — 기전을 소스 라인으로 짚을 수 있음 | 가드 조건문 사각, 정규식 오매칭, 임포트 오타 |
| **확률적** | 모델 성향 — 같은 조건에서 시행마다 변동 | 자발 포기, 수치 누수, 히스토리 모방 |

## 1. 설계 규율 (실험 전 — 사전 등록)

확증 레인 실험은 실행 **전에** 해당 E번호의 "사전 등록" 블록에 기록하고 커밋한다 (사후 변경은 "탐색적" 강등):

1. α=0.05, 검정력 1−β=0.8 고정. 비교 집합 크기 **m 사전 선언** — m>1이면 Holm 보정.
2. **MDE·q 사전 계산** — `stats.mde(N)`으로 이 N이 검출할 수 있는 최소 차이를 선언.
   기대 효과 < MDE이면 **q<1 = 미해결 설계** → N을 키우거나 "해상도 부족" 명시(승격 불가 확정).
3. 확률적 현상은 **문항당 K≥3 재샘플** 후 문항 평균(분산 감소 — Anthropic 권고 3).
4. 판정 지표는 **내용 품질까지** 정의(호출 여부 아님 — 인자·수치·본문. h01 빈-인자 함정이 근거).
5. 문항이 도메인 묶음이면 클러스터를 인지 — 같은 도메인 문항은 독립 아님(클러스터 SE는 나이브의
   최대 3배). 소규모에선 도메인당 1문항으로 설계해 회피.
6. 에러 시행(429 등)은 분모 제외하되 **페어를 유지**(한쪽 에러 시 그 페어 통째 제외).
7. **런 간 비교로는 무엇도 증명하지 않는다** — 페어드(같은 런·같은 문항·같은 시드)만.

## 2. E — 존재 증명 (open → proven)

| 조건 | 결정적 | 확률적 |
|---|---|---|
| E1 재현 | 1회 + **기전을 소스로 증명**(해당 라인 인용) | 페어드 대조 — 유발 조건군에서만 발현 |
| E2 통계 | 불요 (기전이 증명) | **McNemar exact p<0.05** (discordant pairs) 또는 paired bootstrap 95% CI가 0 제외 |
| E3 기전 | 필수 | 기전 가설의 **예측 1개 이상 적중** (h01: "흔적 복원 시 소멸" 적중) |

단발 관측(WUI 1회)은 open 등재 사유일 뿐이다.

## 3. A — 처방 채택 (proven → adopted) : 4조건 전부

1. **A1 효과**: 페어드 [현행 vs 처방] — 확률적: McNemar exact p<0.05 **그리고** paired bootstrap
   95% CI가 0 제외. 결정적: 대상 케이스 **전건 N/N**.
2. **A2 컨트롤 무손상**: 정상 경로 프로브 ≥2종 저하 0(소표본은 전건 유지로 판정).
   트레이드오프 실측 시(예: cover +40 ↔ sibling −20) **자동 채택 금지 — 사용자 결정으로만 승격**.
3. **A3 내용 품질**: 판정 지표가 인자·수치·본문 채점을 포함했는가.
4. **A4 회귀 게이트**: 해당 범위 unit·e2e 그린 + 배선 후 WUI 실연 1회.

## 4. R — 기각 (refuted)

- "효과 없음"이라 쓰지 않는다 — **"MDE(δ) 이상의 효과 부재"**로만 기록 (예: responder 격화판 =
  "N=9 기준 ≥53%p급 효과 부재"). 미세 효과의 존재는 미해결로 남는다.
- wash 1회 기각 허용(비용 규율) — 단 기각 범위는 그 형태의 처방에 한정, 계보 기록 의무.

## 5. 보고 표준형 (점추정 단독 금지)

```
Δ=+56%p · 95% CI [18, 89] · McNemar p=.031 · N=9(K=1) · MDE=53%p · q=1.1 · results/xxx.jsonl
```

LLM-judge를 판정에 쓰면 judge 오차 보정을 함께 보고(arXiv 2511.21140). 사람 판정(WUI)은 "실연"으로만.

## 6. MDE 참조표 (이진 페어드, σ_D=0.6 보수 가정 — ρ̂ 실측 시 stats.py로 갱신)

| 페어드 N | 10 | 20 | 50 | 100 | 200 |
|---|---|---|---|---|---|
| 검출 가능 최소 차이 | ~53%p | ~38%p | ~24%p | ~17%p | ~12%p |

## 7. 소급 조항

v2(2026-07-28) 이전 판정은 유지하되, v2 문턱 미달이 확인되면 파일에 **"v2 재평가 필요"**를 표기하고
확증 재실험(N 증가 또는 K 재샘플)을 백로그에 올린다. 첫 사례: h01 — Δ=+55.6%p·CI[22,89]는 0을
제외하나 McNemar p=.0625·q=0.99(N=9의 해상도 한계). 배선은 유지(A2~A4 충족+WUI 실연), 통계 확증만 미완.
