# 계약 — 하드 제약·설계 불변식

- **max_tokens 4096 필수** — 사고 토큰 잔존으로 1024는 본문 절삭 실측.
- timeout 10s + 전 예외 **draft 폴백** — responder 장애가 턴을 깨지 않는다(설계 불변식).
- 입력 4블록 고정: `<context>` + `<대화>`(텍스트 쌍 최근 6턴 — 가드 재시도·도구 wire 미노출이 오염
  회복 기전) + `<도구_결과>`(건당 4,000자 절삭 — 1,500은 부재오답 유발 실측) + `<초안>`(참고, 자료가 정본).
- usage `io`(요청/응답 원본)를 llm_calls.meta로 영속 — 오독 사후 감사.
- 킬스위치: `ASSISTANT_RESPONDER_MODEL=""` — env 변경만으로 롤백. e2e는 비활성 강제(이중 방어).
