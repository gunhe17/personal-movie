# 축 오배치는 두 기전으로 갈린다 — 부재-축 강제 배치(M1)는 요청 자체가 유발하며 축을 단독 요청할수록 심해지고, 축 간 누수(M2)는 다축 동시 요청에서만 발생한다. 따라서 분할 콜은 M2를 줄이는 대신 M1을 늘린다

통념("한 번에 하나씩 시키면 실수가 준다")에 대한 기전 분해. h08에서 s7 오배치가 **1축
요청**에서도 발생(M1)했고 s5 누수는 **다축 요청**에서 발생(M2)했다 — 두 실패가 다른
기전이라면 분할은 만능이 아니라 트레이드오프다.
