# 계약 — 어기면 즉시 깨지는 하드 제약

**주력 = 경로 2(직결), 2026-07-28 사용자 결정** — 경로 1은 킬스위치(`POOLSIDE_DIRECT=false`) 폴백.

## 경로 1: OpenRouter 경유 (폴백 — Anthropic wire)

- **base_url=OPENROUTER_BASE_URL 필수** — 미지정 시 404.
- Anthropic 전용 기능 사용 불가 — bm25 tool search·`defer_loading` → `native_search=False`로 전 도구 평載.
- **`tool_choice="any"` 강제 무시** (실측 3/3) — 이 경로에선 행동 제어가 텍스트 가드만 유효.
  (직결 경로에선 유효 — 아래. "Poolside가 무시" 판정은 경로 한정으로 정정 2026-07-29)
- **`tool_choice` 값 변경 = 프리픽스 캐시 무효화** — 고정 유지("첫턴만 any" 패턴 금지).
- 병렬 tool_result는 **한 user 메시지**에 묶는다(공식 계약). tool_result 내용은 데이터-only(인젝션 방어), JSON은 `json.loads` 파싱.
- 프로덕션 동결 설정: `reasoning off · max_tokens 2048` — 변경은 페어드 재실측 후에만(D2).
- 공유 풀이라 **Poolside 업스트림 429 파도**를 그대로 맞는다(`is_byok: false`) — BYOK 등록 또는 직결로 회피.

## 경로 2: Poolside 직결 (inference.poolside.ai/v1 — OpenAI Chat Completions wire, 실측 2026-07-29)

- 인증 `Authorization: Bearer $POOLSIDE_API_KEY`(platform.poolside.ai 발급), 한시 무료. 프롬프트 캐시 작동(`cached_tokens` 실측).
- **thinking off가 도구 호출의 전제조건**: `chat_template_kwargs: {"enable_thinking": false}`.
  - thinking 기본(on) + tools → tool_calls 실종: 태그 네이티브 문법(`<function_calls><invoke …>`)이
    content 텍스트로 누출되거나 되물음. **OpenRouter가 이 태그를 파싱해주고 있었던 것** — 직결은 그 층이 없다.
  - thinking off → 구조화 `tool_calls` 정상(auto·required 모두, 인자 완비, finish_reason="tool_calls").
    공식 문서도 동일 고지("tool_choice 강제 전에 thinking을 끄라").
- **system role 금지** — role 존재만으로(내용 무관, "." 1자도) tool 파서 붕괴: 태그 3종
  (`<function-call>`·`<tools>`·`<function_calls>`) 불안정 누출. 같은 user 메시지 접두 병합은
  `<function_results>` **날조** 유발. **별도 선행 user 메시지 `<system>…</system>`만 생존** —
  번역 어댑터(`infrastructure/anthropic/poolside/client.py _to_openai`)가 접는다. 공식 예제도 system 없음.
- 골든 배터리 6/6 관통(실 SYSTEM·26도구·HITL ask 포함, 2026-07-29) — 지연 1.7~4.7s
  (OpenRouter 1.1~2.4s 대비 소폭 위: 논스트림+요청당 커넥션). 스트리밍 v1 미지원(최종 턴 일괄).
- **`tool_choice: "required"` 유효** (실측) — OpenRouter 경유에서 죽어 있던 레버가 직결에선 산다.
  가드 재설계 후보(단, 채택은 페어드 실측 후 — h04).
- 도구 정의는 Chat Completions **중첩형** `{"type":"function","function":{name,description,parameters}}`.
  (OpenAI Responses API 문서의 평탄형 `{type,name,parameters}`와 다름 — 혼용 금지.)
- OpenAI 함수호출 일반 계약(문서 기준, 직결 개별 실측 전):
  - `tool_choice`: auto(기본)/required/지정 `{"type":"function","name":…}`/none.
  - `strict: true` 권장 — 요건: `additionalProperties: false` + 전 필드 `required`(optional은 type에 null 추가).
  - `parallel_tool_calls: false`로 병렬 호출 차단 가능(기본 허용).
  - 도구 정의는 시스템 메시지에 주입되어 **input 토큰 과금**. 시작 도구 <20개 권장(우리 26개 — 재검 후보).
  - 스트리밍: tool_calls는 arguments delta 누적 방식(청크를 call_id별로 이어붙여 완성).
- tool_result 회신은 `{"role":"tool","tool_call_id":…,"content":…}` 문자열 — Anthropic wire와 형태 상이,
  번역은 메신저 어댑터 1곳에서만(infrastructure).
