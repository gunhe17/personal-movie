> 작성일: 2026-05-18

## 1. 핵심 가치

### 왜 필요한가?

현재 앱은 "센터 선택 → 센터 내부 활동" 구조로, 다음 문제가 있다:

- 다중센터 소속 상담사는 센터를 전환하며 일정을 파악해야 함 → **일정 충돌 위험**
- 센터 미소속 상담사(프리랜서, 수련생)는 앱을 사용할 수 없음
- "나"에 대한 공간이 없음 — 모든 데이터가 센터 소유

### 핵심 가치

**멀티센터 통합 뷰 + 개인 전용 공간**

- 모든 센터 일정/업무를 하나의 뷰에서 통합 관리
- 센터와 무관한 개인 도구 (메모, 커리어, 통계)
- 센터 소속 여부와 관계없이 모든 상담사가 사용 가능

## 2. 타겟 사용자

| 유형 | 워크스페이스 가치 |
|------|------------------|
| 다중센터 상담사 | 통합 일정 + 개인 공간 (풀 활용) |
| 1센터 상담사 | 워크스페이스가 기본 홈, 개인 공간 + 센터 연결 |
| 센터 미소속자 | 개인 공간만 (개인 일정, 메모, 커리어 관리) |
| 센터 관리자 | 다중 센터 통합 관리 |

**모든 사용자가 워크스페이스를 기본 홈으로 사용한다.**
센터별로 분리해서 보면 일정 충돌을 놓칠 수 있고, 하루 전체 흐름 파악이 어렵다.

## 3. 앱 구조 (진입 및 네비게이션)

### 변경 전

```
로그인 → 센터 선택 → 센터 앱 (탭: 홈/일정/내담자/더보기)
```

### 변경 후

```
로그인 → 워크스페이스 (기본 홈)
              ├── 통합 일정/대시보드
              ├── 개인 공간
              ├── 프로필
              └── 센터 진입 → 센터 앱 (기존 탭 구조 그대로)
```

### 워크스페이스 ↔ 센터 관계

- **완전 분리** — 워크스페이스와 센터 앱이 독립된 네비게이션
- 센터 카드를 탭하면 기존 센터 앱으로 전환
- 센터에서 나오면 워크스페이스로 복귀
- 기존 센터 앱 구조는 변경하지 않음

```
[워크스페이스]  ←→  [센터 A 앱] (기존 탭 구조)
     홈
     캘린더
     개인 공간     ←→  [센터 B 앱] (기존 탭 구조)
     프로필
```

## 4. MVP 기능 목록

### 포함

| 기능 | 설명 | 데이터 소스 |
|------|------|-------------|
| **통합 일정 보기** | 모든 센터 + 개인 일정을 한 화면에 | cross-center API + personal_schedule |
| **개인 일정 CRUD** | 센터 무관한 내 일정 관리 | personal_schedule |
| **센터 리스트/진입** | 센터별 요약 + 탭하면 센터 앱 전환 | auth /me 기존 데이터 |
| **개인 메모/노트** | 학습 기록, 슈퍼비전 메모, 사례 정리 | personal_note |
| **통합 통계** | 전체 센터 합산 상담 시간, 세션 수, 주간/월간 | cross-center aggregation |
| **업적/스트릭** | 연속 기록, 회기 달성 뱃지, 동기부여 | achievement |
| **내담자 통합 뷰** | 센터별 담당 내담자 한눈에 (읽기 전용) | cross-center API |
| **프로필/커리어 관리** | 자격증, 경력, 교육이수 (개인 마스터 데이터) | personal_profile |
| **테마 설정** | 라이트 / 다크 / 시스템 따라가기 | 로컬 설정 |

### 제외

| 기능 | 사유 |
|------|------|
| 무드/컨디션 체크 | 불필요 |
| AI 인사이트 | 별도 트랙으로 분리 (프로덕션 미배포 상태) |

## 5. 센터 데이터 접근 정책

### 원칙

워크스페이스에서 센터 데이터를 **읽기 + 일부 수정** 가능하게 한다.
센터 진입 없이도 일상 업무 대부분을 처리할 수 있도록 한다.

### 허용 액션

| 액션 | 워크스페이스에서 | 비고 |
|------|:-:|------|
| 통합 일정 보기 | ✅ | 센터별 색상 구분 |
| 세션 출석/노쇼/취소 상태 변경 | ✅ | |
| 일정 시간 변경/취소 | ✅ | |
| 상담 노트 작성 | ✅ | 타임라인에서 바로 진입 |
| 내담자 정보 수정 | ❌ | 센터 진입 후 처리 |
| 내담자 등록 | ❌ | 센터 진입 후 처리 |
| 검사 실시/채점 | ❌ | 센터 진입 후 처리 |

### API 설계 방향

```
기존 (센터 격리):    /centers/{centerId}/schedules
추가 (통합 조회):    /me/schedules
                    /me/dashboard
                    /me/clients/summary
                    /me/stats
```

- 서버가 유저의 모든 활성 멤버십을 조회하여 데이터 합산 반환
- 수정 액션은 기존 센터 API를 그대로 호출 (centerId 포함)

## 6. 데이터 설계

### 신규 테이블

| 테이블 | PK | 소유키 | 용도 |
|--------|-----|--------|------|
| `personal_schedule` | UUID | person_id | 개인 일정 |
| `personal_note` | UUID | person_id | 개인 메모/학습 노트 |
| `personal_profile` | UUID | person_id | 자격증, 경력, 교육이수 (마스터) |
| `achievement` | UUID | person_id | 업적/스트릭 기록 |

### 프로필 데이터 마이그레이션

**결정: 개인 프로필이 원본(master), Member에서는 제거**

- 현재 Member 모델의 `careers`, `educations`, `certifications` (JSONB)를 `personal_profile`로 이관
- 이유: 자격증/경력은 본인의 것이지 센터의 것이 아님. 센터마다 다르게 적혀있으면 신뢰 문제 발생
- 마이그레이션 계획 필요 (기존 데이터 이관 + Member 필드 deprecation)

## 7. 디자인 방향

### 채택 요소

| 요소 | 출처 | 이유 |
|------|------|------|
| 프로그레스 링 | Concept A | 오늘 진행률 — 통합 일정이 핵심이므로 한눈에 파악 |
| 센터 카드 | Concept A | 센터별 요약 + 진입 동선 필수 |
| 통합 타임라인 | A+B | 센터 색상 구분 + 상태 변경/노트 작성 진입점 |
| 스트릭/업적 뱃지 | B+C | MVP 확정 기능, 동기부여 |
| 히트맵 | Concept B | 통합 통계 연결, 주간 밀도 시각화 |
| 나만의 공간 카드 | Concept C | 메모/통계/커리어 진입점으로 적합 |

### 제외 요소

| 요소 | 사유 |
|------|------|
| 오비트 비주얼 | 재밌지만 공간 대비 실용성 낮음, 매일 보면 피로 |
| 무드 체크 | MVP 제외 |

### 테마

- 라이트 / 다크 / 시스템 설정 따라가기 (프로필 설정에서 선택)

### 워크스페이스 홈 화면 구성 (위→아래)

```
┌─────────────────────────────┐
│ 헤더 (인사말 + 프로필)         │
├─────────────────────────────┤
│ 프로그레스 링                  │
│ (오늘 완료/전체, 남은 상담 등)  │
├─────────────────────────────┤
│ 히트맵 (이번 주 밀도)          │
├─────────────────────────────┤
│ 소속 센터 카드                 │
│ ┌─ 마음숲 [관리자] 5건 ──→   │
│ └─ 해맑음 [상담사] 3건 ──→   │
├─────────────────────────────┤
│ 오늘 타임라인                  │
│ (센터 색상 구분 + 액션 버튼)    │
│ 09:00 ● 김민수 상담     [완료] │
│ 10:00 ● 이수진 상담   [진행중] │
│ 13:00 ● 박지훈 검사     [예정] │
│ 15:00 ○ 슈퍼비전 스터디       │
├─────────────────────────────┤
│ 나만의 공간 (가로 스크롤)       │
│ [📓메모] [📊통계] [🏆업적] [📋커리어] │
├─────────────────────────────┤
│ 업적/스트릭 미리보기            │
│ 🔥12일 연속 · 🏅10회기 달성    │
└─────────────────────────────┘
│  홈  │ 캘린더 │ 메모 │ 프로필 │  ← 하단 탭
```

### 워크스페이스 하단 탭 구성

| 탭 | 기능 |
|----|------|
| 홈 | 대시보드 (위 구성) |
| 캘린더 | 통합 캘린더 (일/주 뷰, 센터별 색상, 개인 일정 추가) |
| 메모 | 개인 메모/노트 목록 + 작성 |
| 프로필 | 커리어 관리, 통합 통계, 업적, 설정 (테마 등) |
