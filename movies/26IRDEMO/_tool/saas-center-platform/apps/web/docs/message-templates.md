# 바로링크 전송 양식 관리

전송 모달에서도 서비스 제공 양식을 별도 등록 없이 선택할 수 있다. 기존 기본 본문에 링크/인증번호가 없으면 서비스 양식을 선택하고 사유를 표시한다. 요청의 `template_id="__builtin__"`는 저장된 기본 양식 대신 서버 내장 문구를 사용한다. 신규·재전송·일괄 모두 같은 선택 규약을 사용하며 기존 저장 양식은 변경하지 않는다.

표시 이름은 바로링크 전송이며 내부 타입 `assessment_send_link`와 변수 `assessment_url`은 호환성을 위해 유지한다. 이전 한글 태그 `#{검사 링크}`도 저장 시 같은 변수로 변환한다.

`builtin_content`는 현재 서비스 내장 문구이고 `fallback_content`는 현재 적용된 본문이다. 기존 센터/시스템 양식은 자동 덮어쓰지 않는다. 새 문구가 다르면 비교 후 새 센터 기본 양식으로 저장할 수 있다.

바로링크의 목표는 검사 진행과 결과보고서 확인을 포함한다. 현재 `/verify-link`의 보고서 조회는 미연결이며, 기존 결과 전송은 별도 인증과 문서 접근 감사를 사용한다. 공개 대상·수신자 권한을 확정하기 전에는 응시 인증으로 보고서를 자동 공개하지 않는다. 기본 메시지는 아직 제공되지 않는 일정·보고서 조회를 가능하다고 안내하지 않는다.

전송 모달의 `expires_at`은 검사 일정이나 제출 전용 마감이 아닌 링크 접근 만료다. 보고서 공개와 검사 마감 분리는 별도 권한·수명 설계가 필요하다.

- 설정의 문자 양식(`/center/message-templates`)에서 검사 링크 전송 양식을 조회·생성·편집한다.
- 상단의 현재 기본 양식은 발송과 같은 `/message-templates/default` API로 조회한다. 센터 기본, 시스템 기본, 서비스 내장 문구 순서이며 출처와 본문을 표시한다.
- 시스템/내장 문구는 직접 변경하지 않는다. ‘센터 기본 양식으로 복사’로 생성 폼을 열어 검토 후 저장한다. 복사 버튼 자체로 서버 데이터를 변경하지 않는다.
- 센터 기본 양식의 편집 버튼은 실제 저장된 양식을 연다. 저장·생성·삭제·대표 지정은 목록과 기본 조회 캐시를 갱신한다.
- 검사 링크와 인증번호 변수가 모두 있어야 링크 양식을 저장할 수 있다. 기존 불완전한 기본 양식에는 경고를 표시한다.
- 전송 모달은 명시적으로 선택한 양식을 우선한다. 설정을 다른 탭에서 바꿨다면 ‘양식 다시 불러오기’를 누른다.
- 문자 본문 관리와 카카오 템플릿 승인은 별개다. 설정 변경이 카카오 승인을 보장하지 않는다.

검증은 `validation.test.ts`, `LinkDefaultTemplate.svelte.test.ts`, `MessageTemplateFormModal.svelte.test.ts` 및 기존 바로링크 전송·내역 브라우저 테스트로 수행한다. 실제 메시지는 발송하지 않는다.
