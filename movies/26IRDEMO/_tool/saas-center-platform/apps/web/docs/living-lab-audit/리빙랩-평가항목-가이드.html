mindSCOPE 평가 진행 가이드 — 기능 항목 24종

「프로그램 평가 및 보완계획」의 평가 항목을 실제 화면·순서로 안내합니다 · 시각화 버전: 준비도 대시보드
사용법 — 각 항목마다 ① 어디서(진입 경로) ② 이렇게 해보세요(사용 시나리오) ③ 확인 포인트(평가 관점) 순으로 진행하고, 평가 양식의 [평가 결과 | 보완할 사항]에 기록해 주세요. 노란 상자는 알려진 제한(사전 고지)으로, 평가 대상이 아니라 참고 사항입니다. 이 페이지는 인쇄해도 체크리스트로 쓸 수 있습니다.

A. 내담자 관리 프로그램7종 · 1차 검증(기본 준비 과정) 중점

내담자 등록 → 검사 발송 → 센터 운영의 기본 준비가 목적에 맞게 되는지.
1주간/월간 스케줄 관리 + 스케줄 통계웹모바일
어디서
웹 스케줄 메뉴(첫 화면) · 모바일 일정 탭
해보세요
  1. 웹에서 월간 → 주간 → 일간 뷰를 전환하고, 일간에서 장소별↔담당자별 타임라인을 바꿔봅니다
  2. 프로그램·담당자·내담자 필터를 조합해 원하는 일정만 봅니다
  3. 빈 시간대를 클릭해 등록 선택 모달(내담자/상담/검사)이 뜨는지 확인합니다
  4. 모바일 일정 탭에서 월간/주간/통계 뷰를 전환합니다
확인 포인트
  • 하루/한 주의 센터 일정이 한눈에 파악되는가
  • 일정 색·상태(예정/완료/취소/노쇼) 구분이 직관적인가
  • 통계가 운영 판단(가동률 등)에 도움이 되는가
알려진 제한: 웹의 통계 화면(대시보드>분석)은 이번 차수에서 준비 중입니다 — 통계는 모바일 일정 탭 기준으로 평가해 주세요.
2내담자 조회 / 관계 관리웹모바일
어디서
웹 내담자 메뉴 · 모바일 내담자 탭
해보세요
  1. 내담자 등록: 아동 내담자 + 보호자 2명을 함께 등록해 봅니다 (웹 등록 폼 / 모바일 단계형 등록)
  2. 목록에서 검색·역할 탭(전체/보호자/아동)·회기임박순 정렬을 사용해 봅니다
  3. 내담자 상세에서 보호자(관계)를 클릭해 해당 인물로 이동해 봅니다
  4. 모바일에서 자주 보는 내담자를 즐겨찾기(하트)하고, 행의 전화/문자 버튼을 눌러봅니다
확인 포인트
  • 아동+보호자 가족 구조가 자연스럽게 입력·표시되는가
  • 현장(모바일)에서 내담자를 빨리 찾고 연락할 수 있는가
알려진 제한: 관계(보호자) 정보 수정은 웹의 내담자 수정 화면에서 이뤄집니다(모바일은 조회).
3검사 진행 현황 조회웹모바일
어디서
웹 검사 메뉴 · 모바일 내 정보 > 검사 현황
해보세요
  1. 상태 탭(진행전/진행중/완료)과 담당자·날짜 필터로 목록을 좁혀봅니다
  2. 케이스를 열어 검사 항목별 진행 상태(진행률 N/M)를 확인합니다
  3. 전송 내역 화면에서 링크가 언제 누구에게 발송됐는지 추적해 봅니다
확인 포인트
  • "어느 내담자 검사가 어디까지 왔나"를 즉시 알 수 있는가
  • 미제출·만료 케이스를 놓치지 않게 되어 있는가
4검사의 시작부터 결과까지 (바로링크)웹
어디서
웹 검사 접수 → 발송 → (내담자 휴대폰) → 결과 확인
해보세요
  1. 검사 접수(단일 또는 세트)를 만들고 검사 링크를 문자/카카오/QR로 발송합니다
  2. 내담자 입장에서 링크를 열어 로그인 → 이름·생년월일 확인 → 검사를 수행·제출합니다
  3. 제출 알림을 받고, 검사 상세에서 결과를 확인합니다
  4. 결과 링크를 보호자에게 발송 → 인증번호 4자리 입력 → 보고서를 내려받아 봅니다
확인 포인트
  • 비대면 검사 전달이 전화 안내 없이 자연스럽게 완결되는가
  • 보호자의 결과 확인(인증번호)이 어렵지 않은가
알려진 제한: 내담자 검사용 계정은 운영팀이 사전 세팅해 드립니다. 결과 다운로드 링크는 1시간 유효입니다.
5푸시 알림모바일
어디서
모바일 내 정보 > 알림설정 + 실제 이벤트 발생
해보세요
  1. 알림설정에서 일정 리마인드·검사 제출·공지 토글을 켭니다
  2. 내담자가 검사를 제출하면 푸시가 오고 앱 아이콘에 뱃지가 붙는지 확인합니다
  3. 알림을 눌러 해당 검사/상담 화면으로 바로 이동되는지 확인합니다
확인 포인트
  • 중요한 사건(제출·일정)을 실시간으로 놓치지 않는가
  • 알림 → 해당 화면 이동이 정확한가
알려진 제한: 웹은 화면 안 알림(약 30초 주기 갱신)이며 브라우저 푸시는 제공하지 않습니다.
6청구 관리웹모바일
어디서
웹 청구 메뉴 · 모바일 내 정보 > 청구 현황
해보세요
  1. 회기를 완료한 뒤 청구 화면 상단의 "미청구 세션" 배너에서 원클릭으로 청구를 만들어 봅니다
  2. 바우처를 연결해 지원금·본인부담이 자동 계산되는지 확인합니다
  3. 납부를 부분(예: 50%)으로 등록하고 미수금이 추적되는지 봅니다
  4. 상담 상세에서 패키지 선결제(여러 회기 일괄 청구 + 할인)도 만들어 봅니다
확인 포인트
  • 세션→청구 누락이 구조적으로 방지되는가
  • 바우처·지원금 계산이 센터 실무와 맞는가
알려진 제한: 환불·납부 기록 정정은 이번 차수에 포함되지 않습니다(발견 시 보완사항에 기록해 주세요).
7최신 바우처 정보 알림웹

  2. 유효기간 14일 이내 바우처의 "만료 임박" 신호를 확인합니다
  3. 신호 카드를 눌러 내담자 목록으로 이동해 봅니다
확인 포인트
  • 바우처 소진·만료를 놓치지 않게 해주는가
  • 센터에서 기대하는 "바우처 정보 알림"의 범위와 맞는가 (의견 주시면 반영)

4스마트 일괄 회기 추가웹

  • 임상적으로 부적절한 표현(과잉 해석 등)이 없는가
사전 확인: AI 기능은 리빙랩 전용 환경에서 활성화됩니다 — 평가 시작 전 담당자가 사용 가능 여부를 안내드립니다.
