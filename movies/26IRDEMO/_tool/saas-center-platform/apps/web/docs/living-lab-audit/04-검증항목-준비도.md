# mindSCOPE 검증·평가 계획 대응 — 평가 항목별 준비도 (v1)

> 2026-07-09. 근거: 「mind scope(임상심리사) 프로그램 평가 및 보완계획」(26.6.1, hwpx) + 본 세션 웹·모바일 전수조사.
> **이 문서가 이제 점검의 기준 프레임이다** — 화면/도메인 기준이 아니라, 평가자가 실제로 채점할 **공식 평가 항목 24종** 기준으로 재정렬.

## 1. 평가 계획 요약 (문서 원문 기준)

- **목적**: 임상심리사 5명(센터장/임상실무, 곽금주·정경미 교수 추천 포함 — 이진영·신옥자 박사 등)이 출시 전 프로그램을 평가·보완
- **일정**: 1차 검증 6.30~7.3 → **1차 보완 7.6~7.31 (← 오늘 7.9 = 여기)** → 1차 보완 결과 검증 8.3~8.7 → 2차 보완 8.10~ → 3차(8월 4주) 최종 결과보고서 검토(교수진)
- **평가 방법**: ① 기능이 사용 목적에 맞는가 ② 센터 기능·운영에 부합하는가 ③ 기존 사용 프로그램 대비 장단점 — 차수별 보완요구사항 양식 기록
- **1차 중점**: 내담자 등록·검사 발송·센터 운영 등 **기본 준비 과정**
- **2차 중점**: 검사 결과 확인부터 실제 상담 진행·기록까지 — 접수→**보호자에게 온라인으로 결과 발송·확인**, **상담 일정 예약·시간 변경·중복 일정 확인**
- 평가 양식: 항목별 [평가 결과 | 보완할 사항] 표 + 종합의견

**시사점**: 이 세션에서 발견한 이슈들은 "1차 보완 기간의 작업 목록"으로 재배치돼야 하고, 우선순위는 **평가 항목과 직접 충돌하는 것**이 최우선이다.

## 3. 2차 평가 중점과의 직접 충돌 (예고된 시나리오)

2차 평가 문안이 **정확히 어디를 볼지 명시**하고 있다:

| 2차 평가 문안 | 현재 상태 | 판정 |
|---------------|----------|------|
| "보호자에게 온라인으로 점수내용 보내고 결과까지 확인" | SendResult(인증번호 4자리, 1시간) 완성. 수신자에 관계(보호자) 지정 가능 | ✅ 단 라벨 혼동(P1-5) 정리 권장 |
| "상담 일정 예약, 시간 변경" | 접수·회기 수정 완성 | ✅ |
| "**중복 일정 확인 여부**" | 장소 충돌만 검사. **상담사 이중 배정 무검사(P0-2)** | 🔴 **평가 항목이 현재 최대 결함을 정조준** — 1차 보완에서 반드시 해결 |

## 4. 우선순위 재편 — "1차 보완(7.6~7.31) 작업 목록"으로 재배치

기존 P0/P1을 평가 프레임에 맞춰 재배열. **평가 항목과 직접 충돌 = 최우선.**

### 🔥 즉시 (평가 항목 자체가 깨짐)
1. **상담사 이중 배정(중복 일정) 검사 추가** — 2차 평가 문안 명시 항목 (기존 P0-2)
2. **바로링크 centerId 하드코딩 수정** — 평가 항목 A-4/B-9 (기존 P0-1, 한 줄)
3. **AI 4종 노출 정책 결정** (경영 판단): 상담일지 초안·검사 해석·검사 보고서·에이전트 + 필드노트 — "AI 프로덕션 미배포" 방침 vs 평가 항목. **리빙랩 전용 환경에서 AI 활성화**가 사실상 유일한 해법인지 확정
4. **AI 검사 해석 보조** — 노출 화면 부재. 범위 재협의(평가 항목에서 제외/연기) or 최소 구현
5. **바우처 서류 자동 생성** — 백엔드는 있음. 프론트 연결 완료 여부 결정

### ⚡ 1차 보완 기간 내 (평가 경험 왜곡 방지)
6. 웹 스케줄 **통계 더미 처리**(analytics·검사 통계): 실데이터 최소 구현 or "준비 중" 명시 or 진입 차단 (평가 항목 A-1이 "스케줄 통계" 포함)
7. 만료 바우처 차감 검증 (기존 P0-7 — 바우처 항목 3개가 평가 대상)
8. 검사 접수 충돌 경고 응답(P0-6) + 검사/결과 링크 라벨 분리(P1-5)
9. 고아·더미 라우트 정리: /session(mock)·/settings 인덱스·예약현황/예약설정·purchase — 평가자가 우연히 진입하면 신뢰 하락
10. 모바일: 홈 확정(전환 중 상태 해소), "내 워크스페이스" placeholder 숨김, 녹음 실기기 리허설
11. "최신 바우처 정보 알림"·"바우처 납부 증빙" **기획 의도 확인** → 기대 산출물 정의

### 📋 평가 운영 준비 (개발 외)
- 평가자 5명 계정·센터·검사 18종·복수 센터 세팅, 검사 전용 내담자 계정 리허설
- 평가 항목명 ↔ 실제 화면명 매핑표 제공 ("케어보드"=내담자 상세 등) — 평가 양식에 첨부
- 알려진 미구현(환불·예약 기능군 등) 사전 고지로 평가 왜곡 방지

## 6. 판정 집계
