# 상담사의 하루 — 평가 대본 (시간 축 시나리오)

> 2026-07-23 설계. 목적: 기능 체크(24항목, 완료)가 아니라 **"상담사의 하루에 이 서비스가 들어오는가"** 를 판단한다.
> 구조: 회기 사이클(전-준비 / 중-기록 / 후-정리)의 반복 + 사이에 끼어드는 예외. 케이스 축(내담자 여정)은 등장 내담자 3인의 이력으로 관통.
> 평가 환경: 스테이징 온빛심리상담센터 · 상담사 이봄결(모바일=현장, 웹=책상). 리빙랩 평가 문안으로 재사용.

## 판단 기준 (전 장면 공통 — 마찰 지표)

| 지표 | 질문 |
|---|---|
| 맥락 도달 | 회기 전 **30초** 안에 "이 내담자 지금 상태"를 잡을 수 있는가 |
| 정리 비용 | 회기 후 **2분** 안에 출석·일지·다음 일정 정리가 끝나는가 |
| 화면 이탈 | 한 장면을 끝내는 데 다른 메뉴를 뒤지러 나가는 일이 있는가 |
| 기록의 보답 | 과거에 쌓은 기록(일지·출석·검사)이 지금 판단을 실제로 돕는가 |

## 등장 인물 (케이스 축 겹침)

| 내담자 | 케이스 상태 | 오늘의 역할 |
|---|---|---|
| 서은우 (신규, 6세) | 어제 데스크 접수, 오늘 첫 회기 | 첫 만남 — 정보 없는 상태에서의 준비 |
| 이도윤 (C00002) | 5회 진행, 노쇼 1회 이력 | **오늘 노쇼 발생** — 예외 처리·보호자 연락·보강 |
| 한지우 (C00003, 성인) | 4회 계약 중 3회 진행 | 오늘이 마지막 회기 — **연장 판단** |

## 장면 (시간순)

### S0. 전제 (데스크 — 대표 계정, 어제 처리분)
서은우+보호자 등록, 오늘 10:00 첫 회기 접수(담당 이봄결) · 이도윤 오늘 14:00 회기 · 한지우 오늘 16:00 회기(4회차, 마지막).

### S1. 08:50 출근길 — 모바일 홈
오늘 일정 3건과 "살펴볼 것"(첫 검사/첫 만남 신호) 확인 → 서은우가 처음인 걸 인지 → 홈에서 바로 내담자 상세로 이동해 예습(보호자·메모·사전기록지).
- 판단: 홈만 보고 오늘 하루의 모양이 잡히는가. 신규 내담자 예습 동선이 홈에서 한 번에 이어지는가.

### S2. 10:00 1회기 — 신규 첫 회기 (모바일)
회기 직전 일정 카드 → 상세(직전 요약 없음 = 첫 회기 정상) → 회기 진행(필드노트 녹음은 실기기 항목 — 진입점 존재만 확인) → 종료 후: 완료 처리 → 일지 작성(목표/진행/다음).
- 판단: 첫 회기라 정보가 없는 상태에서 화면이 비어 보이는가, 자연스러운가. 완료→일지가 한 흐름인가(2분 규칙).

### S3. 11:20 틈새 업무 — 검사 소견 (모바일)
검사 현황에서 완료된 검사(이도윤 웩슬러) 소견 열람·보완.
- 판단: 틈새 5분에 끝나는 크기인가.

### S4. 14:00 2회기 — 노쇼 (모바일)
14:05 이도윤 미도착 → 일정 상세에서 노쇼 처리(차감 여부 선택) → 내담자 상세의 빠른 연락(전화/문자)으로 보호자 연락 → 통화 결과 보강 합의 → 케이스에서 보강 회기 추가(내일 14:00).
- 판단: 노쇼 처리→연락→보강까지 한 문맥에서 끝나는가. (모바일에서 회기 추가가 되는가 — 안 되면 웹 위임이 명확히 안내되는가)

### S5. 16:00 3회기 — 마지막 회기와 연장 판단 (모바일→웹)
회기 완료+일지 → "4/4 소진" 인지(연장필요 신호) → 내담자와 연장 합의 가정 → 총회기 8로 확장 + 다음 회기 2건 추가(웹 or 모바일 — 실제 가능한 쪽 기록).
- 판단: 연장 시점을 시스템이 먼저 알려주는가(신호). 연장 행위(총회기+회기추가)의 동선.

### S6. 18:00 마감 — 웹 책상 정리
상담일지 리스트(전체/작성/미작성)에서 오늘 미작성 확인·마저 작성 → 내일 일정 확인 → 본인 담당 청구 상태 훑기.
- 판단: 하루의 꼬리가 몇 분인가. 미작성이 리스트로 잡히는가(오늘 신설 기능 검증).

## 리빙랩 운영 메모
- 평가자에게는 S1~S6를 "본인의 하루"로 소개하고 자유 이탈을 허용 — 이탈 지점 자체가 발견이다.
- 필드노트 녹음(S2)·푸시(S4 연락 수신)는 실기기 세션에서만.
- 이 대본은 24항목 기능 검증과 별개의 "체감 평가" 트랙이다.
