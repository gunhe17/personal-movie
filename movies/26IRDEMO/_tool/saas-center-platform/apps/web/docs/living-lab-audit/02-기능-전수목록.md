## 1. 스케줄

### /schedule/calendar — 캘린더 (기본 진입 화면)
- 뷰: 월간(Calendar) / 주간(WeeklyCalendar) / 일간 — 일간은 **장소별↔담당자별 타임라인 토글**(관리자만)
- 필터 4종: 프로그램(검사/상담/운영), 담당자(관리자 전용, 검색 지원), 내담자(검색 지원), 장소(일간+담당자별 모드만) + 모바일 필터 패널·초기화
- 네비: 이전/다음 기간, "오늘" 점프, 보이는 일정 건수 표시
- 일정 칩: 담당자 색상, 타입 아이콘, 세션 상태(예정/완료/취소/노쇼), 충돌 경고 배지, 운영시간 외 앰버 배지
- 액션: 신규 등록 버튼·날짜 셀 클릭·타임라인 빈 슬롯 클릭 → **ScheduleRegisterModal**(내담자 등록/상담 접수/검사 접수 3분기, 날짜·시간·장소 프리필해 해당 접수 페이지로 이동) / 일정 클릭 → ScheduleDetailModal(수정·취소·삭제) / 세션 상태 인라인 드롭다운 변경
- 시크릿 모드 시 내담자명 마스킹

### /schedule/reservations — 예약 현황 ⚠️더미
- 탭: 예약 대기/확정/취소, 검색(예약자·담당자), ReservationStatusCard 목록
- **데이터가 하드코딩 더미(page 25-59줄)** — 내담자 예약 신청을 받는 기능의 미래 화면으로 보임. 예약 설정과 세트

### /schedule/settings — 예약 설정 ⚠️저장 미확인
- 예약 승인 유형(직접 승인/자동 확정), 변경 횟수 제한(토글+스테퍼 max10), 예약금(고정액/퍼센트+금액), 센터 계좌번호·예금주, 입금 마감(1일/2일/1시간/2시간), 환불 규정(토글+문구 설정)
- 저장하기 버튼의 API 연결 미확인 — 예약현황과 함께 미완 기능군

### /schedule/field-notes — 필드노트 목록·상세 (메뉴 전 환경 숨김, URL 접근 가능)
- 목록: 처리상태 필터(대기/처리중/완료/실패), 연결 여부 필터, 리스트/그리드, 컬럼(날짜·작성자·녹음시간·상태·처리·연결·요약), 삭제
- 상세: 3초 폴링(processing/generating), 연결된 스케줄·케이스 카드, 사이드바 목록(100개·검색), **서식 선택(default/SOAP/DAP/BIRP/family_center)**, 처리 완료 감지 시 세션 노트 invalidate

### /operation/receive — 운영 일정 등록
- 제목(필수·200자)·장소(선택)·날짜·시작/종료(운영시간 외 앰버 경고)·메모(사이드패널)·알림 발송
- 요약 패널("아래 내용으로 접수할게요") · 종료≤시작이면 다음날 자동 조정 · Pydantic 필드 에러 매핑

## 2. 상담

### /counseling/status — 상담 현황
- 탭(전체/진행중/종결), 필터(검색·날짜(어제/1주/1개월)·담당자(관리자만)·유형(개별/그룹)·정렬), 리스트/그리드
- 컬럼: 내담자(그룹 "외 N명" 툴팁)·담당자·프로그램(케이스코드 태그)·**진행률 3구간 바(완료/예약/취소)**·청구 필요 표시·**다음 상담일(D-Day 색상 + 미처리 N건/연장·종결 확인 경고)**·접수일
- 액션: 상담 접수하기(권한), 행 클릭→상세, 케밥(종결 처리/종결 되돌리기/삭제 — 각 확인 모달)

### /counseling/status/[id] — 상담 상세 (웹에서 가장 깊은 화면)
- **연장 배너**: 예약 세션 1~2개 + 마지막 세션 D-7 이내 시 노출, "회기 추가"/"나중에"(7일 dismiss)
- 좌측 프로그램 패널: 케이스 정보, 상담 정보 수정, 내담자 카드(클릭→내담자 상세, **패키지 청구 pill**: 미청구→생성/미납·완료→보기), 세션 목록(상태 아이콘+필드노트 상태 닷), 회기 추가
- 세션 헤더: 회기 완료 / 진행 안 됨(사전 취소·노쇼 — 각각 사유·보충회기·차감 토글) / 되돌리기 / 회기 수정 / 회기 삭제(마지막 회기 경고) / **필드노트 버튼**(상태 뱃지)
- 내담자 탭(그룹상담): 출석 상태별 색(미확인/참석/불참/노쇼), 일지 작성 진행률(N/M), **일괄 참석 처리**, 내담자 추가, 탭 전환 시 일지 자동 저장
- **인라인 일지 에디터**: 상담 목표(3000자)/진행 내용(5000자)/다음 상담(3000자)/개인 메모(본인만·3000자), 자동 저장(blur·이탈·전환)+명시 저장, 출석 드롭다운(노쇼→사유+차감 토글 모달), 청구 버튼(세션 단위 생성/보기)
- **필드노트 뷰**: 분석 시작/재시도, 요약 재생성, **AI 상담일지 초안 생성→일지 주입**, 화자명 수정, 회기 연결, 전사 내보내기(text/json) — 크레딧·플랜 게이팅

### /counseling/receive — 상담 접수 (5단 스테퍼)
- ①프로그램(+개별/그룹) ②내담자(다중, **인라인 신규 등록**) ③담당자(다중+왕관=대표 지정, 상담사는 본인만) ④장소(선택) ⑤일정(멀티 날짜+시간, 프로그램 소요시간 자동 적용, **충돌 사전 검증 — room/member/both 사유 표시**, 제출 시 충돌 확인 모달) + 메모
- URL 프리필(?date&time&room_id&member_ids — 캘린더에서 진입 시), 우측 스테퍼 미리보기

## 5. 청구 (~125 기능, 최다 조밀 영역)

### /billing — 청구 목록
- 탭(전체/발행/완납), 검색·정렬, 리스트(8컬럼: 내담자·청구자·내역(패키지 뱃지+케이스코드)·총액·납부액·미수금(빨강)·상태·생성일)/그리드
- **미청구 세션 배너**(write 권한): 오늘까지 미청구 상담·검사 세션 카운트, 펼침 그리드, 항목별 "청구하기"→단가 매칭→세션 청구 모달

### 청구 생성 3경로 (공통: 바우처 선택→항목 자동 부착, 지원금(정가 초과=차단·잔액 초과=경고), 회기 부족=차단, 0원 청구=자동 완납 경고)
1. **자유 생성**(BillableCreateModal): 내담자 선택, 연동 대상 선택(오늘 미청구 세션→항목 자동), 항목 추가(단가표/수동)·삭제, 묶음 할인(%·원)
2. **세션 청구**(SessionBillingModal): 내담자·항목 prefill(잠금), 수량/단가만 수정 — 배너·상담 상세에서 진입
3. **패키지 선결제**(PackageBillingModal): 케이스 세션마다 항목 자동(취소 제외·시간순), 세션별 relatedSessionId, 할인 지원

### 청구 상세(BillableDetailModal) + 납부(PaymentModal)
