## B. 전문가 앱(모바일) 전수 목록

### 구조·인증
- 로그인(이메일/비번, 필드 검증, 네트워크/인증/서버 에러 분리) → 센터 1개면 자동 선택, 복수면 센터 선택 화면 → 권한 로드 → 탭 홈. 401 자동 refresh(대기 큐)
- 탭: **홈 / 일정 / 내담자 / 내 정보** + 실험실(lab — `__DEV__` 전용, 프로덕션 완전 숨김). 플로팅 pill 탭바 + 우측 **필드노트 FAB**(전역)
- 실험실: 시안 레지스트리(최종/Agentic/이전), 파일 1개=탭 N시안 규칙, mock 전용

### 홈 탭 ⚠️전환 중
- 데이터: 오늘 일정, 주간 일정, 미읽음 알림, 미연결 필드노트, Agentic 신호(일지 미작성·연장 필요)
- **주석상 기획 변경 중**: SoftTasksHome(할 일 중심) → 음성 우선 에이전트 홈으로 전환 예정, 현재 BriefStackHome 렌더. **리빙랩 전 홈 확정 필요**

### 일정 탭
- 3뷰: 월간 캘린더 / 주간 타임라인(WeekStrip) / 통계 대시보드
- 일정 카드 → `/schedule/[id]` 리다이렉터: 상담이면 세션 상세, 검사면 케이스 상세로 자동 이동. meeting/block은 폴백 안내
- 상태 도출(deriveStatus): 예정/진행중/완료/취소/노쇼
- **일정 신규 등록 UI 없음** — 접수·등록은 웹 위임 (의도 확인 필요)

### 내담자
- 목록: 검색(이름·전화), **초성 자동 그룹**, **관심 내담자 캐러셀**(즐겨찾기), 행 내 **전화·문자 바로 연결**, 담당/전체 구분 빈상태
- 상세: 프로필+즐겨찾기 하트, **Attention 신호 카드**, 다가오는 일정, **출석 패턴 점 시각화(●○●○●)**, 상담/검사 탭, 메모, 사전기록지·문서(조회), 기본 정보, 미수금 카드(권한)
- 케이스: 상담/검사 탭 + 상태 필터
- 문서: 폼 응답+문서 통합 검색 — ⚠️다운로드/공유 URL 임시 구현
- 등록: **7단계 위저드**(이름→생일·성별→연락처→보호자 분기→보호자 다중(주 보호자 배지)→추가 정보→확인), 409 중복 Alert. **바우처 스텝 없음(웹 전용)**

### 상담
- 목록: 검색·상태 필터(카운트)·**D-day 임박순 자동 정렬**, 카드(코드·"외 N명"·연장필요 라벨·진행바)
- 상세: **히어로**(다가오는 회기+직전 회기 1줄 요약+다음 회기), 요약 카드, 내담자 목록(진행 회기), 회기 리스트 → **회기 바텀시트**(일정·내담자별 출결·일지·청구), 미수금 카드+청구 버튼
- 세션 상세: 상태 변경(완료=전원 참석 default / 노쇼=전원 노쇼 / 취소=사유 enum+비고), 내담자별 출석(불참 사유 시트), 일지 작성(목표·진행·다음 — 웹과 동일 필드)
- 일지 목록: 검색·작성/미작성 필터·날짜 그룹·무한 스크롤 → CounselingNoteSheet(작성/조회)

### 검사
- 목록: 검색·상태 필터·카운트
- 상세: 요약(진행도 N/M)·내담자 정보·항목별(상태·**소견 작성 시트**·결과 보기·**중단/거부(사유 필수)+되돌리기**)·**task별 필드노트 상태**(온라인 검사는 숨김)·청구 버튼
- 모바일 범위: 조회+소견+필드노트+상태변경. **채점·보고서 생성·링크 발송은 웹 전용**. report.tsx 진입 경로 불명(미완 의심)

### 필드노트 — 모바일 차별화 sub-app (다크 몰입)
- FAB → 독립 공간(다크 스킨+플로팅 네비: 뒤로/◉녹음/노트 탭). 첫 진입 온보딩(기능 3카드→"녹음 시작하기")
- 홈: 오늘 회기 카드(진행 중=그라데이션 강조, 회기별 "녹음"/"분석 보기"), 검사 세션 펼침(**task별 녹음** — 투사검사 inquiry 분리), 최근 노트
- 녹음 흐름: 시작(회기/검사 선택 or blind) → 일시정지/재개/종료 → 자동 전사·화자분리·AI 분석 → 상담일지/검사 소견 **초안 prefill**
- 가드레일: 다른 회기 진행 중 충돌 해소("멈추고 새로?"=finish 저장), 시작 30분+ 전이면 확인 모달, **이어녹음은 분석 시작 전까지만**, 회기/task 1:1 연결(중복 409 토스트), 청크 업로드 재시도(백오프)
- 상세: 전사 싱크(탭→해당 지점 재생), 분석 렌즈 분리(상담=요약·키워드·이슈·정서·하이라이트 / 검사=질문↔반응·관찰·인용 — **해석성 출력 금지**), 다시 분석, 초안 생성

### 청구 (counselor 권한: 본인 담당)
- 목록: 검색·필터(전체/결제 대기/결제 완료), 카드(미수금 빨강, 패키지 뱃지). `read:billing` 없으면 "접근 권한이 없어요"
- 발행: 상담 회기 시트/검사 상세/패키지(상담만) → UnifiedBillingSheet(단가 prefill) · 납부 등록 · 완납은 영수증 시트(read-only)
- **환불·삭제·단가표는 웹 전용**

### 알림·공지·설정
- 알림: 4탭(전체/검사/상담/공지)+카운트, 클릭=읽음+딥링크, 모두 읽음, **앱 아이콘 뱃지 자동 리셋**, 무한 스크롤
- 알림 설정: 섹션(일정 리마인드/검사 제출/공지) 토글 — 인앱+푸시 동시 토글, 즉시 동기화
- 공지: 카테고리 뱃지·고정·미읽음·무한 스크롤·상세
- 내 정보: 프로필(역할 뱃지), 센터 전환(→내 센터: 디바이스 등록 해제→권한 재로드), 업무 바로가기 2×2(상담/검사/일지/청구(권한)), 버전, 로그아웃(디바이스 해제 포함)
- ⚠️ 내 센터의 "내 워크스페이스" = placeholder("준비중" Alert) — **리빙랩에서 노출됨**
- ⚠️ 내 정보 편집 불가(조회만) — 웹 위임

## C. 웹(counselor 시점) ↔ 모바일 패리티

| 기능 | 웹 | 모바일 | 비고 |
|------|:--:|:--:|------|
| 일정 조회 | O | O (3뷰) | 모바일이 통계 뷰 추가 |
| **일정/접수 등록** | O | **X** | 모바일은 조회·상태변경만 — 의도 확인 필요 |
| 회기 상태·출석·일지 | O | O | 동일 로직, UI만 바텀시트 |
| 내담자 등록 | O(폼) | O(위저드) | 모바일: 바우처 X |
| 내담자 편집 | O | X | |
| 사전기록지 재요청/발송 | O | X (조회만) | |
| 검사 접수·링크 발송·채점·보고서 | O | X | 모바일=소견·상태·필드노트만 |
| **녹음(필드노트)** | X (업로드만) | **O (전체 파이프라인)** | 모바일 차별화 |
| 청구 발행·납부 | O | O (본인 담당) | 환불·삭제·단가표=웹 |
| 즐겨찾기·빠른연락·Attention 신호 | X | O | 모바일 고유 |
| 알림 | O(30초 폴링) | O(푸시+뱃지) | |
| 내 정보 편집·자격 인증 | O | X | |

**경계 원칙(코드에서 확인된 실제 분업)**: 모바일 = 현장 기록·1차 입력(녹음·상태·일지·소견·본인 청구) / 웹 = 접수·관리·운영(등록·편집·채점·환불·설정).
