> A와 겹치는 항목(스케줄·내담자·바로링크·청구·푸시)은 관리자 관점(전체 데이터·설정 포함)으로 반복 평가.

## 알려진 제한 고지 (평가 대상 아님)

1. 웹 스케줄 통계(대시보드>분석)는 준비 중 — 모바일 일정 탭 기준으로 평가해 주세요.
2. AI 검사 해석 보조·바우처 서류 자동 생성은 이번 차수에서 제외됩니다.
3. 바우처 알림·납부 증빙은 상태 알림으로 제공됩니다(증빙 출력물 없음).
4. 검사 결과 다운로드 링크는 1시간 유효, 웹은 브라우저 푸시 대신 화면 내 알림입니다.
5. AI 기능(에이전트·일지 초안·필드노트)은 평가 시작 전 담당자가 사용 가능 여부를 안내드립니다.
