## 페이지 구조 요약

```
/applications                    # 센터 신청 목록
/applications/:applicationId     # 센터 신청 상세 (심사)

/centers                         # 센터 목록
/centers/:centerId               # 센터 상세 (기본정보 + 멤버 + 운영시간 + 상담실)
```

## 센터 신청 관리

### 1. 센터 신청 목록 (`/applications`)

#### 화면 구성

```
┌────────────────────────────────────────────────────────────┐
│  센터 등록 신청                                              │
├────────────────────────────────────────────────────────────┤
│  [대기중] [승인됨] [거절됨] [전체]         [검색: 센터명___] │
├────────────────────────────────────────────────────────────┤
│  센터명        │ 신청자     │ 연락처       │ 신청일    │ 상태  │
│─────────────────────────────────────────────────────────── │
│  마음건강센터   │ 홍길동     │ 02-1234-5678 │ 2026.01.15│ 대기중│
│  행복상담센터   │ 김철수     │ 02-9999-8888 │ 2026.01.14│ 승인됨│
│  ...           │            │              │           │      │
├────────────────────────────────────────────────────────────┤
│                    < 1  2  3  4  5 >                       │
└────────────────────────────────────────────────────────────┘
```

#### 상세 사양

| 항목 | 설명 |
|------|------|
| **기본 상태 필터** | `대기중(PENDING)` 기본 선택 (관리자가 가장 먼저 볼 항목) |
| **상태 탭** | 대기중 / 승인됨 / 거절됨 / 전체 |
| **검색** | 센터명 검색 (디바운스 300ms) |
| **정렬** | 신청일 최신순 (기본) |
| **페이지네이션** | 20건/페이지 |
| **행 클릭** | 신청 상세 페이지로 이동 |

#### 테이블 컬럼

| 컬럼 | 필드 | 비고 |
|------|------|------|
| 센터명 | `name` | |
| 신청자 | `applicant_name` | Person JOIN |
| 연락처 | `phone` | |
| 사업자등록번호 | `business_registration_number` | |
| 신청일 | `created_at` | YYYY.MM.DD 포맷 |
| 상태 | `status` | 뱃지: 대기중(노랑), 승인됨(초록), 거절됨(빨강) |

### 2. 센터 신청 상세 (`/applications/:applicationId`)

#### 화면 구성

```
┌────────────────────────────────────────────────────────────┐
│  ← 목록으로                                                │
│                                                            │
│  센터 등록 신청 상세                         [상태: 대기중]   │
├────────────────────────────────────────────────────────────┤
│                                                            │
│  ┌─── 신청 정보 ──────────────────────────────────────────┐ │
│  │ 센터명         마음건강 상담센터                         │ │
│  │ 신청자         홍길동                                   │ │
│  │ 연락처         02-1234-5678                            │ │
│  │ 주소           서울특별시 강남구 테헤란로 123 4층 401호   │ │
│  │ 사업자등록번호  123-45-67890                            │ │
│  │ 대표자명       홍길동                                   │ │
│  │ 소개           전문 상담사가 함께하는 마음건강 센터입니다. │ │
│  │ 신청일         2026.01.15 10:00                        │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                            │
│  ┌─── 심사 ───────────────────────────────────────────────┐ │
│  │                                                        │ │
│  │  거절 사유 (선택):                                      │ │
│  │  ┌────────────────────────────────────────────────┐    │ │
│  │  │                                                │    │ │
│  │  └────────────────────────────────────────────────┘    │ │
│  │                                                        │ │
│  │                        [거절하기]  [승인하기]            │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

#### 상세 사양 (PENDING 상태)

| 항목 | 설명 |
|------|------|
| **신청 정보 표시** | 센터명, 신청자(Person.name), 연락처, 주소, 사업자등록번호, 대표자명, 소개, 신청일 |
| **승인 버튼** | 클릭 시 확인 모달 → `POST /admin/center-applications/{id}/approve` |
| **거절 버튼** | 거절 사유 입력(선택) → 확인 모달 → `POST /admin/center-applications/{id}/reject` |
| **승인 후 동작** | 센터 자동 생성 → 토스트 "승인되었습니다" → 목록으로 이동 |
| **거절 후 동작** | 토스트 "거절되었습니다" → 목록으로 이동 |

#### 승인 확인 모달

```
┌──────────────────────────────────────┐
│  센터 등록 승인                       │
│                                      │
│  "마음건강 상담센터"를 승인하시겠습니까? │
│  승인 시 센터가 즉시 생성됩니다.        │
│                                      │
│              [취소]  [승인]            │
└──────────────────────────────────────┘
```

#### 거절 확인 모달

```
┌──────────────────────────────────────┐
│  센터 등록 거절                       │
│                                      │
│  "마음건강 상담센터"를 거절하시겠습니까? │
│                                      │
│  거절 사유:                           │
│  ┌──────────────────────────────┐    │
│  │ (상세 페이지에서 입력한 사유)   │    │
│  └──────────────────────────────┘    │
│                                      │
│              [취소]  [거절]            │
└──────────────────────────────────────┘
```

#### 상세 사양 (APPROVED / REJECTED 상태)

| 항목 | 설명 |
|------|------|
| **심사 결과 표시** | 심사일, 심사자, 거절 사유(거절 시) |
| **승인 시 추가 표시** | 생성된 센터 링크 → 클릭 시 `/centers/:centerId`로 이동 |
| **버튼 비노출** | 이미 처리된 신청은 승인/거절 버튼 숨김 |

```
┌─── 심사 결과 ─────────────────────────────────────────────┐
│ 상태         승인됨                                        │
│ 심사일       2026.01.16 10:00                              │
│ 심사자       관리자                                        │
│ 생성된 센터  마음건강 상담센터 (A3K9M2)  →                   │
└────────────────────────────────────────────────────────────┘
```

```
┌─── 심사 결과 ─────────────────────────────────────────────┐
│ 상태         거절됨                                        │
│ 심사일       2026.01.16 10:00                              │
│ 심사자       관리자                                        │
│ 거절 사유    사업자 등록번호가 유효하지 않습니다.              │
└────────────────────────────────────────────────────────────┘
```

## 센터 관리

### 3. 센터 목록 (`/centers`)

#### 화면 구성

```
┌────────────────────────────────────────────────────────────┐
│  센터 관리                                                  │
├────────────────────────────────────────────────────────────┤
│  [전체] [활성] [정지]      정렬:[최신순▼]  [검색: 센터명___] │
├────────────────────────────────────────────────────────────┤
│  센터명        │ 코드   │ 대표자   │ 연락처       │ 상태   │ │
│─────────────────────────────────────────────────────────── │
│  마음건강센터   │ A3K9M2 │ 홍길동   │ 02-1234-5678 │ 활성   │ │
│  행복상담센터   │ B7X2P4 │ 김철수   │ 02-9999-8888 │ 정지   │ │
│  ...           │        │         │              │        │ │
├────────────────────────────────────────────────────────────┤
│                    < 1  2  3  4  5 >                       │
└────────────────────────────────────────────────────────────┘
```

#### 상세 사양

| 항목 | 설명 |
|------|------|
| **상태 필터** | 전체 / 활성(active) / 정지(suspended) |
| **정렬** | 최신순(`created_at`), 이름순(`name`) |
| **검색** | 센터명, 센터코드 검색 (디바운스 300ms) |
| **페이지네이션** | 20건/페이지 |
| **행 클릭** | 센터 상세 페이지로 이동 |

#### 테이블 컬럼

| 컬럼 | 필드 | 비고 |
|------|------|------|
| 센터명 | `name` | |
| 센터코드 | `code` | 모노스페이스 폰트 |
| 대표자 | `representative_name` | |
| 연락처 | `phone` | |
| 멤버 수 | `member_count` | |
| 생성일 | `created_at` | YYYY.MM.DD |
| 상태 | `is_active` | 뱃지: 활성(초록), 정지(빨강) |

### 4. 센터 상세 (`/centers/:centerId`)

#### 화면 구성 - 탭 기반

```
┌────────────────────────────────────────────────────────────┐
│  ← 목록으로                                                │
│                                                            │
│  마음건강 상담센터                    [상태: 활성] [정지하기] │
│  코드: A3K9M2                                              │
│                                                            │
│  ┌──────┬──────┬───────┬──────┐                            │
│  │ 기본정보│ 멤버 │ 운영시간│ 상담실│                          │
│  └──────┴──────┴───────┴──────┘                            │
│                                                            │
│  (탭별 콘텐츠 영역)                                         │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

---

#### 4-1. 기본정보 탭

```
┌─── 기본 정보 ─────────────────────────────────────────────┐
│ 센터명            마음건강 상담센터                          │
│ 센터코드          A3K9M2                                   │
│ 연락처            02-1234-5678                             │
│ 주소              서울특별시 강남구 테헤란로 123 4층 401호    │
│ 소개              전문 상담사가 함께하는 마음건강 센터입니다.  │
│ 사업자등록번호     123-45-67890                             │
│ 대표자명          홍길동                                    │
│ 생성일            2026.01.15                               │
│ 최종 수정일        2026.02.01                               │
└────────────────────────────────────────────────────────────┘
```

| 항목 | 설명 |
|------|------|
| **표시 정보** | 센터명, 코드, 연락처, 주소(우편번호 + 도로명 + 상세), 소개, 사업자등록번호, 대표자명, 생성일, 수정일 |
| **수정** | 플랫폼 관리자는 센터 정보를 **읽기 전용**으로 확인. 센터 정보 수정은 센터 관리자가 센터 앱에서 직접 수행 |

---

#### 4-2. 멤버 탭

```
┌─── 멤버 목록 ─────────────────────────────────────────────┐
│  총 5명                                                    │
├────────────────────────────────────────────────────────────┤
│  이름     │ 이메일              │ 역할    │ 고용형태 │ 가입일  │
│────────────────────────────────────────────────────────────│
│  홍길동   │ hong@example.com   │ 센터장  │ 정규직   │ 01.15  │
│  김상담사 │ kim@example.com    │ 상담사  │ 정규직   │ 01.20  │
│  박검사사 │ park@example.com   │ 상담사  │ 계약직   │ 02.01  │
│  ...     │                    │         │         │        │
└────────────────────────────────────────────────────────────┘
```

| 항목 | 설명 |
|------|------|
| **표시 정보** | 이름(Person.name), 이메일(Account.email), 역할(Role.name), 고용형태, 가입일 |
| **읽기 전용** | 플랫폼 관리자는 멤버 목록 조회만 가능. 멤버 추가/수정/삭제는 센터 관리자 권한 |
| **페이지네이션** | 멤버 수가 적으므로 전체 표시 (50명 초과 시 페이지네이션) |

---

#### 4-3. 운영시간 탭

```
┌─── 영업시간 ───────────────────────────────────────────────┐
│  요일     │ 영업시간           │ 휴게시간          │ 상태    │
│────────────────────────────────────────────────────────────│
│  월요일   │ 09:00 ~ 18:00     │ 12:00 ~ 13:00    │ 영업    │
│  화요일   │ 09:00 ~ 18:00     │ 12:00 ~ 13:00    │ 영업    │
│  수요일   │ 09:00 ~ 18:00     │ 12:00 ~ 13:00    │ 영업    │
│  목요일   │ 09:00 ~ 18:00     │ 12:00 ~ 13:00    │ 영업    │
│  금요일   │ 09:00 ~ 17:00     │ -                │ 영업    │
│  토요일   │ -                 │ -                │ 휴무    │
│  일요일   │ -                 │ -                │ 휴무    │
└────────────────────────────────────────────────────────────┘

┌─── 비영업시간 (휴무/공휴일) ──────────────────────────────────┐
│  사유                  │ 패턴              │ 등록자  │ 기간    │
│────────────────────────────────────────────────────────────│
│  신정                  │ 매년 1/1          │ SYSTEM │ 2026년  │
│  설날 연휴             │ 2026. 1/27~29     │ SYSTEM │ 2026년  │
│  4.5일제 (둘째주 화)    │ 매월 둘째주 화요일  │ CENTER │ 상시    │
│  ...                  │                   │        │         │
└────────────────────────────────────────────────────────────┘
```

| 항목 | 설명 |
|------|------|
| **영업시간** | 요일별 영업시간/휴게시간 테이블 (7일) |
| **비영업시간** | 공휴일(SYSTEM), 자체 휴무(CENTER) 구분 표시 |
| **읽기 전용** | 운영시간 수정은 센터 관리자가 센터 앱에서 수행 |
| **패턴 표시** | NonOperatingTime의 패턴 조합을 사람이 읽기 쉬운 텍스트로 변환 |

**패턴 변환 규칙**:

| 패턴 | 표시 |
|------|------|
| year=2026, month=1, day=1 | `2026. 1/1` |
| month=1, day=1 (year=null) | `매년 1/1` |
| month_week=2, weekday=TUE | `매월 둘째주 화요일` |
| weekday=SAT | `매주 토요일` |

#### 4-4. 상담실 탭

```
┌─── 상담실 목록 ───────────────────────────────────────────┐
│  총 3개                                                    │
├────────────────────────────────────────────────────────────┤
│  상담실명     │ 설명              │ 상태    │ 생성일         │
│────────────────────────────────────────────────────────────│
│  상담실 A    │ 창가 쪽, 조용한    │ 활성    │ 2026.01.15    │
│  상담실 B    │ 넓은 공간          │ 활성    │ 2026.01.15    │
│  상담실 C    │ 아동 전용          │ 비활성  │ 2026.02.01    │
└────────────────────────────────────────────────────────────┘
```

| 항목 | 설명 |
|------|------|
| **표시 정보** | 상담실명, 설명, 활성/비활성 상태, 비활성 사유(있을 경우), 생성일 |
| **읽기 전용** | 상담실 관리는 센터 관리자가 센터 앱에서 수행 |

### 5. 센터 정지/활성화

#### 정지 모달

```
┌──────────────────────────────────────┐
│  센터 정지                            │
│                                      │
│  "마음건강 상담센터"를 정지하시겠습니까? │
│                                      │
│  정지 사유 (필수):                     │
│  ┌──────────────────────────────┐    │
│  │                              │    │
│  └──────────────────────────────┘    │
│                                      │
│  정지 기간:                           │
│  ○ 무기한                             │
│  ○ 기간 지정  [____년 __월 __일] 까지  │
│                                      │
│              [취소]  [정지]            │
└──────────────────────────────────────┘
```

| 항목 | 설명 |
|------|------|
| **정지 사유** | 필수 입력 (textarea) |
| **정지 기간** | 무기한 / 특정 일시까지 선택 |
| **API** | `POST /admin/centers/{centerId}/suspend` |
| **정지 효과** | 해당 센터 모든 사용자 접근 차단 (is_active=false) |

#### 활성화

| 항목 | 설명 |
|------|------|
| **조건** | 정지된 센터에만 활성화 버튼 표시 |
| **확인 모달** | "마음건강 상담센터를 활성화하시겠습니까?" |
| **API** | `POST /admin/centers/{centerId}/activate` |

## 상태별 UI 동작 정리

### 신청 상태

| 상태 | 뱃지 색상 | 상세 페이지 액션 |
|------|----------|-----------------|
| PENDING | 노랑 (`amber`) | 승인/거절 버튼 표시 |
| APPROVED | 초록 (`green`) | 생성된 센터 링크 표시 |
| REJECTED | 빨강 (`red`) | 거절 사유 표시 |

### 센터 상태

| 상태 | 뱃지 색상 | 상세 페이지 액션 |
|------|----------|-----------------|
| 활성 (is_active=true) | 초록 (`green`) | 정지하기 버튼 |
| 정지 (is_active=false) | 빨강 (`red`) | 활성화 버튼 |
