## 7. 🎯 우선순위별 누락 항목 압축 리스트

### 🔴 CRITICAL — 인허가/사업 마일스톤 직격 (10건)
1. 풀배터리 통합 보고서 + sLLM 요약 AI
2. 임상전문가(감수자) 역할 + 감수 워크플로우
3. 내담자 본인/보호자 열람 채널
4. 보고서 잠금 / 전자서명 / 해시 / 타임스탬프 / 다운로드 추적
5. 저장 시 AES-256 암호화 (PII / 검사원본 / 결과)
6. MFA 2차 인증
7. 비밀번호 복잡도 강제 + 만료 주기 + 세션 타임아웃
8. AI 신뢰도 임계치 경고 / 재검토 강제 (ISO 14971)
9. 통합/E2E 테스트 + 커버리지 게이트 + RTM 문서 (SVR 기반)
10. IEC 62366 사용적합성 추적 로깅

### 🟡 IMPORTANT — 운영/실증/임상시험 진입 직전 (10건)
11. 내담자 임상정보 확장 (주호소/진단/약물/가족력) + 보호자 정보
12. 개인정보 동의서 관리 (수집·이용·철회)
13. 비밀번호 변경 UI (API 有, UI 無)
14. 감사로그 조회 UI (API 有, UI 無)
15. 기관 정보 수정 UI
16. 보고서 미리보기
17. 품질지표 대시보드 (일치도/중대오류/재검률/시간단축)
18. 임상가·내담자 만족도 조사 + NPS
19. XML(EMR) / Excel / HTML 보고서 형식
20. 로르샤흐 마킹-오디오 시간축 동기화 UX + Exner 비율 완전성 검증

### 🟢 RECOMMENDED — 확장·운영·차별화 (4건)
21. EMR / PACS / LIS 외부 연동 (HL7·FHIR·DICOM)
22. 사용자 매뉴얼·FAQ·용어집·튜토리얼
23. 백업/복구 자동화·모니터링·폐쇄망 모드
24. AI 모델 버전 자동 기록 흐름 검증
