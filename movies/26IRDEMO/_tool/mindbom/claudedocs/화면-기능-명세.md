# 마인드봄 (MindBom) — 화면 및 기능 명세서

> 투사적 심리검사(HTP·로르샤하·SCT) AI 해석 보조 시스템
> 본 문서는 부서 간 공유용 화면/기능 목록입니다. 화면 설명 부분에 캡처 이미지를 첨부해 사용하세요.

---

## 0. 전체 구조 한눈에 보기

| 구분 | 화면 | 비고 |
|------|------|------|
| **로그인 전(공개)** | 로그인 / 회원가입 / 비밀번호 찾기·재설정 / 초대 수락 / 약관 / 개인정보처리방침 | 누구나 접근 |
| **공통** | 기관 선택 / 대시보드 / 설정(내 계정·기관) | 로그인 필요 |
| **대상자 관리** | 내담자 목록 / 내담자 상세 | |
| **조직 관리** | 직원 목록 / 직원 상세 / 감사추적 | 관리자 전용 |
| **검사** | 검사 목록 / 검사 상세 | 모든 검사 공통 진입점 |
| **HTP 검사** | 검사 진행 / 결과 | 그림 검사 |
| **로르샤하 검사** | 검사 진행 / 채점 / 결과 | 음성 검사 |
| **SCT 검사** | 검사 진행 / 결과 | 문장완성 검사 |
| **관리도구** | 로르샤하 영역 관리 | 데이터 관리용 |

### 핵심 원칙: CDSS (임상 의사결정 지원)
> **AI는 초안만 작성하고, 최종 판단·확정은 반드시 임상심리사가 합니다.** AI가 단독으로 결과를 결정하지 않습니다.

### 검사 진행 흐름 (상태 머신)
```
검사 등록 → 검사 진행 → AI 분석 → AI 초안 완료
→ 임상심리사 검토 → 확인 완료 → 보고서 생성 → 완료
```

## 1. 로그인 전 화면 (공개)

### 1-1. 로그인
- **용도**: 기존 사용자 계정 접속
- **기능**: 이메일·비밀번호 입력 / 로그인 버튼 / 비밀번호 찾기·회원가입 링크 / 우측 서비스 소개 슬라이드(자동 전환)
- **이동**: 로그인 후 소속 기관이 여러 개면 '기관 선택', 1개면 바로 '대시보드'

### 1-2. 회원가입
- **용도**: 새 기관의 **관리자** 계정 생성
- **기능**: 이메일·이름·기관명·비밀번호·비밀번호 확인 입력 / 비밀번호 정책 안내(8자 이상, 대·소문자·숫자·특수문자) / 가입하기
- **이동**: 가입 즉시 자동 로그인 → 대시보드

### 1-3. 비밀번호 찾기
- **용도**: 재설정 링크 이메일 요청
- **기능**: 이메일 입력 / 재설정 링크 받기 / (보안상) 가입 여부와 무관하게 동일 안내 문구 표시

### 1-4. 새 비밀번호 설정
- **용도**: 이메일 링크를 통해 새 비밀번호 설정
- **기능**: 새 비밀번호·확인 입력 / 변경 / 링크 만료·오류 안내 / 성공 시 로그인 화면으로 자동 이동

### 1-5. 초대 수락
- **용도**: 기관 관리자의 초대 링크로 기관에 합류
- **기능**: 초대 정보(기관명·역할·이메일) 표시 / 신규 계정이면 비밀번호 신규 설정, 기존 계정이면 기존 비밀번호 입력 / 가입 완료
- **비고**: 기존 계정 보유자는 해당 기관에만 추가로 합류

### 1-6. 이용약관 / 1-7. 개인정보처리방침
- **용도**: 법적 고지 문서 열람
- **비고**: SaMD 2등급 의료기기 관련 의무 사항 포함(AI 초안은 임상심리사 검토 필수, 자체 폐쇄형 AI 처리, 데이터 보관·삭제 정책 등)

## 2. 공통 화면

### 2-1. 기관 선택
- **용도**: 여러 기관 소속자가 접속할 기관 선택
- **기능**: 소속 기관 목록(기관명·역할) 카드 클릭 선택 / 다른 계정으로 로그인
- **비고**: 기관이 1개면 자동 통과

### 2-2. 대시보드 (홈)
- **용도**: 검사 현황을 한눈에 파악
- **기능**:
  - **처리 현황**: 상태별 검사 분포 차트 / 상태별 평균 처리시간 차트
  - **검토 지연 경고**: 5일 이상 미검토 검사가 있으면 배너 표시 + 해당 목록 바로가기
  - **검사 일정 타임라인**: 예정·진행·완료 검사를 시간순으로 표시, 클릭 시 해당 검사로 이동

### 2-3. 설정 — 내 계정
- **용도**: 본인 계정·보안 관리 (전 직원 접근 가능)
- **기능**: 이름·이메일·역할 표시(읽기 전용) / 비밀번호 변경(변경 시 전체 재로그인)

### 2-4. 설정 — 기관 (관리자 전용)
- **용도**: 기관 정보 확인
- **기능**: 기관명·유형·ID·등록일 표시(읽기 전용)
- **비고**: 관리자가 아니면 '내 계정'으로 자동 이동

## 3. 대상자(내담자) 관리

### 3-1. 내담자 목록
- **용도**: 기관 전체 내담자 조회·관리
- **기능**:
  - 요약 카드: 전체 / 활성 / 비활성 내담자 수
  - 필터: 이름 검색, 상태(활성·비활성), 성별
  - 목록 테이블: 이름·성별·생년월일·나이·연락처·상태·등록일 (행 클릭 시 상세)
  - **내담자 등록**: 모달에서 이름·생년월일·성별·연락처·이메일·학력·직업·의뢰경로·비고 입력
  - 페이지네이션
- **비고**: 시크릿 모드 시 이름·연락처 마스킹

### 3-2. 내담자 상세
- **용도**: 내담자 정보 조회·수정 및 검사 이력 확인
- **기능**:
  - 기본 정보 표시 / 정보 수정(모달) / 활성·비활성 전환
  - 검사 이력 테이블: 검사 유형·검사자·상태·등록일 (상태별 색상 표시)
- **비고**: 시크릿 모드 시 민감 정보 마스킹

---

## 4. 조직 관리 (관리자 전용)

### 4-1. 직원 목록
- **용도**: 기관 직원 관리 및 초대
- **기능**:
  - 요약 카드: 전체 / 관리자 / 임상심리사 / 연구원 수
  - 탭: 전체 직원 / 초대 현황(보류 중 초대 목록)
  - 필터: 이름·이메일 검색, 역할
  - 목록 테이블: 이름·이메일·역할·상태·등록일 (행 클릭 시 상세)
  - **직원 초대**: 모달에서 이름·이메일·역할 입력 후 초대 이메일 발송

### 4-2. 직원 상세
- **용도**: 직원 정보 조회·수정 및 담당 검사 이력
- **기능**: 기본 정보(이름·역할·이메일·자격증번호 등) 표시·수정 / 활성·비활성 전환 / 담당 검사 이력 테이블

### 4-3. 감사추적 (Audit Trail)
- **용도**: 시스템 내 모든 활동 이력 조회 (규제 대응 필수)
- **기능**:
  - 필터: 행위자 이메일 검색, 행위 유형(로그인·생성·수정·삭제·상태전이·AI분석·보고서생성·초대 등), 날짜 범위, 초기화
  - 로그 테이블: 시간·행위·대상·행위자·IP / 행 클릭 시 상세(변경 전후 값, 메타데이터 등) 전개
  - 행위별 색상 구분, 페이지네이션

## 5. 검사 공통

### 5-1. 검사 목록
- **용도**: 기관 전체 검사 관리
- **기능**:
  - 요약 카드: 전체 / 진행 중 / AI 분석 중 / 검토 필요 / 완료 수
  - 필터: 검사 상태, 검사 유형(HTP·로르샤하·SCT), 내담자 이름 검색
  - 목록 테이블: 내담자·생년월일·성별·검사유형·검사자·검사일·상태 (상태별 색상)
  - **새 검사 등록**(모달), 페이지네이션

### 5-2. 검사 상세
- **용도**: 검사 단계별 진입점 및 진행 상황 확인
- **기능**:
  - 현재 상태에 따라 액션 버튼 변경: 검사 시작 / 이어하기 / 채점하기 / 채점 검토
  - 보고서 PDF·결과 보기 버튼(확인 완료 이상에서 활성화)
  - 검사 정보(유형·상태·예약·일정·메모), 관련자(내담자·검사자) 표시
  - 진행 단계 시각화(완료 단계 체크 표시)

## 6. HTP 검사 (집-나무-사람 그림 검사)

### 6-1. HTP 검사 진행
- **용도**: 그림 이미지 업로드 → AI 분석 → 객체 검출·해석 기록
- **기능**:
  - 4개 탭: 집 / 나무 / 남자사람 / 여자사람
  - 이미지 업로드 시 **AI 자동 분석 시작** → 원본·분석 이미지 비교
  - 검출된 객체(박스)를 드래그·리사이즈로 위치·크기 조정
  - 사후질문(PDI): 검사자 질문 ↔ 내담자 답변 쌍으로 입력(자동저장)
  - 분석 결과 테이블: 객체 목록의 표현 양상 수정, 항목 추가·삭제 (자동저장)
- **비고**: 작성 후 '결과 보기'로 다음 단계 진행

### 6-2. HTP 결과
- **용도**: AI 해석 초안을 검토·수정하고 최종 확인/완료
- **기능**:
  - 그림 썸네일 클릭으로 특정 그림 해석만 필터링
  - 해석 카테고리 탭: 자기개념 / 정서적 안정성 / 대인관계
  - 해석 테이블(그림·임상요소·표현양상·해석문장) + **중요 항목 표시(별)** + '중요 항목만' 필터
  - 사후질문 기록 조회 패널
  - 액션: '확인 완료'(검토→확정), '완료', '보고서 PDF' 다운로드(확인 완료 이상)
- **비고**: 보고서 생성 후에는 이전 단계로 되돌아가기 차단

## 7. 로르샤하 검사 (잉크반점 검사)

### 7-1. 로르샤하 검사 진행
- **용도**: 반응 녹음 + 카드 위 지각 영역 기록
- **기능**:
  - 음성 녹음 시작/중지 (검사자가 내담자 반응 기록)
  - 10장 카드(I~X) 탭 진행
  - 카드 위에 내담자가 본 영역을 손으로 그리기(영역별 색상·음성 타임스탬프 자동 기록)
  - 영역별 메모 입력(자동저장), 표준 영역 코드(W·D1·Dd22 등) 지정, 추가·수정·삭제
  - 완료 시 녹음 업로드 → **AI 음성인식 + 화자분리 + 전사 자동 생성**
- **비고**: 채점 단계로 넘어간 검사는 진입 불가(채점 화면으로 자동 이동), 최소 1개 영역 필수

### 7-2. 로르샤하 채점 / 코딩
- **용도**: AI가 제시한 채점(Exner CS 기준)을 임상심리사가 검토·수정·확정
- **기능**:
  - 카드별 영역 목록 및 채점 상태 표시
  - 영역 선택 시 AI 채점 초안(위치·결정인자·형태질·내용·대중반응) + AI 신뢰도·추론 근거 표시
  - 임상심리사 최종 코딩 입력(초안 수정 또는 신규)
  - 전사 텍스트 패널: 영역별 해당 발화 선택·연결, 자유연상 텍스트 입력
  - 선택 영역 AI 채점 재실행, 카드 이미지 줌(50~300%)
  - 전 영역 완료 후 **'확정'** → 결과 화면 이동
- **비고**: 확정 이후 상태는 읽기 전용('결과 보기'만 가능)

### 7-3. 로르샤하 결과 (구조 요약)
- **용도**: 확정된 채점을 Exner CS 구조 요약 형식으로 시각화
- **기능**: 섹션 탭(Upper / Lower / Special Indices) / 표·차트 / 보고서 PDF 다운로드
- **비고**: 확정 이후 상태에서만 접근(미확정 시 채점 화면으로 안내)

## 8. SCT 검사 (문장완성검사)

### 8-1. SCT 검사 진행
- **용도**: 내담자가 미완성 문장(60문항)을 직접 완성
- **기능**:
  - 진행률 표시 / 문장 제시 + 응답 입력 / (복합형 문항은) 이유 입력
  - 이전·다음 이동 시 자동저장, 응답 개수 카운트, 저장 상태 표시(저장중·저장됨·재시도)
  - 완료 시 '결과 보기'
- **비고**: 임시저장(localStorage) 후 서버 자동 저장, 저장 실패 시 자동 재시도

### 8-2. SCT 결과 (채점)
- **용도**: AI가 5개 영역별 점수화 → 임상심리사 검토·수정·확정
- **기능**:
  - 3단계: 응답 검토 → AI 분석 중 → 결과 보기
  - 결과: 영역별 점수 차트·테이블 / **점수 직접 수정** / 채점 기준 안내(툴팁)
  - '확정' → 보고서 생성 가능 / 보고서 PDF 다운로드(확인 완료 이상)

---

## 9. 관리 도구

### 9-1. 로르샤하 영역 관리 (관리자/데이터 관리용)
- **용도**: 카드별 표준 영역(좌표) 정의·편집
- **기능**:
  - 카드(1~10) 선택, 사각형·다각형 그리기 모드
  - 영역별 코드·타입(W·D·Dd·DdS)·이름 입력
  - 방향키 미세 조정, 좌우대칭 자동 생성
  - JSON 내보내기·다운로드·가져오기, 전체 삭제
- **비고**: 일반 검사 업무용이 아닌 기준 데이터 구축용 전문 도구
