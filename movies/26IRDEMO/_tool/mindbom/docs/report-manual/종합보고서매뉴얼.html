1-1 화면 구성
  • 종합보고서 작성 화면은 좌측 사이드바 · 중앙 본문 · 상단 툴바로 구성됩니다.
  • 좌측 사이드바에서 검사자료를 첨부하고 검사 간 교차분석을 확인합니다.
  • 중앙 본문은 A4 규격이며, 실제 인쇄물과 같은 모양으로 편집합니다.
  • 상단 툴바에서 서식을 지정하고 AI 종합 리뷰를 실행합니다.

▲ 종합보고서 작성 화면
1좌측 사이드바
  • [검사자료] 탭에서 결과지를 본문에 첨부하고, [교차분석] 탭에서 검사 간 소견을 대조합니다.
2상단 툴바
  • 글꼴 서식·목록·정렬 등 편집 도구와 우측의 [AI 종합 리뷰] 버튼이 있습니다.
3중앙 본문 (A4)
  • 보고서 내용을 작성합니다. 상단에 문단 수와 글자 수가 표시됩니다.
2검사자료 첨부
  • 2-1 자료 목록 확인
  • 2-2 본문에 자료 삽입
2-1 자료 목록 확인
  • 좌측 [검사자료] 탭에 내담자가 받은 검사와 그 결과지가 표시됩니다.
  • 검사별로 접기/펼치기가 가능하며, [전체보기]로 결과지 원본을 확인할 수 있습니다.
  • 확인이 완료되지 않은 검사에는 상태 배지가 함께 표시됩니다.
1 2 3
▲ 검사자료 목록
1검사 헤더
  • 검사 코드와 검사명 · 검사일이 표시됩니다. 우측 화살표로 목록을 접거나 펼칩니다.
2전체보기
  • 해당 검사의 결과지 원본을 큰 화면으로 확인합니다.
3자료 썸네일
  • 결과지·차트·표가 썸네일로 표시됩니다. 클릭하면 본문에 삽입됩니다.
2-2 본문에 자료 삽입
  • 본문에서 자료를 넣을 위치에 커서를 둡니다.
  • 좌측 자료 썸네일을 클릭하면 커서 위치에 삽입됩니다.
  • 이미 삽입한 자료에는 첨부됨 표시가 붙어 같은 자료를 두 번 넣는 실수를 막습니다.
▲ 결과지 이미지가 본문에 삽입된 상태
참고 · 삽입한 자료는 본문의 일부가 되므로, 보고서를 생성하면 그대로 인쇄됩니다. 자료 아래에 해당 결과에 대한 해석을 함께 기술하면 읽는 사람이 근거를 바로 확인할 수 있습니다.
3검사 간 교차분석
  • 3-1 교차분석 개요
  • 3-2 규준 점수 비교
  • 3-3 영역별 소견 대조
3-1 교차분석 개요
  • 좌측 [교차분석] 탭에서 여러 검사의 소견을 구성개념별로 대조합니다.
  • 상단에 검사 수 · 불일치 영역 수 · 규준 보유 검사 수가 요약됩니다.
▲ 교차분석 요약
중요 · 서로 다른 검사의 원점수를 하나의 척도로 환산하지 않습니다. 표준화 검사(규준 보유)만 정량 비교하고, 투사적 검사는 정성 소견으로만 표시합니다. 검사 간 점수를 환산할 표준화된 근거가 존재하지 않기 때문입니다.
3-2 규준 점수 비교
  • 규준이 있는 표준화 검사의 백분위 · T점수만 레이더 차트에 표시됩니다.
  • 검사 칩을 눌러 차트에서 켜고 끌 수 있습니다.
  • 점선은 표시된 검사들의 규준 평균선입니다.
▲ 규준 점수 비교 (표준화 검사 전용)
투사적 검사(HTP · 로르샤하 · SCT)는 규준 점수가 없으므로 이 차트에서 제외되며, 아래 영역별 소견 대조에서 정성 소견으로 표시됩니다.
3-3 영역별 소견 대조
  • 구성개념별로 소견 있음과 정상 범위 검사를 나란히 배치합니다.
  • 불일치 판단은 점수 차가 아니라 임상적 방향(상승 vs 정상)이 갈리는지로 합니다.
  • 투사적 검사는 정성 배지와 함께 원 소견을 그대로 표기합니다.
1 2 3
▲ 공격성 영역의 소견 불일치
1불일치 정도
  • 소견 불일치 · 부분 불일치 · 일치 중 하나로 표시됩니다.
2소견 있음
  • 해당 영역에서 상승 소견을 보인 검사 목록입니다.
3정상 범위
  • 같은 영역에서 정상 범위로 나온 검사 목록입니다.
※ 하단 해석 문구는 두 검사가 경쟁하는 것이 아니라 서로 다른 층위(자기보고 vs 수행기반)를 측정한다는 관점에서 작성됩니다. 최종 해석은 임상가가 판단합니다.
4구간별 AI 리뷰
  • 4-1 리뷰 실행
  • 4-2 리뷰 카드 읽기
  • 4-3 수정안 적용
4-1 리뷰 실행
  • 본문에서 검토할 문장을 드래그해 선택합니다.
  • 선택 영역 옆에 [AI 분석] 버튼이 나타납니다. 클릭하면 리뷰 카드가 열립니다.
▲ 문장 선택 후 나타나는 [AI 분석] 버튼
구간별 리뷰는 선택한 문장만 검토합니다. 보고서 전체를 보려면 5장의 종합 AI 리뷰를 사용합니다.
4-2 리뷰 카드 읽기
  • 리뷰 항목은 임상적 중요도 순으로 정렬됩니다.
  • 카드 헤더를 끌어 위치를 옮길 수 있습니다. 본문이 가릴 때 사용합니다.
  • 다른 문장을 선택하면 카드가 그 옆으로 다시 배치됩니다.
종류의미
검토 필요단정적 서술 · 진단명 직접 기술 등 작성 원칙과 관련된 지적
근거 연결인용된 수치가 검사 결과와 대조되는지 확인한 결과
표현 제안문장 길이 · 검사 간 불일치 반영 권고
맞춤법 / 표현 개선이중 피동 · 임상 용어 등 문체 교정
▲ AI 리뷰 카드
4-3 수정안 적용
  • 수정 제안이 있는 항목에는 변경 전후가 함께 표시됩니다.
  • [이 수정안 적용]은 해당 1건만 반영합니다.
  • 카드 상단의 [N곳 모두 적용]을 누르면 제안된 교정을 한 번에 반영합니다.
▲ 변경 전 → 변경 후 미리보기와 적용 버튼
AI가 본문을 임의로 고치지 않습니다. 제안된 내용을 확인하고 버튼을 눌러야 반영되며, 반영 여부는 전적으로 작성자가 결정합니다.
5종합 AI 리뷰
  • 5-1 분석 실행
  • 5-2 결과 읽기
  • 5-3 수정안 검토와 반영
5-1 분석 실행
  • 툴바 우측 [AI 종합 리뷰]를 클릭하면 우측 패널이 열리고 분석이 시작됩니다.
  • 네 단계로 진행되며, 각 단계의 소요 시간은 작업량에 따라 다릅니다.
단계내용
1문서 구조 파악 — 섹션 구성과 분량을 확인합니다
2검사 결과 대조 — 첨부된 검사가 본문에 반영되었는지 확인합니다
3서술 일관성 검토 — 문서 안에서 상반된 기술이 없는지 확인합니다
4표현·문체 점검 — 구간별 지적을 문단 단위로 집계합니다
▲ 분석 진행 표시
5-2 결과 읽기
  • 완성도 점수(0~100)와 함께 검토사항이 나열됩니다.
  • 각 항목의 색 점이 심각도이며, 마우스를 올리면 설명이 표시됩니다.
  • [이동]을 누르면 본문의 해당 위치로 이동합니다.
1 2 3 4
▲ 검토 결과
1완성도 점수
  • 글자 수 · 섹션 수 · 검사 반영 현황이 함께 표시됩니다.
2검토 종류와 심각도
  • 섹션 누락 · 서술 모순 · 결과 미반영 · 표현 교정으로 구분됩니다.
3이동
  • 본문에서 해당 위치를 바로 확인합니다.
4수정안
  • 버튼을 누르면 미리보기가 열립니다. 바로 반영되지 않습니다.
5-3 수정안 검토와 반영
  • 미리보기에서 변경 전후를 확인합니다.
  • 같은 표현이 여러 곳에 있으면 몇 곳이 바뀌는지 안내합니다.
  • [본문에 적용]을 누르면 반영되고, 점수와 검토사항이 즉시 갱신됩니다.
▲ 수정 미리보기
서술 모순은 양쪽 선택지를 제시합니다. 어느 쪽이 맞는지는 검사 결과와 임상적 판단으로 결정할 문제이므로, AI가 한쪽을 고르지 않습니다.
5-3 수정안 검토와 반영 (계속)
  • 반영하면 해당 검토사항이 목록에서 사라지고 완성도 점수가 오릅니다.
  • 남은 검토사항을 차례로 처리하며 보고서를 완성합니다.
  • 하단 작성 체크리스트에서 항목별 충족 여부를 확인할 수 있습니다.

6. 보고서 생성
  • 작성을 마치면 우측 상단 [보고서 생성]으로 PDF를 내려받습니다.
  • 표지와 마지막 장의 표시 여부는 툴바의 화면 표시 설정에서 조정합니다.
  • 본문에 첨부한 검사자료 이미지도 함께 인쇄됩니다.
▲ 보고서 생성
작성 원칙 · AI는 초안과 검토 의견을 제시하는 보조 도구입니다. 보고서에 담기는 모든 해석과 판단의 최종 책임은 작성자인 임상가에게 있습니다.
