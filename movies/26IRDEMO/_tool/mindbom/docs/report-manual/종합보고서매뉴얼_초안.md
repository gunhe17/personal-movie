# 마인드봄 종합보고서 작성 매뉴얼 (초안)

> 대상: 임상심리사·상담사 (보고서 작성자)
> 📸 스크린샷은 `docs/report-manual/images/` 에 저장. 본문의 `[📸 파일명]` 참조.
>
> ⚠️ **작성 원칙**: AI는 초안과 검토 의견을 제시할 뿐이며, 모든 내용의 최종 판단과
> 확정은 임상가가 한다(CDSS 원칙). 이 매뉴얼도 그 순서대로 기술한다.

---

## 1. 종합보고서 작성 화면

### 1-1 화면 구성

종합보고서 작성 화면은 세 영역으로 나뉩니다.

- **좌측 사이드바(360px)**: 검사자료 첨부 · 검사 간 교차분석
- **중앙 본문**: A4 규격 문서 편집 영역
- **상단 툴바**: 서식 · 화면 표시 · AI 종합 리뷰

**[📸 01-overview.png]** — 보고서 작성 화면 전체

핀 표시:
1. 좌측 사이드바 (검사자료 / 교차분석 탭)
2. 상단 툴바 (서식 도구 + [AI 종합 리뷰])
3. 중앙 A4 본문

---

## 2. 검사자료 첨부

### 2-1 자료 목록 확인

- 좌측 [검사자료] 탭에 내담자가 받은 검사와 그 결과지가 표시됩니다.
- 검사별로 접기/펼치기가 가능하며, [전체보기]로 결과지 원본을 확인합니다.
- 확인이 완료되지 않은 검사에는 상태 배지가 표시됩니다.

**[📸 02-materials.png]** — 검사자료 목록 (검사 3종 펼친 상태)

핀 표시:
1. 검사 헤더 (코드 · 검사명 · 날짜)
2. [전체보기] 버튼
3. 자료 썸네일 그리드

---

### 2-2 본문에 자료 삽입

- 본문에서 삽입할 위치에 커서를 둡니다.
- 좌측 자료 썸네일을 클릭하면 커서 위치에 삽입됩니다.
- 이미 삽입한 자료에는 **첨부됨** 표시가 붙어 중복 삽입을 방지합니다.

**[📸 03-material-inserted.png]** — 본문에 결과지 이미지가 삽입된 상태

---

## 3. 검사 간 교차분석

### 3-1 교차분석 개요

- 좌측 [교차분석] 탭에서 여러 검사의 소견을 구성개념별로 대조합니다.
- 상단에 검사 수 · 불일치 영역 수 · 규준 보유 검사 수가 요약됩니다.

**[📸 04-cross-summary.png]** — 교차분석 상단 요약

> **중요**: 서로 다른 검사의 원점수를 하나의 척도로 환산하지 않습니다.
> 표준화 검사(규준 보유)만 정량 비교하고, 투사적 검사는 정성 소견으로만 표시합니다.
> 표준화된 환산 근거가 존재하지 않기 때문입니다.

---

### 3-2 규준 점수 비교 (레이더 차트)

- 규준이 있는 표준화 검사(MMPI-2 · TCI · S-척도)의 백분위/T점수만 표시됩니다.
- 검사 칩을 눌러 차트에서 켜고 끌 수 있습니다.
- 점선은 표시된 검사들의 규준 평균선입니다.

**[📸 05-radar.png]** — 레이더 차트 + 검사 토글 칩

---

### 3-3 영역별 소견 대조

- 구성개념별로 **소견 있음 / 정상 범위** 검사를 나란히 배치합니다.
- 불일치 판단은 점수 차가 아니라 **임상적 방향**(상승 vs 정상)이 갈리는지로 합니다.
- 투사적 검사는 `정성` 배지와 함께 원 소견(예: `AG=1`, `강한 필압`)을 표기합니다.

**[📸 06-discrepancy.png]** — 공격성 영역의 소견 불일치

핀 표시:
1. 심각도 배지 (소견 불일치 / 부분 불일치 / 일치)
2. 소견 있음 목록
3. 정상 범위 목록

---

## 4. 구간별 AI 리뷰 (문장 단위)

### 4-1 리뷰 실행

- 본문에서 검토할 문장을 드래그해 선택합니다.
- 선택 영역 옆에 [AI 분석] 버튼이 나타납니다. 클릭하면 리뷰 카드가 열립니다.

**[📸 07-select-text.png]** — 문장 선택 + [AI 분석] 버튼

---

### 4-2 리뷰 카드 읽기

리뷰 항목은 임상적 중요도 순으로 정렬됩니다.

| 종류 | 의미 |
|------|------|
| 검토 필요 | 단정적 서술 · 진단명 직접 기술 등 CDSS 원칙 관련 |
| 근거 연결 | 검사 결과와의 대조 결과 |
| 표현 제안 | 문장 길이 · 검사 간 불일치 반영 권고 |
| 맞춤법 / 표현 개선 | 이중 피동 · 임상 용어 등 |

- 카드 **헤더를 끌어** 위치를 옮길 수 있습니다(본문이 가릴 때).
- 다른 문장을 선택하면 카드가 그 옆으로 다시 배치됩니다.

**[📸 08-review-card.png]** — AI 리뷰 카드 (지적 여러 건)

---

### 4-3 수정안 적용

- 수정 제안이 있는 항목에는 **before → after** 미리보기가 표시됩니다.
- [이 수정안 적용]은 해당 1건만, 상단 [N곳 모두 적용]은 일괄 반영합니다.

**[📸 09-fix-apply.png]** — before/after 미리보기와 적용 버튼

---

## 5. 종합 AI 리뷰 (문서 단위)

### 5-1 구간별 리뷰와의 차이

- **구간별**은 선택한 문장의 표현을 다듬습니다(맞춤법 · 문체).
- **종합**은 보고서 전체를 문서 단위로 봅니다. 문장 교정을 다시 하지 않고,
  구간별 지적을 **집계해** "어느 문단에 몇 건"으로 연결합니다.

---

### 5-2 분석 실행

- 툴바 우측 [AI 종합 리뷰]를 클릭하면 우측 패널이 열리고 분석이 시작됩니다.
- 4단계로 진행되며 각 단계의 소요 시간은 작업량에 따라 다릅니다.

| 단계 | 내용 |
|------|------|
| 1 | 문서 구조 파악 |
| 2 | 검사 결과 대조 |
| 3 | 서술 일관성 검토 |
| 4 | 표현·문체 점검 |

**[📸 10-review-progress.png]** — 4단계 진행 표시

---

### 5-3 결과 읽기

- **완성도 점수**(0~100)와 함께 검토사항이 나열됩니다.
- 각 항목 앞의 색 점이 심각도입니다(마우스를 올리면 설명이 표시됩니다).
- [이동]을 누르면 본문의 해당 위치로 스크롤됩니다.

검토 규칙은 네 가지입니다.

| 종류 | 판단 기준 |
|------|----------|
| 섹션 누락 | 필수 섹션이 비어 있거나 분량이 부족한가 |
| 결과 미반영 | 첨부된 검사 결과가 본문에 인용되었는가 |
| 서술 모순 | 문서 안에서 상반된 표현이 쓰였는가 |
| 표현 교정 | 구간별 리뷰 지적의 문단별 집계 |

**[📸 11-review-result.png]** — 검토사항 목록 (점수 + 지적 3건)

핀 표시:
1. 완성도 점수 게이지
2. 심각도 점
3. [이동] 버튼
4. 수정안 버튼

---

### 5-4 수정안 검토와 반영

> **AI가 본문을 직접 고치지 않습니다.** 수정안을 누르면 먼저 미리보기가 열리고,
> 임상가가 승인해야 반영됩니다. 서술 모순처럼 어느 쪽이 옳은지 임상적 판단이
> 필요한 경우에는 양방향 선택지를 제시합니다.

- 미리보기에서 변경 전후를 확인합니다.
- 같은 표현이 여러 곳에 있으면 몇 곳이 바뀌는지 안내합니다.
- [본문에 적용]을 누르면 반영되고, 점수와 검토사항이 즉시 갱신됩니다.

**[📸 12-fix-preview.png]** — 수정 미리보기 모달

**[📸 13-score-improved.png]** — 반영 후 점수가 오른 상태

## ⚠️ 시연 시 유의사항 (매뉴얼 본문에는 넣지 않음)

현재 화면은 시연용 목업이 포함되어 있습니다. 외부 설명 시 아래 구분을 명확히 합니다.

**규칙 기반으로 이미 동작 = 현재 코드가 곧 실기능**
- 섹션 누락·분량 판단
- 검사 결과 반영률 집계
- 구간별 지적 집계

**LLM 연동이 필요한 부분 (인프라는 구현됨, API 키 미설정)**
- 서술 모순 탐지
- 섹션 초안 생성

**목업 데이터**
- 검사 3종(MMPI-2 · TCI · S-척도)과 그 결과지
- 교차분석 수치

**아직 확정되지 않은 것**
- 교차분석 7개 축의 구성. 도메인별 통합은 확립된 보고서 작성법이고 불일치 해석은
  Finn(1996) 모델을 따르지만, **축 개수와 분할 자체는 임상 자문을 거쳐 확정할 예정**입니다.
