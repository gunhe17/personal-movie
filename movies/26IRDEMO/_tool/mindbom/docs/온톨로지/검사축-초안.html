검사 축 온톨로지 초안

사람·기관 축과 같은 방식(질문 ①~⑥, 결정 1개씩)으로 작성. 마인드봄 분리 결정(검사 정본=마인드봄)을 반영해 "플랫폼 내 검사 모델"이 아니라 "마인드스코프–마인드봄 경계 계약"이 중심이다.

결정 6개 (초안)

AS-1
검사 정의의 고유함 = code + 버전, 개정판은 새 행

규준(norm) 개정 시 정의 행을 고치지 않고 새 행 — 과거 실시의 결과는 옛 규준을 계속 가리킨다. 종단 비교(작년 vs 올해)에서 "어느 규준으로 채점됐나"가 행 단위로 보존되어야 비교가 정직하다.

소급 불변 공리의 3번째 재사용 (조직 단위 기간 행·enrollment와 동일 원리) · 마인드봄 카탈로그 설계 요구사항
AS-2
문항·채점은 불가침 — 온톨로지는 "겉모습"만 + 유형은 4축 분해

온톨로지가 아는 것: code·이름·워크플로 축·어느 엔진인지(참조)·실시 상태·결과의 형태. 문항 내용(definition)과 채점 알고리즘은 콘텐츠·코드 영역(=마인드봄) — 판권 리스크 + 문항·채점기 짝 무결성. 현행 workflow_type 2값은 아래 4축의 압축 캐시로 취급(role enum과 동일 처리 — v1 스키마 무변).

    AS-3
    결과 등급의 3분할 소유권

    컷(기준점) = 검사 정의 소유 (마인드봄, 버전 귀속 — 같은 점수가 기관마다 다른 등급이 되면 임상 무결성·SaMD 사고) · 어휘·그룹핑·표시 수준 = 기관 프로필 소유 (관심군/배려, 3→2단계 접기, 병원 등급 비표시) · 선별 정책(상위 X% 2차 면담) = 회차 설정 소유 — 기관 운영 결정, 대표 판정 대기 유지.

    기존 미결 "절단선 문제"가 3분할로 정리됨 — 대표 판정 범위가 선별 정책으로 좁혀짐
    AS-4
    화면 갭 2건 — 통일성 개선 목록에 추가

    ① 결과 등급 어휘가 화면에 하드코딩됐는지 감사 스캔 목록에 추가 (→ 프로필 소비로 전환) ② 보호자 열람 플래그는 capability 연결 대상 (군 프로필 = 존재 변환으로 제거). 접수 화면군 어휘는 기존 치환에서 이미 해소.

    AS-5
    시스템 경계 비노출 (A4 확장)

    Person·Account를 숨기듯, 마인드봄·마인드스코프라는 시스템 이름도 사용자 화면의 명사가 아니다. "검사 보내기"가 내부적으로 마인드봄 호출이어도 화면은 하나의 흐름 — 노출은 상태("분석 중")와 결과로만.

    AS-6
    결과 계약은 산출물 축을 따라 갈라진다

    구조화 점수 계약(총점·하위척도·위험도 — 현행 ScoringResult/InterpretationResult)은 채점 방식이 "엔진 자동"인 조합에만 존재. 전문가 판정(투사)의 산출물은 소견 문서(CDSS 확정본), 외부 수신은 PDF+메타. 플랫폼의 결과 보관·집계·기관 어휘 입히기는 이 세 형태를 구분해 다룬다.

    마인드스코프 – 마인드봄 경계 계약 (조항 3개)

    마인드스코프 (운영 SaaS)

    • 검사 관리 최소한: 채택·접수·케이스·일정 연동
    • 결과 보관·결과지 발송·청구
    • 기관 어휘 입히기 (프로필 소비)
    • 자가보고 실시(현행 62 endpoint)는 과도기 유지 — 정본 이관은 단계적
    계약

    마인드봄 (검사 정본 시스템)

    • 카탈로그 (수백 종) · 문항 · 채점 엔진 · 규준/버전
    • 판권·라이센스 상태 관리
    • 투사검사 CDSS (AI 초안→임상가 확정)
    • SaMD는 내부 2트랙 — 갈림선 = 의료기기 기능 여부 (인증용/운영용 아님)
    조항 1 — 검사 정의 코어: code+버전(AS-1)·이름·4축 조합·라이센스 상태. 두 시스템이 같은 정의를 참조 — ontology/가 계약의 정본 (두 코드베이스가 같은 스택이라 소비 용이)
    조항 2 — 실시 상태 사상: 플랫폼 task 6종 ↔ 마인드봄 상태 머신 8종(created→…→completed)의 매핑표. 사용자에겐 하나의 흐름(AS-5)
    조항 3 — 결과 회수: 산출물 3형(점수 계약/소견/PDF, AS-6) + 등급은 중립 3단계(AS-3). 수검자 신원은 A1대로 기관 스코프 참조 전달 — 전역 통합 없음
