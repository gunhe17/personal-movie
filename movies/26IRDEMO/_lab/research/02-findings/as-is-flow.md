근거: `01-source/livinglab/` 15건, `01-source/meetings/` 6건, `01-source/memos/` 13건.
시각화: `04-artifacts/as-is-flow.html`

역할 코드 — **보호자**(외부) / **실장**(데스크) / **심리사**(임상심리사) / **상담사**(치료사) / **원장**(센터장) / **주무관**(행정기관, 외부)

고장 코드 — `이중` 이중 입력 · `분산` 채널 분산 · `휘발` 기록 미잔존 · `표준` 표준 부재 · `감사` 행정용 기록

## 01. 문의 · 접수

| 역할 | 실태 | 코드 |
|---|---|---|
| 보호자 | 홈페이지 · 카톡 · 전화 3중 채널로 문의 | `분산` |
| 실장 | 출근 직후 CRM으로 당일 일정·상담실 배정 확인. 예약은 전날 21시 확정, 처리는 다음날 오전 | |
| 실장 | 통화하며 동시에 수기 기록. 데스크 PC가 켜져 있을 때만 녹음·이력 조회. CID 꺼지면 부재중 확인 불가 → 응대 누락 | `휘발` |
| 실장 | 단체 유입 시 카톡으로 명단 받아 엑셀로 옮기고 한 명씩 등록 (어린이미래활짝센터) | `이중` |

핸드오프: 보호자 → 실장 (카톡 / 전화 / 홈페이지 폼, 채널마다 기록이 따로)

## 02. 방문 전 서류

| 역할 | 실태 | 코드 |
|---|---|---|
| 보호자 | 예약금 선결제 | |
| 보호자 | 초기상담기록지 · 상담동의서 작성. **센터를 옮길 때마다 사실상 같은 내용을 다시 작성**, 초기상담비(약 20만 원)도 매번 재지불 | `이중` |
| 실장 | 기록지·동의서를 개별 전송하고 개별 회수. 일부 센터는 구글 시트로 동의서 수집 (보안·체계성 취약) | `분산` |

## 03. 초기면담 · 검사 결정

| 역할 | 실태 | 코드 |
|---|---|---|
| 보호자 | 센터 첫 방문 | |
| 실장 | 신상 정보 + 주호소 문제 접수 → 심리사에게 **구두 전달** | |
| 심리사 | 초기면담 (행동관찰 + 가족·대인·직업·문제상황 질문). 지정 초기면담지가 있는 센터도, 없는 센터도 있음 | `표준` |
| 심리사 | 필요 검사를 정해 **검사 오더지를 지류로 제출** → 검색 불가 | `분산` |
| 실장 | 검사 일정 배정. 상담사 휴가·브레이크타임은 개인이 따로 알려줘야 해 중복예약·누락 | |

## 04. 검사 시행

| 역할 | 실태 | 코드 |
|---|---|---|
| 보호자 | 검사받으러 방문. 분리 어려운 어린 아동은 **1주 전 또는 전날 별도 방문**해 보호자 설문 사전 작성 | |
| 보호자 | 아동 검사 중 대기실에서 설문 작성. 문항 의도를 이해 못 해 중도 포기·오답 가능 | |
| 실장 | 초기상담기록지를 출력해 검사자에게 전달 | |
| 심리사 | BGT → 지능 → 로샤 → TAT → HTP → KFD. 인지 과제를 먼저 두고 라포 형성 후 투사검사로. 조합은 대부분 센터 패키지 고정 | |
| 심리사 | 행동관찰을 검사별로 구분해 수기 기록. BGT 시행시간은 휴대폰 초시계로 재느라 도형마다 시작·종료를 정확히 못 누름 | `표준` |
| 주무관 | 사전검사는 경기도 지원단 **별도 사이트**에서 센터 계정으로만 가능 (담당 치료사 계정으로는 안 열림) | `분산` |

소요: 지능 1~1.5시간 · 카스 30분

## 05. 채점 · 종합보고서 — 최대 병목

| 역할 | 실태 | 소요 | 코드 |
|---|---|---|---|
| 심리사 | 로샤를 엑셀로 채점. 일부만 웹사이트. 기존 상용 채점은 오답을 정답으로 응답해 검토 시간이 더 듦 | 코딩 40분 | |
| 심리사 | 반응을 워드·엑셀로 **다시 옮기고** 지침서와 대조 | **3시간+** | `이중` |
| 심리사 | 과거 보고서 파일의 틀을 복사 → 내용만 지우고 새로 채움. 그래프는 한글에 스크린샷 붙여넣기 | **8시간~2일** | `표준` |
| 심리사 | 표현을 찾으려 이전 보고서·타 전문가 보고서·책을 다시 뒤짐. GPT로 문장 다듬기 (보호자 동의 없이) | | `표준` |
| 실장 | 암호 건 메일로 수령 → 누락·검색 불가 | | `분산` |
| 원장 | 상담사별 퀄리티 편차가 커서 전수 검토 | | `표준` |

가장 어려운 지점은 개별 해석이 아니라 **모든 검사 결과를 일관되게 종합하는 것**.

## 06. 해석상담

| 역할 | 실태 |
|---|---|
| 보호자 | 결과 들으러 재방문 (검사 시행 1~2주 후, 50분) |
| 실장 | 해석상담 일정 재조율 |
| 심리사 | 보고서 내용만으로 50분을 채우기 어려움. 참고할 회기 맥락이 손에 없음 |

## 07. 회기 진행 · 일지

| 역할 | 실태 | 코드 |
|---|---|---|
| 보호자 | 주 1회 방문. 월 단위 결제라 결석 시 보강·이월이 어렵고 보강 일정을 직접 확인할 방법 없음. 결석 통보는 전화·문자 | |
| 실장 | 내담자 상태값 수동 변경 (설문완료 / 검사지 제출 / 노쇼) | |
| 실장 | 출퇴근은 눈도장·지문 → 실시간 근태 불가. 상담실 고정 배정 없어 매일 데스크에서 확인 | |
| 상담사 | **하루 6~8회기.** "기록이 밀리면 기억이 흐려지고, 안 밀리려면 퇴근이 늦다" | `휘발` |
| 상담사 | 일지가 엑셀 · 종이 · 메일 · 한글파일 제각각. 같은 센터 안에서도 정해진 틀 없음 | `표준` |
| 상담사 | 지난 회기 내용을 회기마다 다시 파악 | |
| 원장 | 센터 공지는 카톡 또는 구두. 통합 채널 없음 | `휘발` |

## 08. 부모 피드백 — 40분 + 10분

| 역할 | 실태 | 코드 |
|---|---|---|
| 보호자 | 대기실에서 10분 구두 피드백. 오늘 무엇을 했는지 확인할 방법이 없어 **60~70%가 가방에 녹음기를 넣어 보냄** | `휘발` |
| 상담사 | 40분 교육 + 10분 부모상담. 발달장애 아동은 활동보조사가 데려와 부모 대면 자체가 불발 → 저녁에 몰아서 전화 | `휘발` |
| 상담사 | 일지를 부모에게 주는 센터는 거의 없음 (작성 수준 편차 · 시간 부족 · 아이가 숨기고 싶은 내용 노출 우려) | |
| 실장 | 상담사가 남긴 손글씨 메모를 보고 다음 일정 예약 | |

## 09. 행정 · 정산 · 바우처 — 가장 무거운 지점

| 역할 | 실태 | 코드 |
|---|---|---|
| 상담사 | **같은 회기를 두 번 씀** — 센터 내부 일지 + 바우처 제출 양식. 내용은 같은데 양식이 달라 그대로 못 냄 | `이중` |
| 상담사 | 회기·검사 건수를 직접 세서 원장에게 제출. 이 숫자로 급여 산정 | `이중` |
| 심리사 | 전마투 · EAP · 바우처마다 제출 서류가 다름. 바우처 포함 시 수기 제출 | `표준` |
| 실장 | 노쇼 환불은 센터 정책 따라 수기 기록. **사전 취소와 당일 노쇼는 페이 정산이 다른데 구분 안 됨** | |
| 실장 | 매출은 EAP 콘솔을 따로 사용. 통계는 월별·3개월 추이만 | `분산` |
| 원장 | 지각으로 재량 진행한 수업은 집계에서 빠져 실장이 수기 입력 | `이중` |
| 원장 | 수백 페이지 공고에서 조건 · 단가 · 제출서류를 직접 골라냄 | |
| 주무관 | 디지털행정시스템 = 종이 서식을 그대로 옮긴 것 | `감사` |
| 주무관 | 서명 도장 시각이 수업시간 ±30분 벗어나면 부정수급 플래그. 서명일이 개시일보다 늦어도 적발 → 치료사가 수업 중간중간 휴대폰으로 입력 | `감사` |
| 주무관 | 2개월 무실적 = 자격 상실. 중도 중단 미신고 시 센터가 환수 | |

### 현장 실사 핵심 증언 (2026-08-10)

> "여태까지 수기로 한 거를 그냥 디지털화시킨 것뿐이잖아요. 치료사들이 해야 되는 것들은 여전히 똑같다. 저희는 하나도 변한 게 없다니까."

디지털화가 줄인 것은 센터장이 감사 대비로 종이를 들여다보던 시간뿐. **입력 노동량은 동일.**

## 10. 종결 · 사후

| 역할 | 실태 | 코드 |
|---|---|---|
| 보호자 | 진전 여부를 확인할 객관적 지표 없음. 상담사 주관 판단에 의존. 종결 판단은 의사가 하지만 결국 불안한 보호자가 결정 | |

| 심리사 | 재평가 시 이전 검사 자료를 찾기 어려움 (권장 재평가 주기 6개월) | |

| 원장 | 개인정보 파기 미이행 — "버리고 싶은데 파기해서 버리는 게 귀찮아서 그냥 갖고 있다" | `감사` |
| 주무관 | 사후검사 → **점수만 확인**. 치료사가 쓴 소견은 보지 않음 | `감사` |
| 주무관 | 만족도 조사 QR — 반기 1회 | |

## 자료상 주의

- 1차 리빙랩(실장 / 전문가 / 학부모 그룹)이 순수 AS-IS 조사이고, 2·3차는 프로토타입 검증이라 성격이 다르다.
- 1차 노트의 워크스페이스 등록일(2026-01-15)은 **실제 조사 시점이 아니다.** 2차(2025-12-11)보다 늦게 등록됐다.
- 1차 리빙랩 노트 3건은 `content`와 `content_json`에 본문이 중복 저장돼 있다. API로 읽으면 같은 내용이 두 번 나온다.
- `0810` 회의록 2건은 STT 원문이라 고유명사 오탈자가 많다 (부정수급→"부정성", 디지털→"디지터"). 인용 시 의미 단위로 복원할 것.
- MOEUM 산출물 440건 중 AS-IS 관련 22건을 근거로 정리했다.
