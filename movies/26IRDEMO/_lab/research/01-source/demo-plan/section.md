*불편함을 충분히 자극할 수 있는 단위로 구성해볼까?

- '문의/접수'부터 '검사 결정'까지
    - 불편한 요소
        - 문의/접수 통화하면서 수기 기록 (+ 단체 유입) -> 내담자, 구성원, 상담실, 일정, 메모 등록

- '검사' 부터 '보고서 작성'까지
    - 검사 도구, 자료, 참고지, 기록지 등의 도구 구성. -> 바로링크
    - 검사 결과를 직접 작성/채점한다.
        - 검사 시, 수기로 작성한 결과를 직접 문서 편집기로 옮긴다.
        - 문서 편집기로 옮긴 결과를 직접 채점한다.
    - 검사 보고서를 직접 작성한다.
        - 참고지를 참고한다.
        - 검사 결과 중, 유의미한 부분을 참고, scrap한다.

- '상담'
    - 회기 예약 및 변경. 상담사 일정 관리. -> 스마트 일괄 회기 추가
    - 지난 회기 내용 직접 파악. -> 필드노트
    - 하루 최대 6~8회기를 진행하는 상담사, 기억을 바탕으로 일지 작성. -> 필드노트, ai 기반 상담 일지 포안 작성
    - 상담사 별, 일지의 파일 형식 상이 = 관리 안 됨.. -> 필드노트, ai 기반 상담 일지 포안 작성

- '행정/정산'
    - 센터 내부 일지, 바우처 제출 양식, 슈퍼바이저 제출 양식 별도 작성.
