## 1. 신규 아이디어

### 1-1. 랜딩 페이지 & SEO (영세 센터 지원)

- 노션 공개 링크처럼 **센터별 소개 페이지를 자동 생성**하여 검색 노출 지원
- 자체 홈페이지가 없는 영세 센터가 별도 비용 없이 온라인 존재감 확보
- **블로그 자동 생성**: 상담일지(또는 아동 사진 마스킹 처리 후)를 기반으로 AI가 블로그 콘텐츠 초안 작성 → 센터의 전문성 홍보 + SEO 효과

### 1-2. 바우처 알림 서비스

- 카카오 알림톡을 통해 **바우처 관련 개정안·변경사항을 자동 전달**
- 센터 운영자가 정책 변화를 놓치지 않도록 하는 실용적 기능
- 보호자 대상으로도 확장 가능 (바우처 신청 시기, 갱신 알림 등)

### 1-3. 선물 꾸러미 (파트너십 콘텐츠)

- 서울대 등 **파트너십 체결 교수진의 교육 콘텐츠**를 플랫폼 가입 혜택으로 제공
- 핵심 메시지: "현장에서 접하기 어려운 전문가 교육을 플랫폼 가입만으로 이수 가능"
- 센터 가입 유인 + 전문가 역량 강화 + 플랫폼 신뢰도 확보의 삼중 효과

### 1-4. 치료 효과 객관화

- **문제**: 발달장애 아동이 검사 → 치료(놀이, 미술 등) 진행 시, 호전 여부를 보호자에게 전달할 객관적 지표가 부족 (현재 상담사 주관적 판단에 의존)
- **방향**: 검사 점수 추이, 세션별 행동 변화 데이터, AI 기반 진전도 리포트 등을 통해 **치료 경과를 시각화·정량화**하여 보호자 신뢰 확보

### 1-5. 부모용 앱

| 기능 | 설명 |
|------|------|
| 센터 찾기 | 위치·전문 분야 기반 센터 검색 |
| 전문가 찾기 | 자격·경력·후기 기반 전문가 매칭 |
| 매거진 | 육아·발달·심리 관련 큐레이션 콘텐츠 |
| 퀘스트 & 리워드 | 가정 내 활동 수행 시 보상 제공 |

> **퀘스트/리워드 보완 필요**: 보상 재원(센터 부담 vs 플랫폼 부담 vs 광고), 보상 형태(포인트, 할인, 콘텐츠 잠금 해제), 치료 참여 동기부여라는 목적과의 정합성 검토 필요

## 2. 주요 타겟 세그먼트

| 세그먼트 | 대상 | 핵심 니즈 |
|----------|------|-----------|
| **운영** | 센터장, 실장, 행정 담당 | 일정·매출·인력 관리, 바우처 정산, 마케팅 |
| **전문가** | 임상심리사, 상담사, 치료사 | 검사·상담 기록, 보고서 작성, 전문성 향상 |
| **내담자(보호자)** | 아동·청소년 보호자 | 센터 탐색, 치료 경과 확인, 일정 관리 |

## 3. AI 활용 영역

| 영역 | 적용 방식 | 비고 |
|------|-----------|------|
| **에이전트 (관리)** | 운영 업무 자동화 (일정 조율, 알림, 문의 응대 등) | 운영 타겟 핵심 기능 |
| **필드노트** | 음성 전사 → 화자 분리 → 구조화된 상담 기록 생성 | 실시간 추천 기능 포함 |
| **상담일지 작성** | 이전 기록 + 검사 결과를 반영한 AI 초안 생성 | 전문가 작성 부담 경감 |
| **투사적 검사 해석** | HTP, KFD 등 그림 검사의 AI 보조 해석 | 정량적 해석 지원 |
| **종합 보고서** | 검사·상담 데이터를 종합한 보고서 AI 자동 생성 | 효과 객관화와 연계 |

## 4. 비즈니스 모델 (요금제)

| 요금제 | 운영 (센터) | 전문가 (개인) |
|--------|-------------|---------------|
| **무료** | — | 필드노트 전사 + 화자 분리, 에이전트 일부 |
| **스타터** | 에이전트 일부 | 필드노트 + 검사 AI 일부 |
| **프로** | 에이전트 전체 | 모든 AI 기능 (상담일지, 투사검사, 보고서) |
| **엔터프라이즈** | 미정 | 미정 |

> **엔터프라이즈 검토 방향**:
>
> - 다지점 통합 관리 (대시보드, 통계, 인력 배치)
> - 커스텀 검사 도구 / 자체 검사지 탑재
> - 전용 API 연동 (기존 ERP·EMR 시스템)
> - SLA 보장 + 전담 지원
> - 데이터 분석 리포트 (센터 운영 인사이트)
> - On-premise 또는 VPC 배포 옵션 (대형 병원·기관 대상)
