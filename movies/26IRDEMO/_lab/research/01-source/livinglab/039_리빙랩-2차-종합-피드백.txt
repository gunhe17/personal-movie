# 리빙랩 2차 종합 피드백 - 통합 정리

## 주요 의사결정 흐름

### 1. 검사 전 단계
#### 접수 및 초기 면담
- 센터 실장이 접수 담당 (신상정보 + 주호소 문제 수집)
- 임상심리사가 초기 면담 진행
  - 행동관찰 + 가족/대인관계/직업/문제상황/사회성 관련 질문
  - [어휘/표현] "직업이 뭐에요?", "과거에는 어땠어요?", "일상생활에서 문제가 발생한 경우가 있나요?"
- 초기 면담 결과를 바탕으로 필요한 검사 결정

#### 검사 구성 의사결정
**기본 풀배터리 (아동 중심)**
- 지능검사 + 적응행동검사 + 행동평가 기본 구성
- BGT → 지능검사 → 로샤 → TAT → HTP → KFD 순서

**특수 상황별 검사 추가**
- 자폐 의심: 카스(CARS) 추가
- ADHD 의심: 주의력 검사(CAT, 병원 기계) 추가
- 성인: 간편 검사 위주 (MMPI, TCI, SCT, HTP)

*예외: 센터마다 정해진 패키지를 따르는 경우가 많음, 개별 조합은 제한적

### 2. 검사 시행 단계
#### 검사 순서 의사결정 원칙
'인지적 과제를 먼저 시작해서 점점 라포 형성 후 자신의 마음을 더 깊이 탐색할 수 있는 검사 순으로 진행'
'인지 과제가 더 많은 집중력을 요하기 때문에 먼저 진행'

#### 검사별 특이사항
**BGT**
- 지우개 제공하지 않음
- 리콜 진행 여부는 검사자마다 상이
- !본인의견: 시간 기록의 일관성 유지 어려움

**로샤**
- 엑스너 vs 알파스 방식 선택
- !본인의견: 기존 채점 프로그램들의 정확도에 대한 불만족
- '세심한 부분, 문맥을 파악하는 것들이 중요'

**HTP/KFD**
- 면담과 연결성 중시
- !본인의견: 단일 검사 결과만으로 판단하면 혼선 발생 가능

#### 행동관찰 기록
- [어휘/표현] 검사별로 구분하여 행동관찰 기록 필요
- '지능 검사 때 불안 행동과 로샤 검사 때 불안행동은 해석이 다를 수 있음'

### 3. 보고서 작성 단계
#### 작성 순서 의사결정
1. 의뢰사유 + 행동관찰 + 지능검사 결과 먼저 확인
2. 객관적 검사 채점 완료
3. 포멧 설정 (인지 → 정서 → 성격/대인관계 → 요약/제언)
4. 로샤 채점
5. 각 검사별 결과 정리
6. 종합 해석 및 제언 작성

#### 보고서 구성 의사결정
**기본 구조**
- 의뢰사유, 행동관찰, 신경심리학적 평가, 지능검사, 사고 및 판단, 정서 및 성격

**핵심 원칙**
'보고서의 문장력이 가장 중요하다'
- 전문용어보다는 내담자가 이해하기 쉽게 풀어서 설명
- [어휘/표현] 반복되는 문장 개선 필요 ("시사됨, 사료됨, 의심됨" 등)

#### 검사 비중 의사결정
- 투사 검사의 비중은 크지 않음
- HTP/KFD는 부록 느낌으로 간단하게 기술
- MMPI와 SCT 연계 활용 (척도 결과에 일치하는 문장을 근거로 포함)

### 4. 해석상담 단계
#### 상담 일정 의사결정
- 검사 시행 후 1-2주 후 진행
- 50분 분량 구성의 어려움

### 5. 시스템 관련 의사결정

#### AI 활용 범위
'AI는 결과 확인·근거 점검 수준으로 도움을 주면 좋다'
!본인의견: 수련생은 AI 도움을 너무 많이 받으면 안 된다 → 많이 작성해야 실력이 는다

#### 필요 기능
- 'ADHD 증거를 취합해 보여주면 좋겠다'
- [어휘/표현] 검사 결과 중 유의미한 수치만 선별하는 기능
- 우울, 불안 등의 카테고리별로 검사별 근거 척도 제시

#### 신뢰성 요구사항
*예외: 'AI 생성이 아닌 공신력있는 정보이길 바람' (DSM-5, 공병률 등 제시시)

## 주요 예외사항

### 기관별 차이
*예외: 기관마다 보고서 분량·제출 방식·추가 검사 항목이 다를 수 있음
*예외: EAP/전마투 여부에 따라 제출 서류 상이
*예외: 바우처 사업 포함 시 수기 제출 필요

### 내담자 특성별 차이
*예외: 아동의 협조도에 따라 검사 거부·진행 방식 변화 가능
*예외: 분리 어려운 어린 아이의 경우 사전 방문하여 검사지 작성

### 비용 관련
*예외: 검사가 중단되거나 시행되지 않더라도 비용차감 없음
*예외: 검사 추가 시에만 추가 비용 청구

## 향후 개선 방향

### 우선순위 높음
1. 보고서 문장력 개선 지원
2. 검사별 근거 기반 해석 제시
3. 유의미한 지표 선별 기능

### 우선순위 중간
1. 행동관찰 기록 편의성 개선
2. 로샤 채점 정확도 향상
3. 해석상담 내용 생성 지원

### 검토 필요
1. 태블릿 기반 검사 도구 도입 (기존 수기 작성자들의 거부감 고려)
2. 영역 기록 자동화 (없는 영역 직접 그리기 기능 필수)
