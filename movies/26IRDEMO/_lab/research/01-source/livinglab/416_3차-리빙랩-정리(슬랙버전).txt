# CRITICAL

## 즉시 해결이 필요한 중요 이슈

### BGT 검사 핵심 문제
- **BGT 리콜(회상) 비중 증대 필요** - 현재 비중이 너무 낮음, 리콜이 더 중요함
- **BGT 채점 시스템 개선** - 점 개수, 크기, 배치 등 자동 제공 시스템 구축
- **규준 정보 실시간 제공** - 정상범위 리콜 개수(4개/5개) 등 기준 정보 바로 제공 필요

### HTP 검사
- **PDI 직접 입력 문제** - 수고로움으로 인한 사용 포기 우려
- **PDI 미사용 시 종합보고서 정보 누락 문제** - 보고서 완성도 저하

### 로샤 검사
- **채점 단계 AI 정확도 개선** - 높은 정확도 항목 자동 확정, 검토 필요 부분만 표시
- **가독성 심각한 문제**
  - 결과 보기 화면의 반응 기록표
  - 군집별 해석 상세 가독성
  - 분석 단계 결과표 가독성

### 투사검사 전반 사용성 문제
- **원자료 스캔/업로드 작업의 높은 허들** - 기존 방식이 더 빠름
- **클릭 기반 채점 방식 거부감** - 도형 선택→오류 내용 입력 방식 절대 사용 안 함
- **질적분석 기능 목적 불분명** - 결과 활용 방식이 직관적이지 않음
- **Optional 항목의 필수 느낌** - UI 구성상 모든 항목을 해야 할 것 같은 느낌

### 저작권 및 데이터 보안
- **마음사랑 보고서 등 상업적 자료 활용 저작권 확인 시급**
- **업로드 자료 서버 저장에 대한 명확한 설명 필요** - 중앙 서버 업로드 거부감

### 필드노트 STT 성능
- **받아쓰기 성능 최적화 필수** - 성능 부족 시 검수 작업 더 번거로워짐

## 개선하면 좋을 사항들

### BGT 검사
- BGT 인트로 페이지 연령 설명 제거
- 관련 오류들 묶어서 해석하는 기능
- 코피츠, 헛 등 특정 채점법 기준에서 벗어난 유연한 채점

### 로샤 검사
- LOC 화면에서 위치 선택 창 스크롤 개선 (한 화면에 모든 내용 표시)
- 자유 반응 및 질문 단계에서 임상적으로 중요한 반응 특별 표시
- 특수 지표 유의미할 경우 해석 제공
- 채점 단계 테이블에서 가로 스크롤 제거
- 카드 그림이나 방향 정보 삭제를 통한 화면 넓이 확보
- 색상(초록색, 노란색, 주황색) 의미에 대한 안내 제공

### 투사검사 전반
- 모든 원자료 업로드 후 검사별 자동 분류/선택 기능
- 채점 단계에서 칸마다 일일이 확인하는 작업 간소화

### 필드노트
- 녹음 시 검사자가 녹음을 지나치게 의식하는 문제 고려
- 지능 검사에서는 녹음 필요성 낮음
- 행동 관찰 내용을 종합보고서에 기술하는 시간이 짧은데, 굳이 녹음을 할 필요는 없어보인다.
