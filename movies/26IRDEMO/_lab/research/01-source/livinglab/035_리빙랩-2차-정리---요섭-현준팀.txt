### NOTE | 리빙랩 2차 정리 - 요섭/현준팀
(2025-12-11 by 이현준)

내용)
- 접수할 때 센터 실장이 "접수"를 받는데, 이 떄 신상정보 + 주호소 문제를 받음
- 그리고 임상심리사한테 전달되고 심리사가 "초기 면담"을 통해 행동관찰 + 가족/대인관계/직업/문제상황/사회성 관련 질문을함(직업이 뭐에요?, 과거에는 어땟어요?, 일상생활엣더 문제가 발생한 경우가 잇나요? 그럴때는 어떻게 하나요?)
- 초기 면담을 바탕으로 필요한 검사를 정해서 센터 실장한테 전달하면, 검사 일정을 잡는다.
- 센터에서 지정된 "초기 면담지"가 있는 경우도 있고 없는 경우도 있음.
- 종합 보고서 어투는 전문용어 보다는 내담자가 이해하기 쉽게 풀어서 설명함.
- 검사를 진행하면서 행동 관찰을 엄청하고, 이것을 검사별로 구분해서 작성해둘 필요가 있음.
  - ex) 지능 검사 때 불안 행동(펜돌리기 등)과 로샤 검사 때 불안행동은 해석이 다를 수 있음.
- 종합보고서 맥락에서 진짜 특이한 경우 일때만 HTP/KFD는 부록 느낌. 간단하게 기술, 묘사 정도만
- 종합보고서에서 MMPI를 기술하는 영역에서 SCT가 함께 사용된다. (MMPI에서 어떤 척도가 나왓으면, 그것에 일치하는 문장을 근거로 넣음.)
- 각 검사별 그리고 검사 내부 항목끼리 대척되는 결과가 나와도 일단 그것에 기반하여 기술하고, 마지막 요약단계에서 행동관찰 + 전체 검사 결과를 종합해서 판단을한다.
- 종합보고서에서 투사 검사의 비중이 크지 않다. 
- 로샤 채점에 대한 니즈는 확실하다.
- 종합보고서 작성 과정
  1. 객관적 검사 채점
  2. 보고서 포멧 설정
    a. 인지 : BGT, 지능(WISC)
    b. 정서 : 투사검사, 그림이나 로샤 -> 스트레스나 대인관계, 대처방식
    c. 성격 / 대인관계 : MMPI, TCI
    d. 요약 및 제언
  3. 로샤 채점
  4. 포멧에 맞게 검사 결과 넣기
  5. 최종 요약 및 제언
- 보통 종합보고서 해설 상담은 검사 종료후 2주후에 한다
- BGT도 로샤만큼이나 채점이 까다롭다.

기능 제안)
- 종합보고서 내용만 가지고 50분 가량의 해석 상담을 하기에는 무리. 그래서 AI를 이용햇 50분 분량을 채워주기
  - ex) "강박이 있어요" -> 검사 결과를 보아하니, 강박은 별로 없으신데 직업 상(현재 상황상)~~~~ 해서 그러신 것 같다. -> 제언까지 생성

예외)
- 풀배터리는 아동 대상, 성인은 간편 검사(MMPI, TCI, SCT, HTP) 주로 함.

본인의견)
- 이런 프로그램은 아직 경력이 짧거나 없는 임상심리사들만 쓸 것 같다. 그런데 경력이 없으면 취업이 안된다.
- KFD/HTP 같은 검사들은 임상심리사가 직접 사진을 찍거나 스캔을 해서 업로드를 해야하는데, 그렇게까지 쓰지 않을 것 같다.
- 검사 진행 중에 작성하는 행동관찰 기록이 매우 중요한데, 이걸 AI가 대신 해줄수는 없으니 좀 더 사용하기 편하게 해주는게 있으면 좋겠다.
- 본인은 종합보고서를 작성할 때 TCI, MMPI 같은 기질을 알수 있는 검사 결과를 초반에 작성을 한다.
