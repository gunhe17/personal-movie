## Ⅰ. 있으면 좋은 기능

1. **고객관리 자동화**
    - 현재는 상담이 끝난 후 추가적인 접촉(터칭)이 부족해 내담자가 쉽게 이탈할 수 있음.
    - 회기권이 소진되거나 종결 시점이 다가와도 실장이 직접 확인 후 안내해야 하는 불편이 있음.
    - → 자동으로 “회기권 임박 안내”, “상담 종결 예정 안내” 메시지를 발송하면 내담자 유지율 향상 가능.
2. **기본 자동화 시스템**
    - 예약금 결제 후 내담자가 따로 동의서·기록지를 작성해야 해 인건비가 발생함.
    - → 시스템에서 예약 결제 직후 자동으로 **설문지·상담 동의서**가 제공되고, 내담자가 방문 전에 처리하도록 하면 센터 인력 부담 최소화.
3. **소통 채널**
    - 공지사항은 카톡, 상담사 공유 내용은 수기로 따로 전달되는 경우가 많아 누락 위험이 있음.
    - → 센터 공지사항 방과 상담사 전용 공유 채팅방을 만들면 내부 커뮤니케이션이 단순해짐.
4. **대시보드**
    - 매출 인건비 추이, 상담 프로그램별 비율, 연령대, 상담사별 연계율(리퍼 추이 상담사별 빨간불: 표정이 안좋은 것) 매출금액

## Ⅱ. 출근 후 루틴 일과

### 1. 하루 일과

- **출근 직후** CRM을 켜고, 당일 일정 및 상담실 배정을 확인.
- 이후 홈페이지·카톡·전화 문의(EAP 콘솔) 처리.
- 예약은 전날 오후 9시에 확정되고 실제 처리는 다음날 오전에 이루어짐.
- 내담자와 상호작용 시 모든 메모를 남겨 **실장 간 공유** 자료로 사용.
    - 현재는 수기로 정리하거나 PC에 분산 저장 → 추후 찾기 어려움.

### 2. 통화 확인

- PC가 켜져있을 때만 통화 녹음·이력 확인 가능.
- 통화 시에도 **수기로 기록**해야 하는 번거로움.
- CID 꺼져있을 경우, **부재 전화 확인 불가** → 응대 누락 발생.
- **자동화 한계**: AI 기반 통화 기록은 가족관계, 민감한 개인정보 인식이 어려우며 통신사 제약과 비용 부담 존재.

### 3. 스케줄 처리

- 상담사별 휴가·브레이크 타임을 고려해 일정을 배정해야 함.
- 현재는 상담사 개인이 따로 알려주어야 해서 중복 예약이나 누락 발생 위험 있음.

### 4. 관리 채널

- 데스크에서만 PC로 관리 가능.
- 별도의 스케줄 앱은 “그날 일정 확인”만 가능하고, 내담자 개인정보는 확인 불가.
    - 상담사가 외부에서 내담자 관련 기록을 참고하기 어려운 불편 존재.

## Ⅲ. 전문가(상담사) 관리

- 출퇴근: 눈도장·지문으로만 체크 → **실시간 근태 확인 불가**.
- 상담실: 고정 방이 없어, 매일 데스크에서 당일 배정을 확인해야 함.
    - → 실시간 배정 시스템이 필요.

---

## Ⅳ. 고객 응대 및 관리

### 1. 내담자 방문 전

- 예약금 선결제 후 초기상담 기록지, 상담 동의서를 따로 전송해야 함.
- 일부 센터는 구글 시트로 동의서를 받아 관리 → 보안과 체계성에 취약.
- → 앱 내에서 예약금 결제 + 기록지 작성 + 동의서 제출 + 알림문자 발송이 일괄 처리되면 효율적.

### 2. 코드 분리

- 예: 아동(채연, A 코드), 어머니(B 코드), 아버지(C 코드)로 분리 관리.
- 현재는 각각 다른 내담자로 관리되다 보니 회기 차감이 통합되지 않아 관리가 어렵다.
- → 코드 통합 필요: **가족 단위 연동**으로 회기 관리.

### 3. 내담자 방문

- 내담자가 방문하면 **기존 초기상담 기록지 출력** 후 상담사 전달.
- 상담 종료 후, 데스크에서 상담사가 남긴 메모·일지를 보고 다음 일정 예약.
    - 예: “다음은 부모상담으로 잡아주세요.”
- 내담자 상태값(설문완료, 검사지 제출, 노쇼 등)을 수동 변경.
- 노쇼 시 환불금액을 센터 정책에 맞게 수기로 기록.

### 4. 내담자 방문 후

- 자동 알림 필요: 예약 완료 / 회기권 임박 / 상담 종결 예정.
- **상담일지 공유 문제**:
    - 학부모에게 직접 제공(키즈노트식)하는 방식은 부적절.
    - 아이가 부모에게 숨기고 싶은 내용까지 전달될 수 있어 **치료 신뢰도** 저하 우려.
    - 치료사와 부모의 관점 차이로 오해 발생 가능.
- 종이 문서는 내담자별 파일철 보관 → 디지털화 미흡.

### 5. 검사 진행

- 상담사가 검사 오더지를 지류로 제출 → 비효율적, 검색 불가.

### 6. 장기 미방문자 관리

- 회기권을 보유했지만 장기간 미방문하는 내담자를 찾기 어려움.
- → 시스템 내 필터링 기능이 반드시 필요.

---

## Ⅴ. 내담자 문의

- 부모가 상담 관련 문의 시, 데스크에서 상담일지를 확인해 설명.
- 상담사가 직접 대응하지 않아도 되는 구조가 필요.

---

## Ⅵ. 매출 관리

- 현재 EAP 별도 사용 → 시스템 이원화 문제.
- 매출 통계는 월별·3개월 추이만 확인 가능.
- 내담자가 늦었을 때 상담사가 재량으로 진행한 수업은 자동 집계 안 됨 → 실장이 따로 수기 입력해야 함.

---

## Ⅶ. 보고서 관리

1. **통합 관리 문제**
    - 상담사와 실장이 결과 보고서를 메일로 주고받음 → 누락, 검색 불편.
2. **품질 관리 문제**
    - 상담사별 보고서 퀄리티 차이가 크고, 실장이 반드시 검토해야 함.
3. **참고 자료 필요성**
    - 초기상담 기록지, 검 사신청서 같은 자료가 보고서 작성 시 큰 도움이 되지만 체계적 관리 부재.
