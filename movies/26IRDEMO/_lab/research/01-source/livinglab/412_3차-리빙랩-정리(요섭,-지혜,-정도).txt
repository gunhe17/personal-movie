# 개별 검사 피드백
## BGT
- BGT 인트로 페이지에서 연령 설명은 불필요합니다.
- 코피츠, 헛과 같은 특정 채점법의 기준에만 얽매이지 않고 채점합니다.
- BGT 리콜(회상)이 더 중요하게 다뤄져야 하며, 현재는 그 비중이 너무 낮습니다.
- BGT 결과에서 연관된 오류들은 묶어서 해석하는 것이 효율적일 것입니다.
- BGT 채점 시 점 개수, 크기(cm), 배치 등은 시스템적으로 자동 제공되는 것이 오류 내용을 직접 입력하는 것보다 효율적일 것입니다.

## HTP
- BGT와 유사한 내용이 많습니다.
- PDI(그림 그리기 역동성 지표)를 직접 입력해야 한다면 이 프로그램은 사용하지 않을 것입니다. (수고로움 때문)
- 현재 시스템에서 PDI 사용 여부는 선택 사항이나, 사용하지 않을 경우 종합보고서 작성 시 해당 정보가 누락되어 문제가 될 수 있습니다.

## PDF 보고서 업로드
- 마음사랑 보고서와 같은 상업적 자료를 활용하는 데 저작권 문제가 없는지 확인이 필요합니다.
- PDF를 파싱하여 그래프나 표에서 임상 범위 점수가 나온 부분을 하이라이팅 해주면 빠르게 확인할 수 있어 유용할 것입니다.
- MMPI와 같은 검사의 쌍척도, 타당도 척도 등은 기존 보고서에 없어 일일이 찾아야 하는 번거로움이 있습니다. 이를 미리 제공해준다면 활용도가 높을 것입니다.

## 종합보고서
- 과거에 작성했던 종합보고서를 기준으로 현재 작성할 보고서의 초안을 생성할 수 있도록 해야 합니다.
- 투사 검사 결과가 보고서 화면에서 어떻게 표현될지 확인하기 어려워 아쉽습니다. (지능 검사는 비교적 정형화되어 있으나 투사 검사는 아님) -> 이에 대한 기획이 필요합니다.
  - HTP를 예로 들면, 스캔 후 간략한 기술적 분석을 작성해두면 종합보고서 맥락에서 통합적으로 반영될 수 있도록 지원하면 좋겠습니다.

## 로샤
- LOC(위치 선택) 화면에서 위치 선택 창이 잘려 스크롤해야 하는 점이 불편합니다. 한 화면에 모든 내용을 볼 수 있도록 개선이 필요합니다.
- LOC에서 커서를 근처에 가져가면 해당 위치가 하이라이팅 되면 좋을 것 같습니다.
- 형태 반응(고래, 해골 등) 중 엑스너(Exner) 책에 없는 경우, LLM 외에 다른 사용자들의 데이터 기반으로 목록을 보여주거나 추천/채점 기능을 제공하면 좋겠습니다.
- 자유 반응 및 질문 단계 테이블에서도 임상적으로 중요한 반응이 있다면 특별 표시가 필요합니다.
- 특수 지표가 유의미할 경우 해석이 필요합니다.
- 채점 단계에서 테이블 AI 부분의 가로 스크롤이 없어져 한눈에 볼 수 있었으면 좋겠습니다.
  - 카드 그림이나 방향 정보는 삭제해서라도 화면 넓이 확보가 필요합니다. (방향 삭제가 가능한지 고려 필요)
- 반응 시간을 표시하는 열 추가가 필요합니다.
- 결과 보기 화면의 반응 기록표는 가독성이 매우 떨어집니다.
- 결과 보기 화면의 군집별 해석 상세(도움말) 또한 가독성이 떨어지며, 보고서 작성 시 내용을 전부 읽지 않게 됩니다.
- 분석 단계에서 기존 엑셀과 동일한 결과표는 로샤의 특성이지만 가독성이 너무 떨어집니다.
- 채점 단계에서 칸마다 사람이 일일이 확인하는 작업이 번거롭습니다. AI 정확도가 높은 항목은 자동으로 확정하고 확인이 필요한 부분만 검토하도록 유도하면 좋겠습니다.
  - 초록색, 노란색, 주황색이 무엇을 의미하는지에 대한 안내가 없어 색상 의미를 알 수 없습니다.

## 필드노트
- 인터뷰(PDI, 로샤)와 같은 경우 녹음이 유용할 수 있습니다.
- 받아쓰기(STT) 성능은 매우 중요하며, 조금이라도 떨어진다면 검수 작업이 더 번거로워질 것입니다.
- 화자 분리가 명확하고 받아쓰기가 정확하다면 내용 편집은 크게 필요하지 않을 수 있습니다.
- 녹음을 하게 되면 내담자가 의식하여 추가적인 정보를 더 말해야 할 것 같다는 의견이 있습니다.
- 지능 검사에서는 녹음이 크게 필요하지 않을 것 같습니다.
- 행동 관찰과 같은 내용은 보고서 작성 시간을 단축시킬 수 있지만, 굳이 녹음까지 해가면서 해야 할지는 의문입니다.

# 종합적인 피드백
## 투사 검사
- 원 자료 스캔, 업로드, 채점 선택 등의 절차가 번거로워 직접 수기로 하는 것이 더 빠를 수 있습니다.
- 원 자료 스캔 및 업로드 작업 자체가 매우 큰 진입 장벽입니다.
- 모든 원 자료를 한 번에 업로드하면 BGT 검사 시 이미 업로드된 그림을 선택하여 사용할 수 있어 편리할 것입니다.
- 투사 검사 채점에서 클릭(도형 선택, 오류 내용 입력 등)을 반복하는 방식은 번거로워 사용하지 않게 될 것입니다.
- BGT에서 정상 범위 리콜 개수(예: 4개 또는 5개) 등 채점 관련 규준(기준)을 즉시 제공하면 좋겠습니다.
- 업로드된 원 자료가 서버에 저장될 것이므로, 개인 자료가 중앙 서버에 업로드되는 것에 대한 거부감을 해소할 수 있도록 명확한 설명이 필요합니다.
- 질적 분석을 작성했을 때, 이것이 보고서에 통합되는 것인지, 채점/해석 목록에 들어가는 것인지 등 직관적인 이해가 어렵습니다.
- 전체적으로 선택 사항(optional)이지만, UI 구성 때문에 모든 항목을 다 채워야 할 것처럼 느껴집니다. (질적 분석 작성 부분이 고정되어 있어 반드시 적어야 할 것처럼 느껴지는 등)
- 검사 현황 페이지에서 각 검사에 대한 설명, 필요성, 장단점 등의 도움말이 제공되면 나중에 참고하기 좋을 것입니다.

# 상담사 개인적인 의견
- HTP, BGT와 같은 검사를 일반인에게도 공개하여 사용자 대상을 확대하는 것은 어떨까요? (전문가들은 현재 방식에 번거로움을 느껴 사용하지 않을 가능성이 높으므로)
- 비 오는 날 우산 쓴 사람 그리기와 같이 풀 배터리에 포함되지 않는 검사들을 표준화하여 제공하는 것은 어떨까요? (풀 배터리 투사 검사는 현재 방식으로 인해 전문가들이 사용하지 않을 것이므로, 새로운 표준화된 검사에 대한 수요가 있을 수 있습니다.)
- 전문가는 익숙해서 사용하지 않고, 수련자는 훈련이 필요해서 사용하면 안 된다는 인식이 있습니다.
