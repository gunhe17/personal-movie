### PLAN | 전문가용 앱 기획안
(2026-03-24 by 강태훈)

(목표) 전문가가 가지고 있는 문제점을 파악하고 앱-웹 유기적인 연동 방안 확립

## 어떤 문제가 있나?
- (예약) 이번주/오늘 어떤 예약이 있나 확인
- (예약) 일정 변경/취소
  - => 취소 권한 어떻게 됨?
  - => 삭제 권한 어떻게 됨?
- (상담) 상담 출첵 확인
- (상담) 상담 내용 기록 / +++
- (검사) 검사 내용 기록
- 

- 앱에서 가능한것
  - 취소 및 상태변경
  - 변경 및 생성은 웹에서 가능하다고 안내는 해둘것

- (상담/검사) 전문가가 삭제까지 가능하게 해줘야할까?
  - 기본 권한을 삭제를 제외한 권한으로 전문가에게 넘기고, 이후 요청 시 권한 부여

- 일정 변경
  - 흐름
    - 내담자 변경 요청 -> 실장 확인 -> 시스템 노티(담당자에게)
  - 전문가는 [일정 생성] / [일정 변경] 불가능을 기본으로
    => 실장급(매니저) 부터 가능하게 하되, 변경이 이루어지면 담당자에게 noti 알림
  - 요청 승인도 변경 권한과 동일하게 가야한다. 

  - 내담자(학부모)가 변경 요청을 할 경우
    - 모든 것을 고려해서 변경 가능한 일자만 보여주기. 
    - 요청의 변경 범위
      - 내담자의 경우 - 시간만 알면된다. 

- 상담
  - 출첵 
  - 녹취
    - 일지 작성 시 참고
    - => ai 인사이트를 녹취 도중에 알려주기. ex 질문거리라던가?
    - 실시간 메모
  - 일지 작성 (사용자에게 확실히 인지가 되었으면 함 private 과 public 차이)
    - private (개인만 볼 수 있음 - 센터 공유 x)
    - public  (센터 열람 가능)
  - 회차 변경은 마찬가지로 불가

- 검사
  - 누가 했는지 확인 조회
  - 구성 자체는 웹과 유사하게
  - 종합보고서는 외부링크로 띄우던가해서 처리
